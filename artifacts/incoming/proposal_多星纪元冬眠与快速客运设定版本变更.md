# 版本变更提案：多星纪元「冬眠 + 快速跨恒星系客运」

## 一、问题（为什么必须走版本变更，而非逐篇返工）

内核物理硬约束（AGENTS.md §4.1 / 世界规则）明确：**无 FTL、无冬眠、无金手指；200 年航程是数学必然**。

但已入库正典中，有 **14 篇**在「多星纪元」及相邻纪元正面使用了黑名单设定，且它们**互引成网**，共同支撑起一个"跨恒星系定期客运/救援"子设定：

- **冬眠/低温休眠**（13 篇）：GS-2515（定期跨光年客运·一等休眠舱）、GS-2947（整篇·冬眠技术临评）、GS-2941、GS-2934、GS-2948、GS-2968、GS-2975、GS-2986、GS-3416、GS-3435、GS-3598、GS-2915、ARK-01第二航行世纪普查。
- **室温超导**（1 篇）：GS-2932（第四代聚变推进"室温超导材料，临界温度>300K"）。

这些不是孤立笔误：GS-2515 的"星槎-02 定期客运"、GS-2947 的"冬眠技术十年评估"、GS-3416/3435 的"救援船冬眠舱"彼此引用，构成一条完整的"人类已掌握安全冬眠 + 快速跨系客运"世界线。**逐篇删掉"冬眠"二字会留下断裂的时间线与互引死链**（如航程时长、代际结构、救援半径全部依赖该前提）。因此须按 AGENTS.md §5「大纲结构变更 = 升格流程」与内核版本变更处理，全轴回算。

## 二、两条可选路线

### 路线 A · 收束回硬约束（推荐）
**判定当前 14 篇为违规产物，回改以符合"无冬眠/无 FTL"内核。**
- 跨恒星系移动一律改回**多代际慢船 / 无人探针 / 信息传递（光速链路）**，删除"定期客运""冬眠团聚""冬眠救援"前提；
- 涉及"航程仅苏醒3次""冬眠乘客2103人"等，改为**代际值守机组 + 长期闭环生保**（与 ARK-01 主轴一致）；
- GS-2932 室温超导 → 改回**低温超导磁约束**（临界温度<150K），回算第四代聚变推进比冲；
- GS-2947 整篇以冬眠为前提 → **撤稿留号**（登记簿加注，号不复用），或改写为"长期闭环生保/低速休眠医学"合规主题；
- 代价：需回改 14 篇正文 + 登记簿加注 + 校验互引死链；工作量大但**保住物理脊柱**。

### 路线 B · 升格内核（放宽黑名单，全轴回算）
**正式修订内核：允许"多星纪元起，人类掌握了非 FTL 但可接受的低温休眠与亚光速快速客运"。**
- 需在世界规则附录新增"冬眠技术解锁节点"（何年、何物理机制、何代价），并**全轴回算** 2025—4000 的时间线、人口结构、代际设定、既有 ARK-01"200年航程是数学必然"叙事；
- 代价：**动摇项目立身之本**（硬科幻/无金手指/世代飞船叙事），README 与 core/ 多处需改，且与已入库的大量"慢船/代际"正典冲突。风险远高于 A。

## 三、提案人建议

**采用路线 A**。理由：本项目的独特价值正是"硬约束下的无冲突史诗"；冬眠/快速客运一旦合法化，世代飞船的"200 年数学必然"与代际叙事将被掏空，得不偿失。14 篇的返工量可控，且已有合规改写示范（GS-2915 见 `artifacts/正典红线工作清单_20260915.md` 与优化报告）。

## 四、执行清单（若附议通过 · 路线 A）

1. 登记簿对 GS-2947 撤稿留号加注；其余 13 篇标"待回改"。
2. 逐篇回改正文：冬眠→代际值守/闭环生保；定期客运→慢船/信息链路；室温超导→低温超导。
3. 回改后跑 `scripts/check_submission.py --all` 确认金手指红线归零，且互引 archive_id 无死链。
4. 更新 core/世界规则 附录（如需明确"跨系交通 = 慢船 + 光速信息"）与 README 正典数。
5. 内核/大纲版本记录 +1，注明本提案与附议者。
