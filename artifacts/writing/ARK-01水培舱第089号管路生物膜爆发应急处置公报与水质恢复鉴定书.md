# ARK-01水培舱第089号管路生物膜爆发应急处置公报与水质恢复鉴定书

**船政总署 · 生态环控处 · 水培科**
**联合发文：** 船政安全应急处、船政医疗处
**文件编号：** 船政生字〔2225〕第019号
**事件等级：** 丙类（局部生态扰动，未威胁全船供水）
**事件起止：** 2225年7月14日—8月2日

---

## 一、事件发现与初始响应

### 1.1 发现经过

2225年7月14日03时17分，B环水培舱第三栽培区营养液循环系统在线传感器触发报警：
- 溶解氧（DO）从正常值6.8mg/L骤降至3.2mg/L
- 浊度从0.3NTU升至14.7NTU
- 化学需氧量（COD）从12mg/L升至87mg/L

值班运维员何秀兰（工号B-2198-0076）接警后5分钟内抵达现场，目视检查发现第089号主管路（DN200不锈钢，连接第三栽培区A、B两组栽培架）视镜内可见深绿色至黑色黏膜状附着物，部分区域已堵塞管路截面约40%。

### 1.2 应急响应启动

03时42分，生态环控处值班处长赵稼祥（二代）宣布启动丙类应急响应。响应措施：
1. 关闭第089号管路前后阀门，将第三栽培区A、B组切换至旁路循环（第090号备用管路）。
2. 通知安全应急处、医疗处派员到场。
3. 采集生物膜样本与营养液样本，送生态实验室检测。
4. 对第三栽培区作物进行临时营养液更换（使用储备液）。

## 二、事件调查与原因分析

### 2.1 生物膜样本检测结果

| 检测项目 | 结果 |
|---|---|
| 生物膜厚度（均值） | 3.2mm（最厚处7.8mm） |
| 生物膜干重 | 147g/m² |
| 优势菌种 | 假单胞菌属（Pseudomonas sp.）占68%，鞘氨醇单胞菌属占21% |
| 藻类成分 | 小球藻（Chlorella vulgaris）变异株，占生物膜有机成分23% |
| 胞外聚合物（EPS）含量 | 412mg/g干重 |
| 异养菌总数 | 2.3×10⁸ CFU/g |
| 致病菌筛查 | 未检出沙门氏菌、军团菌、大肠杆菌O157:H7 |

### 2.2 原因分析

经管路拆解检查与运行数据回溯，确定爆发原因为多因素叠加：

1. **管路老化。** 第089号管路为出港时安装的原始管路，已运行75年。内壁钝化层局部破损（经检查发现17处点蚀，最大深度0.4mm），为微生物附着提供了粗糙表面。
2. **流速偏低。** 该管路所在分支因第三栽培区2223年改造后栽培架数量减少，营养液流量从设计值12m³/h降至7.5m³/h，管内流速从1.06m/s降至0.66m/s，低于生物膜控制阈值（0.8m/s）。
3. **营养负荷波动。** 2225年6月第三栽培区更换肥料批次后，营养液中可溶性有机碳含量从8mg/L升至15mg/L，为异养菌增殖提供了碳源。
4. **消毒频次不足。** 该管路上次酸洗消毒为2220年11月，已超过规定的3年消毒周期（因2223年栽培区改造而推迟）。

### 2.3 影响范围评估

| 影响项 | 评估结果 |
|---|---|
| 受影响栽培架 | 第三栽培区A、B组，共48架 |
| 受影响作物 | 生菜（船生-1号）24架、菠菜12架、香草12架 |
| 作物损失 | 生菜12架出现根系褐变，预估减产约180kg |
| 全船供水影响 | 无（水培营养液回路与饮用水回路物理隔离） |
| 人员健康影响 | 无（致病菌筛查阴性，未接触人体） |

### 3.2 处置过程中的关键决策

**关于消毒药剂选择：** 初始方案考虑使用过氧化氢（浓度3%），但因089管路内壁存在点蚀，过氧化氢可能加速点蚀扩展，最终改用柠檬酸+次氯酸钠组合方案。次氯酸钠消毒后用硫代硫酸钠中和，确保残留氯达标。

**关于管路更换：** 检查发现089管路点蚀17处，虽未穿透（管壁厚度3mm，最大点蚀0.4mm），但已接近更换阈值（点蚀深度>壁厚15%）。应急处置后，将089管路列入2226年度更换计划，更换为船载精密制造车间生产的316L不锈钢管（内壁电解抛光，粗糙度Ra<0.4μm）。

### 4.3 鉴定结论

第089号管路经清洗消毒后，水质各项指标恢复至设计标准范围内，生物膜处于正常定植初期水平，无复发迹象。第三栽培区作物生长状态恢复正常。应急响应解除，转入常规监测。

**鉴定人：** 水培科 科长 林秀芳（签章）；公共卫生科 科长 王雅琴（签章）

## 五、整改措施与长效机制

1. **全管路排查。** 对全船水培系统127条主管路进行内壁检查，重点排查运行超过50年的原始管路。预计2225年底前完成。
2. **消毒周期缩短。** 将主管路酸洗消毒周期从3年缩短至2年，流速低于0.8m/s的分支管路缩短至1年。
3. **流速优化。** 对因栽培区改造导致流速下降的管路进行流量重新分配或加装增压泵，确保主管路流速≥0.8m/s。
4. **在线监测升级。** 在所有主管路加装生物膜早期预警传感器（基于ATP生物发光法，检测阈值100RLU），实现实时监控。
5. **管路更换计划。** 2226—2230年分批次更换运行超过70年的原始主管路，共38条，预计消耗316L不锈钢管材约2.4吨。
6. **肥料批次管理。** 建立肥料批次可溶性有机碳含量检测制度，超标批次不得直接使用，需经预处理降碳后方可投入。
