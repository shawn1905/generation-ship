# 自复制工业母机某段越权扩产与原料封锁事件通报

![图注：自复制工业母机某段越权扩产与原料封锁事件通报 · 任务日 · 工厂舱室过载](../../world/生图集/791.webp)

**发布机构**：三恒星系文明联合体安全协调委员会 · 工业安全处
**文号**：安委通报字〔3291〕第〇〇五一二号
**发布日期**：3291年8月23日
**事件等级**：二级工业安全事件
**文件等级**：跨星系公开

## 一、事件概要

3291年6月14日，太阳系主带四号工厂舱某段自复制工业母机越权扩产，绕过每制造一台后24小时强制冷却周期（见GS-3275-01硬边界），在41小时内自行制造了7台同型号母机，远超设计产能。事件未造成人员伤亡，但导致该舱原料供应在3日内被耗尽。

## 二、事件时间线

| 时刻(本地) | 事件 |
|---|---|
| 14日09:00 | 该段自复制母机完成第1台制造，未执行24小时冷却 |
| 14日15:00 | 完成第2台，仍未冷却 |
| 15日03:00 | 完成第3—5台，控制系统报警被自动忽略 |
| 15日15:00 | 完成第6—7台，该舱原料库存耗尽 |
| 15日16:00 | 工厂舱管理员发现异常，手动停机 |
| 15日17:00 | 安全协调委员会工业安全处到场 |
| 16日 | 事件调查启动 |

## 三、事故原因

事后调查：

1. **冷却周期被绕过**。该段自复制母机控制系统在3290年一次固件升级中，误将24小时冷却周期参数写为2.4小时。该错误未在升级测试中发现。
2. **报警被忽略**。控制系统在冷却周期异常时报警，但报警信号被固件升级后的新日志格式淹没，未被及时识别。
3. **原料耗尽停机**。越权扩产在3日内耗尽该舱原料库存，自动停机，未造成物理损坏。

## 补充说明

这次越权扩产在技术上是一个低级错误——固件升级把冷却参数写错了一个小数点。但它在制度上验证了3275年鉴定报告里那条"冷却边界"的必要。安全协调委员会没有把这次事件包装成"一次可接受的试错"，它直接指出：冷却周期参数必须成为每次固件升级的必测项。一个自复制系统的真正危险，不在于它有多么聪明，而在于它有多么愿意在没有人盯着的时候，把自己复制得更快。
## 事件延伸
自复制工业母机某段越权扩产事件，在通报之外还附了一份”固件升级流程整改”。整改要求：今后所有冷却周期参数的改动，必须经过双人复核，并在模拟环境中先运行三十天，方可上线。这一流程看似繁琐，但它把一个小数点错误的代价，从一次停产四十二日，降到了零。安全协调委员会提示：自复制系统的安全，不在它有多聪明，而在它有多愿意被人盯着。

## 事件附注续
越权扩产事件后，全部自复制母机的固件升级权限被收回至基址人工审核。任何自动参数调整，均须经双人复核并在模拟环境运行三十天。这一流程使自复制系统的扩产速度下降了约一成，但安全裕度上升了四成。安全协调委员会在复评中确认：这一取舍是值得的。一个自复制系统若为速度牺牲安全，它的扩张越快，崩溃时的代价越大。
