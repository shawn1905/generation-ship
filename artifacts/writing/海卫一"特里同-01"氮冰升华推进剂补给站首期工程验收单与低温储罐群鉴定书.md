## 第一部分：首期工程验收单

### 一、工程概况

海卫一"特里同-01"氮冰升华推进剂补给站首期工程于2102年7月启动建设，2105年3月15日完成全部施工与设备安装，3月20日至4月10日进行全系统联调与性能测试，4月18日通过竣工验收委员会现场验收。补给站位于海卫一南极冰原（南纬78°，东经120°），该处氮冰覆盖厚度达120—180 m，氮冰纯度>99%，是海卫一表面氮冰资源最富集的区域之一。

补给站核心功能：从海卫一表面氮冰中采集原料，经升华—纯化—压缩工艺生产高压氮气推进剂，为途经海王星系统的深空飞船（柯伊伯带探测船、外太阳系货运舰、内奥尔特云补给船）提供原位推进剂补给服务。氮气作为冷气体推进剂，虽比冲较低（约70 s），但在海卫一原位获取成本极低，适用于深空飞船的轨道机动与姿态控制。

### 三、氮冰采集与升华工艺

氮冰采集采用机械刨削方式：四台履带式刨削车（全封闭加压金属车体，乘员2人，车体重12 t）在冰面行进，刨削头（硬质合金刀具，转速60 rpm，刨削深度50 mm/次）将氮冰刨削为5—20 mm碎块，经螺旋输送机装入密闭保温料斗（容积8 m³，真空绝热，漏热<2 W）。料斗满后由牵引车运回补给站卸料区，倒入地下原料仓（容积2,000 m³，温度维持在40 K以下）。

升华阶段：原料氮冰经螺旋给料机送入真空升华炉（炉内压力10⁻² Pa，温度由50 K加热至65 K，利用裂变堆余热），氮冰在低压下直接升华为氮气。升华炉内壁涂覆聚酰亚胺薄膜（耐低温+低出气率），炉体采用真空多层绝热。每台升华炉处理量5 t/h，4台并行运行，日处理量480 t氮冰，产出氮气约432 t（升华效率90%，部分氮气随不凝气排出）。

纯化阶段：粗氮气经低温吸附塔（分子筛5A，工作温度77 K，利用站内液氮冷源冷却）吸附去除CO、CH₄、H₂O等杂质，纯化后氮气纯度达99.999%以上。吸附塔每8小时切换再生一次（加热至200 K脱附，真空抽除杂质）。

压缩储存：纯化氮气经多级活塞压缩机（四级压缩，出口压力40 MPa）压缩后，送入低温储罐群。储罐采用"高压气态+低温液态"混合储存：上部为高压气态氮气（40 MPa，常温293 K），下部经节流膨胀制冷转化为液氮（温度77 K，压力0.5 MPa），单罐可储存约40 t氮气当量。

## 第二部分：低温储罐群鉴定书

### 五、储罐群设计与构造

特里同-01低温储罐群由12台立式圆筒形真空绝热储罐组成，分两排布置于地下冰洞（人工开挖，洞顶覆冰厚度15 m，利用冰体天然隔热与结构支撑）。单罐核心参数：

| 参数 | 数值 |
|:---|:---|
| 储罐型式 | 立式圆筒形，真空粉末绝热（VPL）+高真空多层绝热（VMLI）复合 |
| 几何容积 | 500 m³（内径8 m，切线长10 m，椭圆封头） |
| 有效容积 | 450 m³（充装系数0.9） |
| 内筒材质 | 奥氏体不锈钢304L（低温韧性良好，300 K—4 K温度范围适用） |
| 内筒壁厚 | 12 mm（设计压力0.8 MPa，液氮工况） |
| 外筒材质 | 碳钢Q345R（外筒处于常温，承受外压） |
| 外筒壁厚 | 16 mm（设计外压0.1 MPa，真空夹层） |
| 绝热层 | 内筒外壁包裹40层高真空多层绝热（铝箔+玻璃纤维纸，层间距0.5 mm），夹层抽真空至10⁻³ Pa以下；多层绝热外侧填充珠光砂（厚度200 mm）作为辅助绝热 |
| 总绝热厚度 | 约240 mm |
| 设计温度 | 内筒77 K（液氮），外筒293 K（环境） |
| 设计压力 | 内筒0.8 MPa（液氮储存）/ 40 MPa（高压气态区，独立分隔） |
| 日蒸发率（设计） | ≤0.5%/天（液氮工况） |
| 储罐自重 | 约85 t/台 |
| 满液质量 | 约360 t/台（液氮密度0.8 t/m³×450 m³） |

### 六、储罐制造与检验

储罐内筒在地球地月L1造船厂预制（卷板+焊接+无损检测），经深空货运船运抵海卫一，在补给站现场进行外筒套装与绝热层施工。制造与检验执行以下标准：

| 检验项目 | 标准要求 | 检验方法 | 结果 |
|:---|:---|:---|:---|
| 内筒焊缝无损检测 | 100%射线检测（RT），Ⅱ级合格 | Ir-192射线探伤 | 全部合格 |
| 内筒焊缝表面检测 | 100%渗透检测（PT），无线性显示 | 着色渗透 | 全部合格 |
| 内筒水压试验 | 试验压力1.0 MPa（1.25倍设计压力），保压30 min无渗漏 | 充水加压 | 12台全部合格 |
| 内筒氦质谱检漏 | 漏率≤10⁻⁹ Pa·m³/s | 氦质谱检漏仪 | 12台全部合格（最大漏率6×10⁻¹⁰） |
| 外筒真空度 | 夹层真空度≤10⁻³ Pa | 真空规管测量 | 12台全部达标（均值8×10⁻⁴ Pa） |
| 绝热层日蒸发率 | ≤0.5%/天 | 充液氮静置7天，称重法测量蒸发量 | 12台均值0.32%/天，最大0.41%/天 |
| 基础沉降 | 不均匀沉降≤2 mm/年 | 冰基沉降监测（光纤应变传感器） | 首期监测期沉降0.3 mm（均匀） |

### 七、储罐群运行安全鉴定

1. **结构安全**：12台储罐内筒经水压试验与氦检漏合格，外筒真空度达标，绝热层日蒸发率优于设计值。冰基基础在首期监测期内沉降均匀（0.3 mm），远低于限值（2 mm/年），结构安全鉴定合格。

2. **低温安全**：储罐内筒工作温度77 K，外筒293 K，温差216 K。经热应力核算，内筒筒体最大热应力120 MPa（304L在77 K下屈服强度约280 MPa），安全系数2.3，满足要求。管道与储罐连接处采用波纹管膨胀节补偿热收缩，膨胀节行程±50 mm，实际热收缩量约32 mm，裕度充足。

3. **压力安全**：每台储罐配备2套安全阀（开启压力0.85 MPa，排放能力2 kg/s氮气），1套爆破片（爆破压力0.95 MPa），以及压力变送器（量程0—1.0 MPa，精度0.25级）。安全阀每年校验一次，爆破片每2年更换一次。储罐区设置氮气浓度监测报警（工作区O₂浓度低于19.5%时报警），防止氮气泄漏导致窒息。

4. **防火防爆**：氮气为惰性气体，不可燃不助燃，储罐区无火灾爆炸风险。但储罐区周边设备（裂变堆、压缩机、电气设备）需按常规防火要求管理，配备二氧化碳灭火器（不适用于氮气泄漏场景，但用于电气火灾）。

5. **抗震与微陨石防护**：海卫一无构造地震（冰壳稳定），但冰火山喷发可能引发局部冰震（观测到最大震级约3级）。储罐按5级冰震设防（水平加速度0.5 m/s²），经核算满足要求。微陨石防护：储罐位于地下冰洞，洞顶覆冰15 m，可完全屏蔽>0.1 mm微陨石，无需额外装甲。

6. **人员操作安全**：储罐区操作需佩戴低温防护手套（耐77 K）、防护面屏、防静电工作服。液氮加注时操作人员必须站在上风向，防止低温氮气窒息。储罐区设置紧急喷淋装置（常温水，用于液氮溅洒后的快速升温复温）。

**鉴定结论**：特里同-01低温储罐群12台储罐全部通过制造检验与性能测试，结构安全、低温安全、压力安全、人员操作安全均满足设计要求与外太阳系深空设施安全规范。储罐群鉴定合格，同意投入正式运行。建议每5年对储罐进行一次开罐内检（检查内筒腐蚀与绝热层状态），每10年进行一次全面耐压试验。
