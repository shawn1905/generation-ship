# 跨航道海盗残余清剿收官行动与航道安全总结公报

**发布机构**：联合体安全协调署 / 航道防卫处
**发布日期**：3072年10月10日
**文件等级**：跨星系公开
**公报号**：SEC-3072-1010

## 一、背景

自2979年航道巡逻机制建立（GS-2979-01），跨星系航道上针对货运船队的武装抢劫已持续近百年。前哨、自治港、巡逻舰三方联防，逐步将主要匪巢压制至三恒星系航道交界处的几处残骸锚地。本次为残余清剿收官行动。

## 二、行动

3072年上半年，巡逻舰队对三处残余锚地实施封锁与劝降：

1. 第一处锚地14艘武装船，劝降后缴械，人员依《深空公海纠纷法典》（GS-2382-02）处置；
2. 第二处锚地抵抗，巡逻舰按交战规则瘫痪其推进器，未登船滥伤；
3. 第三处锚地人员自行弃船，乘救生舱投降。

全程无交火致死——三处均在劝降阶段解决或瘫痪即止。

## 三、总结

| 项 | 数值 |
|---|---|
| 缴械武装船 | 22艘 |
| 俘获人员 | 约310人 |
| 巡逻舰战损 | 0 |
| 无交火致死达成 | 是 |

航道防卫处指出：海盗现象的根源是三恒星系间经济落差与部分前哨的法权真空，军事清剿只能收一时之功。收官之后，仍须靠发展基金（GS-2973-01）与自由流动法（GS-3060-01）让那些会去当海盗的人有别的活路。

## 四、附则

本公报不把任何一位舰长写成英雄。清剿收官是巡逻、缴械、劝降、审判一长串日常公事的终点，不是传奇的高潮。
