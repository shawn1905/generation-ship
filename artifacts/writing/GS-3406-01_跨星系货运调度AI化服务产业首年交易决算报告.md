# 跨星系货运调度AI化服务产业首年交易决算报告

![图注：3406年6月30日 · 调度总署产业结算屏 · 数据看板 · 档案体](../../world/生图集/906.webp)

**编制单位**：联合体经济协调司产业结算科
**报告编号**：ECO-3406-021
**结算周期**：3405年7月1日—3406年6月30日

## 一、产业范围

调度AI化服务产业，指为跨星系货运提供调度算法、货柜标签识别、航线排序、靠泊预排、延误预警等AI服务的市场交易。该产业自3402年第七次修订（见GS-3402-01）允许第三方服务商接入调度AI"衡陆"开放接口后正式形成市场。本报告为首年决算。

|---|---|---|
| 调度算法授权费 | 4,200 | 35% |

| 航线排序API调用 | 2,100 | 18% |
| 靠泊预排服务 | 1,500 | 12% |
| 延误预警订阅 | 800 | 7% |
| 其他（数据标注、模型微调） | 600 | 5% |
| 合计 | 12,000 | 100% |

## 六、就业影响

调度AI化服务产业首年直接就业岗位：

| 岗位 | 人数 |
|---|---|
| 算法工程师 | 320 |
| 数据标注员 | 1,800 |
| 模型审核员 | 240 |
| 运维与现场支持 | 560 |
| 合规与安全审计 | 180 |
| 合计 | 3,100 |

同期，传统人工调度岗位减少约2,800个，其中2,100人转岗至AI审核与数据标注，400人退休，300人转岗至物流标准化（见GS-3425-01）。转岗率75%，高于自动化替代潮平均水平。

## 七、风险提示

经济协调司在决算末注明三项风险：

1. 调度AI误判事件（见GS-3404-01）表明算法风险仍在，第三方服务商若接入开放接口，须承担连带审核责任；
2. 首年市占率CR3为72%，存在集中化趋势，须按反垄断例行审查；
3. AI服务营收与货运总量挂钩，若跨系贸易波动，本产业营收同步波动，不适用独立增长逻辑。

## 八、与既有正典咬合

- 误判事件与整改：GS-3404-01；
- 伦理签批员制度：GS-3440-01；
- 标准货柜产业：GS-3414-01；
- 运输成本下降决算：GS-3430-01。

## 七、数据标注产业

调度AI化服务催生了一个新岗位：数据标注员。首年数据标注员1,800人，主要工作是为调度AI标签识别模型标注货柜标签图像。标注员人均日标注400张图像，月薪约星汇4,200元。

经济协调司注明：数据标注是调度AI的"手"。AI出图靠算力，AI认得准靠标注员的眼睛。这1,800人的眼睛，是3404年误判事件（见GS-3404-01）后长出来的。

## 八、反垄断审查

首年市占率CR3为72%，经济协调司按反垄断例行审查，结论为：调度AI服务市场尚在早期，集中度高不构成垄断，但若CR5超过85%须启动分拆评估。审查不公开，仅在经济协调司内部存档。

## 九、与3450年旺季压港的前瞻

首年决算时，经济协调司已注意到调度AI对旺季舱位预测的系统性低估。报告末页注："若旺季来临，AI预测可能偏低。"这行字在3450年旺季压港事件（见GS-3450-01）后被重新翻出，作为预警证据。

## 十、调度AI服务的技术架构

| 层 | 功能 | 服务商 |
|---|---|---|
| 模型层 | 调度算法主接口 | 衡陆官方运营体 |
| 识别层 | 货柜标签识别 | 听澜算务 |
| 排序层 | 航线排序 | 安澜数据 |
| 预排层 | 靠泊预排 | 远禾智能 |
| 预警层 | 延误预警 | 其余七家 |

各层通过开放接口连接，数据格式统一。经济协调司注明：分层不是为了好看，是为了出事时知道找谁。

## 十一、调度AI服务与货主的关系

调度AI服务产业首年营收一万二千万，货主端净节省五千七百万。经济协调司注明：产业赚了一万二，货主省了五千七。这笔账算得过来。AI服务不是成本，是投资。

## 十二、调度AI服务的社会意义

调度AI化服务产业首年营收一万二千万，就业三千一百人。经济协调司注明：这三千一百人的工作，是让船准点、让柜不丢、让港不挤。他们的工作不是AI能替代的——AI替代的是重复劳动，不是判断。

## 十三、首年交易的社会评价

首年交易完成后，经济协调司收到货主来信三百一十二封，其中表扬二百零三封、抱怨八十九封、十封为建议。表扬集中于准点率提升；抱怨集中于一级带宽仍偏贵。经济协调司注明：生意做起来了，骂声也来了。有骂声，说明有人在乎。

## 十四、首年交易的行业结构

调度AI化服务产业首年交易一万二千万中，模型层占百分之四十二，识别层占百分之二十八，排序层占百分之十五，预排层占百分之十，预警层占百分之五。经济协调司注明：钱花在识别和模型上，因为这两层决定准点率。预警层占比小，是因为预警本来就不赚钱，是保险。

## 十五、决算数据复核与归档

本决算全部交易明细由经济协调司产业结算科复核，复核人签认名单附后。原始交易流水保留十年，审计署可随时调阅。首年利润率33%为早期红利，不构成长期预期；经济协调司在决算末页加注：次年若利润率回落超过八个百分点，须在决算中单独说明原因。本报告归档号ECO-3406-021，跨星系公开。
