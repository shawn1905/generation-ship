# 跨星系客运班船"远信号"遇第四恒星系沙暴偏转航线与旅客安置事件公报

![图注：航道调度屏 · 远信号偏航轨迹与避风停泊点 · 档案体](../../world/生图集/704.webp)

**发布机构**：三恒星系文明联合体航道安全局
**事件对象**：跨星系定期客运班船"远信号"（注册港：新海市）
**事件日期**：3204年5月中旬
**发布日期**：3204年5月30日
**密级**：跨星系公开

## 一、事件经过

3204年5月14日，"远信号"载乘客三百一十二人、船员二十八人，自新拓前哨（GS-3101-01）启航返航新海市。启航后第九日，船抵第四恒星系方向一原生尘暴（GS-3104-01）外缘。该尘暴较预测图扩展半径约四十万公里，船首雷达于两小时内侦测到高速沙粒流密度陡增。船长依预案决定偏离预定航线，向北转向避风，在一处临时停泊点停泊等待风暴过境。

## 二、时间线

| 时刻(协星历) | 事件 |
|---|---|
| 5-14 启航 | 载340人离新拓前哨 |
| 5-23 02:11 | 雷达首见尘暴密度异常 |

| 5-23 06:15 | 转入临时停泊点，主推进器怠速 |
| 5-23 09:00 | 向联合体航道调度（罗盘系统，GS-3028-01）发出偏航报告 |
| 5-24—5-27 | 原地避风，期间舱外沙粒冲刷舰体 |
| 5-28 13:20 | 尘暴减弱，重启主推进器复航 |
| 5-30 | 安全抵新海市，旅客无伤亡 |

## 三、旅客安置情况

偏航避风期间，全船人员舱压、温控、氧气均正常。三百一十二名旅客中，有孕妇两名、幼童七名、老人十一名、行动不便者三名，船医与乘务组逐人登记并安排靠近救生舱之铺位。船上储备食物与饮水按原定航程四十日设计，避风四日消耗在预算之内，未启用应急配给。因航线延误十二日，部分旅客后续行程受影响，联合体依自由流动与旅客人身保障规则（GS-3060-01）协调改签，未发生群体性投诉。

## 四、旅客反映与善后

避风期间，船上乘务组每日向旅客通报尘暴预测与预计复航时刻，无一人恐慌。事后随机访谈八十名旅客：七十人认为处置得当，八人认为复航后应安排一定补偿，二人认为启航前应更早预报。联合体依规则对因延误十二日导致后续跨系航班错过者，统一改签并补偿一张跨系通程券。无人提出诉讼或正式投诉。船医记录：全程无新增病患，原有两名孕妇胎象平稳。

## 五、船体与设备检查

抵港后逐项检查：船首防沙涂层局部冲刷，无损；光学通信窗有三处细痕，已抛光；主推进器与姿态喷口工作正常，无异物吸入。未发现微流星撞击之外的结构性损伤。

## 六、整改措施

1. 第四恒星系方向尘暴预测图更新周期由七日缩短至三日，避风停泊点由三处增至六处；
2. 偏航报告与航道调度系统（罗盘，GS-3028-01）实现自动报送，不再依赖人工发电；
3. 客运船应在启航前向旅客书面告知第四恒星系方向尘暴季节之可能延误；
4. 对本次偏航处置，船长决定及时、报告规范，航道安全局予通报表扬。


## 七、同类事件教训归档

本事件后，航道安全局将第四恒星系方向沙暴季节纳入启航前旅客告知例行内容，并将偏航避风案例编入航海安全教材（见GS-3173-01统一课程）。"远信号"船长在事后自评中写道："偏航不是失误，是本分；真正要检讨的，是风暴图为何晚了三天。"此评语已入训鉴。全船三百一十二名旅客事后无一人投诉，部分旅客反致信表扬乘务组。


## 八、旅客补偿与航海教材

三百一十二名旅客事后无一人投诉，部分反致信表扬。因延误十二日错过后续跨系航班者，统一改签并补偿一张通程券。"远信号"船长自评："偏航不是失误，是本分；要检讨的，是风暴图为何晚了三天。"此评语编入航海安全教材（统一课程，见GS-3173-01）。航道安全局另将第四恒星系方向沙暴季节纳入启航前旅客告知例行内容。


## 八、事后航线复盘

"远信号"抵港后，航道安全局对本次航线作复盘：风暴预测图滞后三日，是第四恒星系方向空间天气（见GS-3034-01）监测在该扇区覆盖不足所致。复盘结论已反馈天警中心补盲。船长在返航总结中写道：船上三百一十二人，无一人受伤，靠的是急停及时、告知及时、补给充足。此事件未记入任何"英雄"叙事，只入航海教材。


## 九、写入航海档案

本事件经航道安全局核定为"避险得当"，不列入事故。船长与乘务组获通报表扬，全船旅客事后联名致信致谢。事件档案存文枢（见GS-3015-01），其偏航避风案例编入航海安全教材，供后来者知悉：在沙暴外缘，偏航不是怯懦，是职责。


## 十、立卷说明

本事件经航道安全局核定为"避险得当"，不列入事故统计，亦不记入船长技术过失档案。船长与乘务组获通报表扬，三百一十二名旅客事后联名致信致谢。事件全部卷宗——含沙暴路径图、偏航航向记录、旅客安置名册、补给清单——存文枢（见GS-3015-01），其偏航避风案例编入航海安全教材（统一课程，见GS-3173-01）。航道安全局在卷末附言：在沙暴外缘，偏航不是怯懦，是职责；把风暴图作准，是后来者当自勉之事。本档案自此成为第四恒星系方向空间天气监测补盲之起点。
