# 跨星系量子通信中继网第五代升级与带宽扩容公报

![图注：跨星系量子通信中继网第五代升级与带宽扩容公报 · 任务日 · 档案体](../../world/生图集/660.webp)

**发布机构**：三恒星系文明联合体通信委员会 / 跨星系通信局
**发布日期**：3160年3月25日
**文件等级**：跨星系公开

## 一、升级背景

跨星系量子通信中继网自2910年首次部署以来（见GS-2910-01），已经历四次重大升级。随着三恒星系跨星系贸易、人口流动、文化交流的快速增长，现有第四代中继网的总带宽已接近饱和。

据联合体通信局统计，3159年度跨星系通信总流量为3150年度的2.3倍，其中视频通信、虚拟现实传输、跨星系数据贸易（见GS-2957-01）三项占总流量的68%。预计到3165年，总流量将再翻一番。

为应对需求增长，联合体通信委员会决定启动第五代中继网升级工程。

## 二、升级内容

**（一）技术升级**

| 项目 | 第四代（现有） | 第五代（升级后） |
|---|---|---|
| 单中继站带宽 | 10 Gbps | 50 Gbps |
| 中继站数量 | 12座 | 18座 |
| 端到端延迟 | 0.3毫秒 | 0.1毫秒 |
| 量子密钥分发 | 支持 | 支持+后量子加密 |
| 同时支持用户数 | 50万 | 200万 |

**（二）新增中继站**

第五代升级将新增6座中继站：

| 编号 | 位置 | 功能 | 建成时间 |
|---|---|---|---|
| QRS-13 | 比邻星b轨道L1点 | 比邻星b方向汇聚 | 3161年 |
| QRS-14 | 鲸鱼座τ星轨道L2点 | 鲸鱼座τ星方向汇聚 | 3162年 |
| QRS-15 | 太阳系外缘柯伊伯带 | 太阳系外缘链路 | 3162年 |
| QRS-16 | 星际航道中段A点 | 跨航道中继 | 3163年 |
| QRS-17 | 星际航道中段B点 | 跨航道中继 | 3163年 |
| QRS-18 | 第四恒星系方向预备点 | 未来扩展预留 | 3164年 |

**（三）带宽扩容效果**

升级完成后，三恒星系量子通信总带宽将从目前的120 Gbps提升至900 Gbps，增长6.5倍。这将使：
- 跨星系高清视频通话从当前的2K分辨率升级至8K；
- 虚拟现实跨星系协同工作从当前的"可接受延迟"升级至"沉浸式体验"；
- 跨星系数据贸易市场交易量预计增长3倍。

## 三、工程预算

| 项目 | 预算（亿星元） |
|---|---|
| 新中继站建设 | 480 |
| 现有中继站升级改造 | 220 |
| 地面接收站升级 | 80 |
| 光缆与量子纠缠对分发线路 | 150 |
| 运维与测试 | 70 |
| **合计** | **1,000** |

## 四、施工计划

| 阶段 | 时间 | 内容 |
|---|---|---|
| 第一阶段 | 3160-3161 | QRS-13、QRS-14建设 |
| 第二阶段 | 3161-3162 | 现有中继站升级改造 |
| 第三阶段 | 3162-3163 | QRS-15、QRS-16、QRS-17建设 |
| 第四阶段 | 3163-3164 | QRS-18建设与全网联调 |
| 第五阶段 | 3164-3165 | 试运行与正式切换 |

预计3165年第一季度正式投入使用。

## 五、对社会的影响

通信局在公报中指出：

> "通信是跨星系文明的血管。从2910年第一座量子中继站建成到今天，我们已经习惯了跨星系即时通信的便利。但这背后是150年持续不断的技术升级和基础设施投入。
>
> 第五代中继网不仅是一次技术升级，更是一次文明基础设施的换代。它将让三恒星系的48亿人真正感受到'我们住在同一个社区'。"
