# 第四恒星系与三恒星系边界共栖人工水体跨生态共管公报

![图注：边界共栖水体加压透明管道 · 两侧生态舱分色 · 单一冷光 · 档案体](../../world/生图集/823.webp)

**发布机构**：联合体生态学派 · 跨系生态共管处
**文件编号**：ECO-BND-3323-004
**日期**：3323年5月19日
**文件等级**：跨星系公开

## 一、背景

第四恒星系拓荒定居点（见GS-3101-01起）与三恒星系内部轨道定居点之间，存在一段长约40公里的加压透明水体管道——原为3150年代"人工水体微型生态系统"（见GS-3150-01）的延伸段，后因两系定居点扩张，该段管道恰好位于两系行政边界。水体中既有地球来源的鱼类与植物，也有第四恒星系驯化物种（见GS-3115-01、GS-3123-01）。共管处成立以管理这一跨系共栖水体。

## 二、水体现状

| 项目 | 状态 |
|---|---|
| 长度 | 40公里加压透明管道 |
| 水体体积 | 约12万立方米 |
| 生物组成 | 地球鱼类3种、地球植物12种、第四恒星系驯化作物4种、本地微生物群落 |
| 行政归属 | 中段10公里为两系边界，两侧各15公里分属两系 |
| 生态稳态 | 自3190年代以来基本稳定（见GS-3150-01） |

## 三、共管机制

1. **联合监测**：两系生态站各出2人，每月联合巡检一次，数据共享。
2. **水质标准统一**：水温、含氧量、pH按两系中较严者执行。
3. **不跨界捕捞**：任何一方不得在边界段10公里内捕捞，仅监测。
4. **病害联防**：若一方发现真菌或病原（见GS-3131-01、GS-3183-01），48小时内通报对方，联合处置。
5. **决策权**：日常运行由两系生态站自行协商；涉及水体结构改造，须跨系生态共管处批准。

## 五、与资源争端的关系

该水体管道下方的富冰小行星（见GS-3326-01）曾因归属争议，一度影响水体维护——争议方担心对方借维护之便占用小行星。共管处明确：水体共管与小行星归属是两回事，水体维护不因资源争端中断。

## 六、遗留

- 第四恒星系驯化作物在边界段是否自然扩散至三恒星系侧，需三年观测。
- 若扩散，按GS-3309-01迁徙伴生物种检疫口径评估。
- 本共管不涉及第五恒星系方向——该方向无水体管道。

两系按水体长度分摊：三恒星系侧60%，第四恒星系侧40%。

## 七、争议上报

共管双方若对水质标准有分歧，先协商30日；不成，报跨系生态共管处裁定。本年度无分歧上报。共管处说明："水体不认行政线，只认连通。我们按连通管，不按线管。"

## 八、与气候控制的区别

比邻星b全球气候控制（见GS-3182-01）是行星级工程；本水体是40公里加压管道。共管处说明："我们管的是一段管子，不是一颗行星。别把事做大。"

## 九、监测数据公开

水质监测数据每季度公开，供生态学派研究。共管处说明："水是大家的，数据也是大家的。"
