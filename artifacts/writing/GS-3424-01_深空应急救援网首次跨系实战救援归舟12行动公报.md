# 深空应急救援网首次跨系实战救援"归舟-12"行动公报

![图注：3424年8月8日 · 救援船抵近遇险货船 · 封闭金属船体 · 单一恒星直射 · 档案体](../../world/生图集/924.webp)

**发布机构**：联合体安全协调委员会深空救援处
**发布日期**：3424年8月8日
**行动代号**：归舟-12

## 一、遇险概况

3424年7月30日，跨系货运船"远穗-11"在第四恒星系方向距母港1.2亿公里处，主推进器局部故障，船速降至维持姿态。船上载员6人，货柜28柜，无伤亡。7月30日22:14，救援网接到求救信号，启动一级响应。

## 二、行动时间线

| 时刻（中继港标准时） | 行动 |
|---|---|
| 7月30日22:14 | 收到求救，启动一级响应 |
| 7月30日22:44 | 第二救援母港救援船"救-03"出动 |
| 7月31日08:00 | "救-03"抵达遇险船附近，建立通信 |
| 7月31日09:30 | 两名救援人员出舱对接"远穗-11" |
| 7月31日11:00 | 确认6人安全，货柜无泄漏 |
| 7月31日14:00 | 救援船牵引"远穗-11"缓慢返航 |
| 8月2日06:00 | 抵达第四恒星系方向救援母港 |
| 8月2日10:00 | 6人下船，体检无异常 |

## 四、行动评估

| 项目 | 评估 |
|---|---|
| 响应时间 | 30分钟内出动，符合一级标准 |
| 通信延迟 | 48秒，救援流程已适应 |
| 救援船性能 | 第七代生保闭环（见GS-3375-01）运行正常 |
| 牵引对接 | 一次成功，无第二次尝试 |
| 人员安全 | 救援人员无伤亡 |

## 五、经验与不足

**经验**：

1. 救援网第一代组网（见GS-3416-01）后首次实战，流程顺畅；
2. 救援船封闭加压船体完整，出舱对接一次成功；
3. 通信延迟48秒下，本地自主决策有效。

**不足**：

1. 救援船牵引功率略低于设计预期，返航速度比预计慢6小时；
2. 第六名船员有轻微焦虑症状，救援船心理支持预案不足；
3. 救援费用280万，由遇险船所属公司承担，保险理赔流程尚待完善（见GS-3438-01）。

归舟-12为救援网第一代组网后首次跨系实战，6人全部生还。救援处注明：第一次实战，6人回来，这是制度的胜利，不是运气。下一程，希望不用再出动。
