# 跨星系文明多样性遗产旅游配额与收益分成首年决算报告

![图注：遗产旅游中继站观览窗 · 远处穹顶定居点 · 单一恒星光 · 档案体](../../world/生图集/821.webp)

**编制单位**：联合体跨星系文化委员会 · 遗产旅游处
**报告编号**：CUL-TOUR-3321-007
**日期**：3321年8月14日
**文件等级**：跨星系公开

## 一、背景

《跨星系文化遗产保护公约》（见GS-3159-01）与《文明多样性保护名录》（见GS-3317-01）建立后，部分已入名录的民俗、技术、口述史点具备旅游价值。文化遗产产业（见GS-3162-01）与考古旅游（见GS-3170-01）此前已有规范，但未针对"文明多样性"点设配额。本报告为3320—3321年度遗产旅游配额与收益分成决算。

## 二、配额与准入

| 旅游点 | 年配额（人次） | 准入条件 |
|---|---|---|
| 第四恒星系"锚定夜"仪式点（见GS-3105-01） | 1200 | 提前一年预约，不现场售票 |
| 比邻星b ARK船骸发掘区（见GS-3158-01） | 800 | 须有考古学背景或随队 |
| 鲸鱼座τ星地下城口述史点（见GS-3145-01） | 1500 | 仅听口述，不采访口述者 |
| 名录刻石厅（见GS-3320-01） | 每年开放一日，不另配额 |
| 濒危语言村落 | **不开放** | 见GS-3317-01第五条 |
| 第五恒星系方向 | **不开放** | 见GS-3303-01 |

## 三、首年决算

| 项目 | 金额（星元） |
|---|---|
| 门票总收入 | 1280万 |
| 接待与导览成本 | 540万 |
| 收益分成给东道主社区 | 510万（40%） |
| 上缴联合体文化保护基金 | 230万（18%） |
| 净盈余 | 0（分成后收支平衡） |

收益分成原则：遗产旅游收入不用于财政，40%返东道主社区，18%入文化保护基金，余42%覆盖接待成本。

## 四、限制

1. **不商业化**：不设纪念品商店、不设美食街、不设打卡点。
2. **不打扰东道主**：旅游团不进入居民日常居所，仅走指定观览路线。
3. **濒危语言村落不开放**：见GS-3317-01第五条，避免博物馆化。
4. **第五恒星系方向不开放**：接触期不旅游。
5. **不拍照**：口述史点与仪式点禁止拍照，保护口述者隐私。

## 五、与既有产业衔接

- 与"边疆研学游"（见GS-3142-01）分账：研学游为教育，遗产旅游为观览，不混。
- 与文物修复产业（见GS-3162-01）联动：遗产旅游收入部分用于文物修复。
- 与数字版权平台（见GS-3177-01）无关——遗产旅游不售数字内容。

## 七、不开放清单

以下地点明确不开放旅游：

- 濒危语言村落（见GS-3317-01）。
- 第五恒星系方向（接触期，见GS-3303-01）。
- 名录刻石厅非开放日（见GS-3320-01）。
- 任何在世口述史提供者的居所。

遗产旅游处说明："看别人的生活，要有边界。不是所有东西都该被看。"

## 八、投诉与监督

游客若投诉导览越界、拍照被默许等，可向遗产旅游处申诉。首年收到投诉3起，均为游客要求拍照被拒后投诉——经复核，拒绝正确，不予支持。

## 九、收益分成

门票收入40%返东道主社区，18%入文化保护基金，42%覆盖接待成本。遗产旅游处说明："看别人的地方，钱要留给那个地方。"

## 十、不设纪念品

不售纪念品、不设美食街。遗产旅游处说明："看完就走，别带走什么。"
