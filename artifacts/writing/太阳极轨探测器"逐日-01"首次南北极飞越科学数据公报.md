# 太阳极轨探测器"逐日-01"首次南北极飞越科学数据公报

**发布单位**：国家空间科学中心 · 太阳极轨探测项目科学团队
**公报编号**：SPO-ZR-2051-001
**发布日期**：2051年8月22日

---

## 一、任务概况

太阳极轨探测器"逐日-01"（Solar Polar Orbiter，简称SPO-01）于2047年9月从地球发射，经两次地球引力助推（2048年12月、2049年11月）和一次木星引力助推（2050年6月），将轨道倾角提升至78.5°，进入太阳极轨。2051年7月14日完成首次太阳北极飞越（近日点0.28 AU），2051年8月15日完成首次太阳南极飞越（近日点0.31 AU）。本公报发布两次飞越的首批科学数据。

| 探测器参数 | 数值 |
|---|---|
| 发射质量 | 1,850 kg |
| 科学载荷质量 | 320 kg（共8台仪器） |
| 供电 | 钚-238 RTG（额定功率280 W，任务末期210 W） |
| 通信 | X波段高增益天线，下行速率最高2 Mbps |
| 轨道倾角 | 78.5°（相对黄道面） |
| 轨道周期 | 约142天 |
| 近日点距离 | 0.28—0.32 AU |
| 远日点距离 | 约2.1 AU（小行星带内侧） |
| 设计寿命 | 5年（含2次木星助推后） |

## 三、首次北极飞越数据（2051年7月14日）

### 3.1 极区冕洞观测

紫外成像光谱仪在北极极冠区观测到一个面积约占北半球42%的巨大冕洞，比地面（黄道面视角）观测估计的面积大18%。冕洞边界呈现复杂的扇形结构，在极区中心附近存在多个小尺度（<5,000 km）的闭合磁结构嵌入开放磁场区。

| 冕洞参数 | 数值 |
|---|---|
| 冕洞面积（北半球占比） | 42.3% |
| 冕洞中心温度 | 约8.5×10⁵ K |
| 冕洞边界温度梯度 | 约2.1×10⁴ K/km |
| 开放磁通量 | 约3.2×10¹⁴ Wb |
| 小尺度闭合结构数量 | 17个（直径2,000—8,000 km） |

### 3.2 太阳风原位测量

在北极飞越期间（近日点0.28 AU），原位等离子体分析仪记录到高速太阳风（平均速度782 km/s），其速度比1AU处同纬度太阳风高约15%。太阳风成分中³He/⁴He比值为4.2×10⁻⁴，比低纬度太阳风高约3倍。

| 太阳风参数（北极近日点） | 数值 |
|---|---|
| 质子平均速度 | 782 km/s（范围690—865） |
| 质子数密度 | 142 cm⁻³（0.28AU处，未归一化） |
| 质子温度 | 2.8×10⁵ K |
| 阿尔法粒子占比 | 4.8% |
| ³He/⁴He比值 | 4.2×10⁻⁴ |
| 磁场强度 | 38 nT（平均），峰值62 nT |
| 磁场方向 | 径向为主，极区开放场线 |

## 四、首次南极飞越数据（2051年8月15日）

### 4.1 南北极不对称性

南极飞越时观测到的冕洞面积占南半球的28.7%，明显小于北极（42.3%）。南极极区磁场强度平均为29 nT，低于北极的38 nT。南北极太阳风速度差异较小（南极平均765 km/s），但南极太阳风的温度波动更大。

| 参数 | 北极 | 南极 | 差异 |
|---|---|---|---|
| 冕洞面积（半球占比） | 42.3% | 28.7% | -13.6% |
| 磁场强度（平均） | 38 nT | 29 nT | -23.7% |
| 太阳风速度（平均） | 782 km/s | 765 km/s | -2.2% |
| 太阳风温度（平均） | 2.8×10⁵ K | 3.1×10⁵ K | +10.7% |
| 高能粒子通量（>10MeV） | 1.2 p/cm²/s/sr | 2.8 p/cm²/s/sr | +133% |

### 4.2 南极高能粒子事件

南极飞越前3天（8月12日），探测器记录到一次持续约18小时的太阳高能粒子（SEP）事件，质子通量峰值达14.5 p/cm²/s/sr（>10 MeV）。射电频谱仪同时记录到III型射电爆发群，源区定位在南极冕洞东边界。高能粒子的方向性测量表明，粒子沿开放磁力线从南极冕洞加速区直接传播至探测器，传播路径长度约0.31 AU，延迟时间约22分钟。

## 五、初步科学发现

1. **极区冕洞面积被地面观测低估**：由于黄道面视角的投影效应，地面观测对极区冕洞面积的估计系统性偏低约15—20%。"逐日-01"的极轨视角首次给出极区冕洞的真实面积与拓扑结构。
2. **南北极磁场与冕洞显著不对称**：当前太阳活动周（第26周）上升期，北极磁场明显强于南极，冕洞面积北大于南。这种不对称性可能与太阳发电机的经向环流差异有关，需后续多个轨道周期的观测验证。
3. **极区高速太阳风的³He富集**：北极冕洞高速太阳风中³He/⁴He比值显著高于低纬度太阳风，提示极区开放磁场区的粒子加速与分离机制与低纬度存在本质差异。
4. **极区小尺度闭合磁结构**：在极冠开放磁场区内部发现17个小尺度闭合磁结构，这些"磁岛"可能是极区冕洞内部物质循环与能量耗散的重要通道，此前地面观测因分辨率不足未能识别。

## 六、数据发布与后续计划

- 本次飞越的原始数据（约1.2 TB）已通过深空网回传，经校准后将于2051年10月1日向全球科学界开放。
- 下一次北极飞越预计2051年12月4日，南极飞越2052年1月12日。
- 项目团队计划在2052年上半年完成首个完整太阳极轨周期（约142天）的数据集，召开首次科学成果发布会。
- 2053年计划启动"逐日-02"号探测器研制，目标轨道倾角90°（完全极轨），增加极区红外干涉仪与中微子探测器。
