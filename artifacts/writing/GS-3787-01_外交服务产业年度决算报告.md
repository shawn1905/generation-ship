# 外交服务产业年度决算报告（3752 年度）

**编制单位**：联合体深空外交署 · 后勤处
**编制日期**：3753年2月10日
**报告年度**：3752年度
**报告编号**：FOR-FIN-3753-028　本卷附证两件

兹将外交服务产业3752年度决算汇列如后。范围四项：驻"晶环"站使馆人员经费、馆舍维护费、通信费、交通费。交接单与台账附卷。

## 一、收支计数总表

| 项 | 3752年度（跨星系记账单位） |
|---|---|
| 人员经费 | 约四百八十万 |
| 馆舍维护费 | 约一百二十万 |
| 通信费 | 约八十万 |
| 交通费 | 约六十万 |
| **总支出** | **约七百四十万** |
| 财政拨款 | 约七百四十万 |
| 直接收入 | 无 |
| 人员社会保障支出 | 约三十万 |

外交服务产业无直接收入，全部支出由联合体财政拨款，支出与拨款基本持平。通信费占总支出约百分之十一。本年度总支出较上年增长百分之八，主要因新增两处常驻办事处。

社会保障约三十万，按联合体统一标准执行：医疗保险约十二万｜养老保险约十二万｜工伤保险约六万。

预计3753年度总支出约七百八十万，增加部分主要为新增两名文化处人员与通信设备更新。预计3754年度使馆人员增至十六人，馆舍面积维持不变，生命支持系统须扩容至十二人规模。
