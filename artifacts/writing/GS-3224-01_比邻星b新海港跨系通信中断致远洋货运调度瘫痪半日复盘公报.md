# 比邻星b新海港跨系通信中断致远洋货运调度瘫痪半日复盘公报

![图注：新海港调度室 · 中断期间人工白板与临时调度 · 档案体](../../world/生图集/724.webp)

**发布机构**：比邻星b新海港管理署
**事件日期**：3224年5月下旬
**发布日期**：3224年6月5日
**密级**：跨星系公开

## 一、事件经过

新海港为比邻星b最大远洋货运港，调度依赖跨系通信与罗盘系统（见GS-3028-01）。3224年5月26日，新海港跨系通信主链路因光频标节点（见GS-3209-01）一次维护切换失误而中断，备用链路亦因同一维护批次同时下线，致港口调度与跨系航道失联约五小时。期间停泊与装卸改以人工白板调度，未发生撞港，亦未发生坠货。

## 二、时间线

| 时刻 | 事件 |
|---|---|
| 5-26 08:20 | 主链路维护切换，新海港调度失联 |
| 5-26 08:25 | 发现备用链路同批下线，无冗余 |
| 5-26 08:40 | 启动人工白板调度，暂停远洋班轮进出 |
| 5-26 10:00 | 切换至第三应急微波链路，部分恢复 |
| 5-26 13:10 | 主链路修复，全量恢复 |
| 5-26—6-05 | 复盘整改 |

## 三、原因初查

主因是维护切换计划未作"主备不同批"安排，致两链路同批维护、同批下线。新海港虽有人工调度预案，然远洋班轮进出港指挥仍以电子屏为主，白板调度仅维持基本秩序，未能恢复正常效率。

## 四、整改措施

1. 跨系通信主备链路维护必须错开批次，严禁同批下线；
2. 港口另设第三应急独立链路，与主备物理隔离；
3. 人工白板调度预案每半年演练一次，本次瘫痪即暴露演练不足；
4. 对维护切换责任人依公务员考绩法（见GS-3052-01）处理；
5. 半日瘫痪致货运班轮延误约十一艘，经后续加密班次追回，未影响跨系供应链。

## 五、无伤亡说明

本事件未致人员伤亡，未致船只碰撞。然半日调度瘫痪已暴露"一切依赖电子屏"之脆弱。新海港管理署强调：人在回路，不可全交机器。

## 六、港口冗余改造

事故后，新海港除另设第三独立微波链路外，另在调度楼设独立人工调度室，不依赖电子屏。远洋班轮进出港指挥改为"电子屏为主、白板为辅"，双轨并行。港口管理署说明：半日瘫痪暴露的不是机器的问题，是人把机器当成了全部。

## 七、港口冗余改造

事故后新海港除另设第三独立微波链路外，另在调度楼设独立人工调度室，不依赖电子屏。远洋班轮进出港指挥改为"电子屏为主、白板为辅"，双轨并行。港口管理署说明：半日瘫痪暴露的不是机器的问题，是人把机器当成了全部。

## 八、对"一切依赖电子屏"之反思

新海港管理署强调：半日瘫痪暴露"一切依赖电子屏"之脆弱。远洋班轮进出港指挥改为"电子屏为主、白板为辅"，双轨并行。后续加密班次追回延误，未影响跨系供应链。

## 八、人不交出全部

新海港管理署强调：半日瘫痪暴露的不是机器的问题，是人把机器当成了全部。远洋班轮进出港指挥改为电子屏为主、白板为辅，双轨并行。后续加密班次追回延误，未影响供应链。
