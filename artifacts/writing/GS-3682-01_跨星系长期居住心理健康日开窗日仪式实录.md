# 跨星系长期居住心理健康日开窗日仪式实录

![图注：3682年 · 档案体](../../world/生图集/1182.webp)

**实录机构**：心理学总站
**仪式日**：3682年6月1日　**举行范围**：三系各舱段同时
**卷宗号**：开窗-3682-01
**附件**：开窗率统计表一件、广播词抄件一件（均随本实录装订）

## 一、广播词抄件（播音室存，照录）

> "今日为心理健康日开窗日，请于十时开窗望外三十分钟。"

抄件一页，右上角有总站广播提醒编号，播音员签认（略）。三系各舱段广播同步，开窗期间无广播干扰。

## 二、四步双签单（存根照录）

| 步 | 事项 | 时刻 | 舱段值班员签 | 总站值班签 |
|---|---|---|---|---|
| 一 | 心理学总站广播提醒 | 3682-06-01 10:00 | ✓ | ✓ |
| 二 | 居民开窗 | 3682-06-01 10:05 | ✓ | ✓ |
| 三 | 望外三十分钟 | 10:05—10:35 | ✓ | ✓ |
| 四 | 关窗 | 3682-06-01 10:35 | ✓ | ✓ |

全程四步，均双签。第三步签名落在关窗之后——三十分钟里，签单在值班台上摊着，没人动笔。

## 三、开窗率统计表（附件之一，照录）

| 项 | 计数 |
|---|---|
| 当日开窗率 | 百分之九十二 |
| 未开窗 | 百分之八，多为值班人员 |
| 参与 | 全体居民均可参与，不强制 |
| 计数依据 | 各舱段居民名册与值班表逐段勾选，汇总于总站 |

未开窗者的值班表在册，逐段勾注事由，附卷。

## 四、仪制一行

开窗日为心理学总站（见GS-3655-01）首年推行之仪式，为缓解密闭舱居倦怠（见GS-3676-01）而设。此前两代心理学站未设开窗日。

## 五、封存与范本

原件封存于心理学总站恒温柜组，柜位有编号；副本分发各舱段，各舱段收文登记簿逐件签认。本实录为心理健康日开窗之基准件，后续年度以本实录为范本。开窗率百分之九十二，为心理学总站首年成效。

> 总站注：百分之八未开窗，值班表在册。本仪式不强制，故不追问，只记数。四步双签齐备，归档。
