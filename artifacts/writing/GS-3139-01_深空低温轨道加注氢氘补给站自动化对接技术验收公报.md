# 深空低温轨道加注氢氘补给站自动化对接技术验收公报

![轨道补给站 · 主站轨道段 · 加注臂与对接端口](../../world/生图集/639.webp)

**编制单位**：拓荒委员会工程处
**公报日期**：3139年4月26日

## 一、背景

新拓站水冰异常区（GS-3103-01）经加工，可产氢氘推进剂。为降低跨星系运费（GS-3114-01），在新拓站轨道设低温加注补给站，供过往货运艇就地补燃料。

## 二、技术要点

补给站为封闭加压工业舱，带低温储罐、加注臂、对接端口。自动化对接：

1. 货运艇接近后，由补给站自动识别对接标记；
2. 加注臂自动伸出对接；
3. 加注过程无人操作，由艇方与站方双确认；
4. 加注完毕自动断开。

## 三、验收

3139年3月至4月，补给站完成12次自动对接试验：

| 项目 | 结果 |
|---|---|
| 对接成功率 | 12/12 |
| 加注泄漏 | 0 |
| 对接时间 | 平均18分钟 |
| 无人操作 | 是 |

## 四、效益

补给站投运后，新拓—太阳系航段货运艇不必从太阳系带满燃料来新拓，运费占铂矿货值比例由14%降至11%（GS-3114-01预期）。

## 五、附则

本补给站为工业设施，不载客。自动化对接为辅助，艇方仍有最终决定权。
