# 口述史数字化与有声记忆产业3515年度决算报告

![图注：有声记忆产业演播与录制舱 · 任务日 · 档案体](../../world/生图集/1016.webp)

**编制单位**：三恒星系文明联合体经济产业署
**报告年度**：3515年
**发布日期**：3516年5月20日
**文件等级**：跨星系公开

## 一、产业范围

口述史数字化与有声记忆产业承接文明记忆产业（见GS-3376-01），包括：第四代采集舱运营（见GS-3511-01）、口述条目入库与去伪（见GS-3534-01）、有声记忆产品制作、有声档案借阅。本产业与口述史捐献制度（见GS-3536-01）配套。

## 二、年度决算

| 项目 | 金额（亿星汇） | 占比 |
|---|---|---|
| 采集舱运营 | 9.2 | 31% |
| 去伪存真与入库 | 6.7 | 23% |
| 有声记忆产品制作 | 5.1 | 17% |
| 有声档案借阅 | 3.8 | 13% |
| 技术研发 | 2.4 | 8% |
| 跨系运输 | 2.3 | 8% |
| 合计 | 29.5 | 100% |

## 三、服务量

| 指标 | 3514年 | 3515年 |
|---|---|---|
| 采集条目（万） | 1560 | 1700 |

| 有声记忆产品（部） | 120 | 187 |
| 借阅人次（亿） | 3.2 | 4.7 |

## 四、产业特征

经济署注明：口述史捐献是自愿的，但把这些话录下来、存起来、做出来给人听，是要花钱的。29.5亿星汇，买的是"普通人的话有人录、有人存、有人听"。这事不赚钱，但它是文明记忆工程的门面。

## 五、捐献与商业的边界

捐献条目本身不收费（见GS-3536-01）；商业有声记忆产品经继承人授权后制作，收益分成。经济署注明：老人说话不赚钱，把话做成专辑卖钱，那是另一回事，得先问他家里人。

## 六、就业

本产业直接从业约8.4万人，其中采集员3.8万、去伪存真1.2万、产品制作1.5万、运输与运营1.9万。

## 八、成本结构

| 项 | 占比 |
|---|---|
| 采集与降噪 | 38% |
| 封存舱与备份 | 29% |
| 口述史版权清算 | 15% |
| 开放检索与导览 | 10% |
| 其他 | 8% |

经济署注明：这门产业最大的开销是录和存，不是卖。录进去、存起来，就花掉七成。剩下三成用来让后人找得到它。

## 九、不向听众收费

开放检索对个人不收费。经济署注明：老人的话不是商品。谁想听，来库里听，不收钱。收费的是商用改编，不是听本身。

## 十、经济署注

29.5亿，换1700万条话。这账不算经济账，算记忆账。记忆这东西，平时看不见，等看不见的时候就晚了。下一年，继续录。话比钱值钱。

## 八、产品与捐献的边界

有声记忆产品收益，55%归捐献人或继承人，30%入文明记忆基金（见GS-3393-01），15%归制作方。经济署注明：不能让录话的人吃亏，也不能让录话变成赚钱生意。分成是个平衡。

## 九、借阅人次与真实听众

借阅4.7亿人次中，纯音频聆听占6成，配字幕观看占4成。经济署注明：老人说话，年轻人戴着耳机听。听不进去另说，至少戴上了。

## 十、产业的天花板

本产业不设营收指标。经济署注明：记忆产业不像别的产业，不能催它涨。话是慢慢录的，人是慢慢说的。我们不冲业绩，只守着录。


## 十一、有声记忆的边界
经济署在决算末尾说明：本产业只做录和存，不做改编、不做配乐、不做播客。经济署注明：老人的话不是素材，不是故事原料。把它配上音乐剪成节目，就变成别人的了。我们只存原话，不二次创作。


## 十二、产业的不扩张
经济署在决算附记中说明，本产业近五年收入平稳，未随文化热扩张。经济署注明：录话这门生意，不能靠多录赚钱。老人就那么多，他们的话就那么多。录完了，就录完了。产业守着存量，不做增量文章。


## 十三、产业的克制
经济署在决算附记中说明，本产业拒绝了三次将口述史改编为播客的商业提案。经济署注明：老人的话不是节目素材。可以听，可以存，不能剪。剪了配乐，就成了别人的故事。


## 十四、有声记忆的边界
经济署在决算附记中说明，本产业不做有声书、不做广播剧。经济署注明：老人的话不是读物。它是档案。档案不改编，不演绎。


## 十五、产业的慢
经济署在决算附记中说明，本产业近五年收入年增不到百分之二。经济署注明：录话不能赶，赶了就假。这门产业慢，慢得对。
