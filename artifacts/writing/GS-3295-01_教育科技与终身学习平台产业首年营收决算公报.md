# 教育科技与终身学习平台产业首年营收决算公报

![图注：教育科技与终身学习平台产业首年营收决算公报 · 任务日 · 多层教育平台终端](../../world/生图集/795.webp)

**编制机构**：三恒星系文明联合体经济与产业协调署
**文号**：经产署公字〔3295〕第〇四七六号
**编制日期**：3295年3月28日
**文件等级**：跨星系公开
**会签**：教育学派议事会

## 一、决算背景

自3265年《终身学习与能力分段认证制度》（见GS-3265-01）与3267年开卷节（见GS-3267-01）以来，终身学习体系已运行三十年。3294年1月1日起，教育科技与终身学习平台首次作为独立产业板块核算。本决算核算首年（3294全年）营收规模。

## 二、产业规模

| 产业板块 | 首年营收(亿贡献工时指数) | 平台数 |
|---|---|---|
| 能力认证辅助平台 | 481.2 | 412 |
| 教学资源共享平台 | 312.6 | 876 |
| 同行评审协作平台 | 206.4 | 312 |
| 口述史录制协助平台 | 96.4 | 186 |
| 跨星系异步学习平台 | 124.8 | 124 |
| **合计** | **1,221.4** | **1,910** |

## 三、用户规模

| 项目 | 数值 |
|---|---|
| 注册用户(亿) | 48.1 |
| 月活跃用户(亿) | 21.4 |
| 段二以上认证用户(见GS-3265-01) | 8.94 亿 |
| 教师/评审专家用户 | 0.89 亿 |

## 四、与既有制度衔接

- 本产业不替代3265年终身学习制度（见GS-3265-01）：平台为制度执行工具，非制度本身。
- 平台上教学资源共享为意义工时登记的一类（见GS-3258-01）。
- 与3266年首任课程督学程知返档案（见GS-3266-01）相关：其为制度执行人事侧写。

## 五、问题

经济署监测到两类问题：

1. **平台垄断风险**。能力认证辅助平台中，头部三家占市场份额78%，存在垄断风险。应对：反垄断审查。
2. **跨星系延迟**。跨星系异步学习平台受往返延迟四年限制，实时互动课程不可行。应对：跨星系学习以异步录制、年度集中面授为主。

## 六、平台治理细则

经济署会同教育学派议事会，对首年平台执行以下治理细则：

| 治理项 | 细则 | 执行率 |
|---|---|---|
| 平台备案 | 全部1,910家平台完成备案 | 100% |
| 数据本地化 | 用户学习数据须存储于用户所在定居点 | 98.2% |
| 跨星系数据镜像 | 备案平台须接受年度跨星系数据镜像(见GS-2500激光平准) | 96.4% |
| 平台抽成上限 | 意义工时服务经平台结算，抽成不得超过5% | 100% |
| 用户数据可携权 | 用户可随时导出全部学习记录 | 100% |
| 未成年人保护 | 16岁以下用户须经监护人同意方可注册 | 100% |

## 八、附则

本决算作为教育科技产业监管依据。涉及平台垄断审查的具体方案，由经济署会同法学派议事会另行制定，不迟于3296年第三季度发布。跨星系异步学习平台的实时互动课程限制，由教育学派议事会另行制定实施细则。

## 补充说明

教育科技产业的首年营收，在旧时代会被解读为"教育产业化"的胜利。但经济署在决算里强调：这个产业不替代终身学习制度，它只是制度的执行工具。平台上的教学资源是意义工时登记的一类，平台抽成被限制在百分之五以内，用户数据可以随时导出。这些约束不是事后追加的，而是产业从一开始就被设计在框架里的。一个教育产业如果不能保证它的数据可携、它的抽成克制，它就会在一代人之后变成一个比旧学历更坚固的牢笼。
## 教育产业延伸
教育科技与终身学习平台产业首年营收决算，在数字之外还附了一份”平台用户数据可携性审计”。审计显示：全部头部平台均允许用户一键导出全部学习记录与认证数据，导出格式为开放标准。这一可携性是教育产业从一开始就被设计进框架的约束。经济署提示：一个教育产业若不能保证数据可携，它就会在一代人之后变成一个把人的学习经历锁死在平台里的封闭系统。
