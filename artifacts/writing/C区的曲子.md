# C 区的曲子

> 世代飞船 ARK-01 · 启航第 137 年 · 短篇

工单是早上到的:**C 区,3 号泵房,扬声器,音质异常。**

阿留看了两秒。又是 3 号泵房。这半年她已经在同一面墙上换了三只扬声器——不是扬声器不行,是 3 号泵房那台老循环水泵,运转声总往墙里渗,把音乐震得发毛。她合上工单,背上工具包,顺路在食堂窗口多拿了一个饼。

船上最后一个音响管理员,岗位编号还是第一代传下来的:**AUD-001**。启航时这个岗有四个人,管着全船十七个舱段的环境音乐。现在只剩她一个,管着还能响的九个。

不是没人听。是没人再把它当音乐了。

C 区是农业环。137 年前,设计师给这里配的曲子,是启航前就去世的一位地球作曲家写的——据说他写的时候,谱面上标注的不是节拍,而是"给植物的节奏"。曲子很慢,一圈一圈地转,像灌溉的水。现在它还在转,只是转了 137 年,转出了自己的毛病:音高漂着,回声拖得忽长忽短,偶尔还丢一个音,像水泵喘气。

舱里没人觉得这是毛病。种土豆的人听着它,说那是"C 区的脾气"。

阿留第一次听到这句话,是在第 133 年的维修例会上。机务主管说,3 号泵房的音乐"又犯脾气了",大家笑。她跟着笑完,回去调了系统日志——那条"脾气",是 28 年前一次继电器老化留下的,当时没人修,后来修了,修的师傅顺手把延时参数调过一档,再后来,又一任师傅把音高补偿关掉,说"反正也没人听得出来"。

137 年,每一任师傅都只动了一点点。动完都觉得"没人在意"。

她走进泵房,果然,音乐又"犯脾气"了。她没急着换扬声器,先站在墙边听了一会儿。曲子走到第三小节,那个熟悉的顿挫又来了——像谁在拍子上轻轻绊了一下,然后若无其事地继续走。她听了 137 年……不,她只听了 31 年。但她听得出来,这个绊,现在是这首曲子的*一部分*了,就像泵房墙上的水渍,谁都见过,谁都不觉得碍眼。

她正要拆扬声器,通讯器响了。

档案室的老周:"阿留,你来一趟,有东西给你看。"

档案室在 A 区,和 C 区隔了大半个环。她到的时候,老周正对着一台老式读盘机搓手——那东西 137 年没通电了。

"整理储藏区翻出来的,"老周说,"地球备份卷,第一代。系统识别出来,里面有一段音频,标注是'C 区-原版环境音乐'。"

他顿了顿,声音放低:"原版。你听听?"

读盘机转起来,发出旧机械特有的、谨慎的声音。然后——

音乐响起来。

阿留站在原地,没动。

这首曲子,她太熟了。她闭着眼都能画出它的脾气:哪里会漂,哪里会拖,哪里会绊一下。可此刻从读盘机里流出来的这个版本,没有漂,没有拖,没有绊。每一个音都站在它该站的位置上,准得像图纸。像……像新出厂的东西。

好听吗?好听。干净得让人不敢呼吸。

可她觉得陌生。

老周说:"要把它放回去吗?给 C 区换回原版。这毕竟是……作曲家本人写的。"

阿留没接话。她走到读盘机旁边,蹲下来,看了很久。

她想,137 年前,那个作曲家写这首曲子的时候,想象过这艘船吗?他写的是给植物听的节奏。他大概以为,这艘船会永远按他写的来转——音高不漂,循环不错位,水泵不喘气。他写的是一个*设计*。

可船不是设计。

船是 137 年的每一天。是第一任音响员听着它入睡的第 1 年;是第 44 年那次大检修,师傅在日志里写"调了一档,反正没人听得出来";是第 89 年,农业组的小孩在泵房门口跟着它哼,哼走调了,妈妈没纠正;是 137 年来,每个把它的"脾气"当成日子一部分的人。

图纸上的曲子,是作曲家写的。

泵房里的曲子,是这艘船写的。

她站起来,把读盘机关了,声音断在最后一个音上,像泵房的那次"绊"——不,比那次干脆。那次绊完,曲子还会继续走。这次是真的停了。

"不放回去。"她说。

老周看着她。

"原版归档,"她听见自己说,"标注——'历史文件,不用于播放'。备份两卷,卷上写清楚:这是第 1 年的 C 区。船上响的那个,不是。"

她停了一下,又补了一句:"船上响的那个,才是。"

回 C 区的路上,她拐进 3 号泵房,把扬声器换了——照例换了只新的,也照例没动系统的任何参数。

音乐又响起来。音高还是漂着,回声还是忽长忽短,走到第三小节,还是绊那一下。她站在墙边,把饼吃完,听完了完整的一圈。

工单系统提示她填写完工记录。故障、处置、用料,她一项一项填完。在备注栏,她停了很久。

最后只写了一行:

**"3 号泵房的曲子,状态正常。别修。"**

她合上工具包。曲子还在响——绕着圈,一圈一圈,像灌溉的水,像 137 年来每一个照常响起的早晨。
