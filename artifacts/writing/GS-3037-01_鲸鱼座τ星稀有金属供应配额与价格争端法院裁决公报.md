# 鲸鱼座τ星稀有金属供应配额与价格争端宪法法院裁决公报

**发布机构**：宪法法院书记庭 / 跨星系贸易与产业部
**文件编号**：CON-3037-001　**日期**：3037年11月23日　**文件等级**：跨星系公开

鲸港稀有金属自2920年投产（见GS-2920-01），是其出口支柱。零关税区（见GS-3032-01）后，比邻星b与太阳系厂商大量采购鲸港金属。鲸港政府认为：金属被贱卖，三系厂商压价，鲸港"卖资源、没利润"，遂要求提高出口配额门槛与最低限价。比邻星b厂商反对：零关税刚自由，怎么又限价？

争端诉至宪法法院。

## 一、裁决要点

| 条款 | 内容 |
|---|---|
| 1 | 鲸港有权定"最低合理价格"，但不得借此囤积居奇、卡三系脖子 |
| 2 | 配额须在联合发展银行（见GS-2973-01）监督下公开，不搞暗箱 |
| 3 | 价格争端每年复议一次，按跨系供需动态调整，不锁死 |

## 二、首年执行数据表

| 指标 | 数值 |
|---|---|
| 出口均价（相对成本倍数） | 1.6倍 |
| 较零关税前变化 | +14%（从1.4倍） |
| 较鲸港最初要求 | -20%（鲸港要求2.0倍） |
| 三系厂商采购量变化 | +4% |
| 鲸港出口收入同比增长 | +18%（最低限价贡献11个百分点，采购量回升贡献7个百分点） |
| 三系工业企业采购成本变化 | +6% |

## 三、成本核算原行

> 成本核算表 · 3037
> 鲸港稀有金属开采成本：基准价P
> 跨系运费占成本比例：30%
> 若限价低于1.4倍P，鲸港实际在补贴三系工业
> 法院调取数据确认：成本结构合理，限价1.6倍P为平衡点
>
> 数据来源：联合发展银行监督下的独立价格委员会

## 四、首年复议记录（3038年）

| 项目 | 内容 |
|---|---|
| 复议时间 | 3038年 |
| 复议结果 | 最低限价较首年微调下调3% |
| 下调原因 | 鲸港金属开采成本下降，三系采购量稳定 |
| 双方异议 | 无 |

复议机制：价格委员会成员三系各出一人，不与争端双方有经济利害。

## 五、长期影响

裁决后三年，鲸港稀有金属供应链趋于稳定。三系厂商开始长期投资鲸港金属加工产能——因为价格可预期。两家依赖鲸港金属的比邻星b小厂因成本上升濒临倒闭，后经联合发展银行转产贷款转型为金属回收企业。

## 六、未裁决事项

法院未裁决"鲸港稀有金属是否应全部由鲸港自主定价"——那属于未来宪章修正案的范围。法院未裁决"鲸港稀有金属出口是否应逐步本地化加工"——这属于鲸港产业政策范畴。

## 七、岗位按语

> 贸易与产业部注：一次法院裁决，不能解决所有争端，但它把一个"随时可能翻脸"的供应，变成了一个"可以长期合作"的供应——这才是真正的价值。
