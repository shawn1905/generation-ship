# 跨星系航道安全与海盗残余清剿联合行动公报

![图注：跨星系航道安全与海盗残余清剿联合行动公报 · 任务日 · 档案体](../../world/生图集/679.webp)

**发布机构**：三恒星系文明联合体安全协调委员会
**发布日期**：3179年10月15日
**文件等级**：跨星系公开

## 一、行动背景

自2979年深空航道巡逻机制建立以来（见GS-2979-01），主要航道海盗活动已大幅减少。但3170年代以来，在第四恒星系方向的新开辟航道上，发现少量海盗残余活动。

## 二、行动经过

3179年6月至9月，联合体安全部队联合三恒星系巡逻力量，在第四恒星系方向新航道开展"清道夫行动"：

- 6月15日：发现海盗据点（废弃矿站）；
- 7月2日：封锁据点，逮捕海盗12人；
- 8月20日：剿灭残余两艘海盗船；
- 9月30日：行动结束。

## 三、战果

| 项目 | 数量 |
|---|---|
| 逮捕海盗 | 18人 |
| 缴获海盗船 | 3艘 |
| 解救被劫货物 | 约2,000吨 |
| 巡逻方伤亡 | 0 |

## 四、后续

第四恒星系方向航道巡逻站已部署，海盗残余已基本肃清。

## 续录一：施行细则与监督反馈

本公报所定事项自公布之日起施行。施行细则如下：

1. 各执行单位须于公布后30日内制定本单位实施方案，报主管部门备案；
2. 实施方案须列明责任人、时间节点、资源需求；
3. 主管部门每季度对执行情况作一次检查，检查结果书面通知执行单位；
4. 执行单位遇重大困难可申请延期，延期不超过6个月；
5. 本公报施行满一年后作首次评估，评估报告报上级部门。

监督反馈渠道：公民对执行情况有异议者，可通过主管部门公开信箱提交，30日内答复。本公报与相关既有法规交叉引用之处，以正文所列档案编号为准。本公报不溯及既往，施行前已发生的法律事实按当时法规处理。

## 附则补充：被俘人员移交与审判进度

逮捕海盗18人于3179年10月移交拓荒委员会司法处，依《跨星系公海纠纷仲裁法典》起诉。至本公报发布，已审结11人，其中8人判处航道作业限制、3人判处强制劳役；余7人审理中。缴获海盗船3艘经鉴定无军事物资，2艘拆解回收、1艘移交巡逻站作训练艇。解救货物约2,000吨已全部发还原主。
