## 第一部分：建成公报

### 一、工程概况

"天青-01"深空测控与氦-3前哨站于2096年3月启动在轨建造，历时4年3个月，于2100年6月10日完成全部模块对接与系统联调，6月15日通过竣工验收。前哨站位于天王星同步轨道（距天王星中心约105,000 km，轨道周期17.24小时），是人类在天王星系统部署的首座永久性综合前哨设施，承担三大核心功能：（1）外太阳系深空测控与通信中继；（2）天王星大气氦-3采集产品的精炼、储存与中转；（3）天王星系统探测任务的人员驻留与后勤补给枢纽。

### 三、测控与通信能力

天青-01的35 m深空测控天线采用X/Ka双波段设计，X波段（8.4 GHz上行/7.2 GHz下行）用于深空探测器的遥测遥控，Ka波段（32 GHz下行）用于高速数据回传。天线指向精度0.001°，可同时跟踪3个深空目标。

测控覆盖范围：以天王星为中心，半径50 AU球域内的深空探测器均可实现测控支持，覆盖海王星系统（距天王星约11 AU）、柯伊伯带内侧（距天王星约10—30 AU）及部分内奥尔特云探测器。

通信中继功能：前哨站配备星载交换机，可实现地球—天王星—海王星—柯伊伯带探测器之间的数据包中继，单程延迟累加（地球→天王星2h41m，天王星→海王星约1h30m）。

---

### 四、氦-3精炼与中转

天王星大气氦-3采集由"凌云"系列浮空采集平台执行（2056年首航，至2100年已部署4个平台），采集的粗产品（氦-3含量约0.5%，其余为氦-4与微量甲烷）由全封闭加压金属船体转运驳船送至天青-01，经低温蒸馏精炼机组提纯至99.99%。

精炼工艺：粗氦气经压缩机加压至2 MPa，进入预冷换热器（利用液氦冷源冷却至30 K），随后进入三级低温蒸馏塔（工作温度4.2—3.2 K），利用氦-3（沸点3.19 K）与氦-4（沸点4.23 K）沸点差分离，塔顶收集氦-3产品，塔底排出氦-4（作为副产品出售，用于低温冷却与飞艇浮力）。

2100年Q2试生产数据：累计处理粗氦气1,240 m³（标准状态），产出氦-3产品1.82 kg，纯度99.993%，回收率87%，达到设计指标。

## 第二部分：极寒环境运维规程

### 五、环境参数与运维挑战

天王星同步轨道环境参数：

| 参数 | 数值 |
|:---|:---|
| 太阳辐照度 | 约3.7 W/m²（地球的0.27%） |
| 环境温度（阴影面） | -223°C（50 K） |
| 环境温度（日照面） | -185°C（88 K） |
| 天王星反照率辐照 | 约0.8 W/m² |
| 宇宙线剂量率 | 约0.3 mSv/h（银河宇宙线主导，太阳风极弱） |
| 微陨石通量 | 约0.05次/m²·天（>0.1 mm） |
| 天王星辐射带 | 极弱（天王星磁场轴偏移大，辐射带不显著） |

核心运维挑战：（1）极低温导致材料脆化与润滑剂凝固；（2）极低太阳辐照导致太阳能完全不可用，全靠裂变堆；（3）设备散热温差极大（舱内293 K vs 外部50 K），热管理复杂；（4）单程通信延迟2小时41分，无法实时遥控，需高度自主运行。

### 六、极寒环境运维核心规程

#### 6.1 材料与润滑剂管理

1. 所有外部活动部件（天线指向机构、桁架对接机构、舱门铰链）必须采用低温韧性材料（钛合金Ti-6Al-4V ELI、奥氏体不锈钢316L、因科镍718），禁止使用体心立方结构钢（低温脆化）。
2. 外部轴承与齿轮采用固体润滑（二硫化钼溅射涂层+聚四氟乙烯基润滑脂，工作温度范围40—350 K），禁止使用常规矿物油润滑（50 K下完全凝固）。
3. 每季度对外部活动部件进行一次全行程运动测试，记录驱动力矩变化，力矩增长超过20%时安排预防性维护。

#### 6.2 热管理规程

1. 前哨站采用"多层隔热毯（MLI）+主动电加热+液滴辐射器"三级热管理体系。MLI覆盖所有非散热表面（层数40层，面密度1.2 kg/m²），被动漏热控制在50 W/m²以下。
2. 所有外部设备与管道均配备电伴热（额定功率20—100 W/m，根据设备温度需求分级），由站控系统自动调节，维持设备温度在设计下限以上（电子设备≥233 K，机械设备≥200 K，推进剂管道≥250 K）。
3. 液滴辐射器仅在裂变堆满功率运行时展开，散热功率与堆功率匹配。裂变堆降功率运行时，对应辐射器组收回（减少漏热）。
4. 居住舱与设备舱之间设置气闸式热隔离过渡段，人员进出时温差不超过50 K/分钟，防止热冲击。

#### 6.3 电力与裂变堆运维

1. 3台裂变堆采用"2运行+1备用"模式，正常运行时2台并网供电（24 MWe），1台热备用（可在30分钟内并网）。单堆检修时，备用堆顶上，确保供电不中断。
2. 裂变堆每18个月进行一次计划内停堆检修（更换控制棒、检查堆芯冷却剂回路、校准核测量仪表），检修期间由另外2台堆供电（需降负荷至20 MWe，部分非关键设备暂停）。
3. 极寒环境下裂变堆冷却剂（钠钾合金NaK-78，凝固点260 K）必须始终保持流动，停堆检修期间采用辅助电加热维持回路温度≥280 K，防止冷却剂凝固。
4. 每6个月对液滴辐射器进行一次 droplet generator 检查，清理堵塞的喷嘴（极寒下残留工质凝固可能导致堵塞）。

#### 6.4 氦-3低温系统运维

1. 氦-3精炼系统工作温度3.2—4.2 K，是全站温度最低的子系统。低温蒸馏塔采用真空多层绝热（VMLI），漏热控制在5 W以下。
2. 液氦冷源由站内氦液化器提供（液化能力50 L/h），氦-4副产品作为液化器工质循环使用。氦液化器每季度检修一次（更换膨胀机活塞、清理换热器）。
3. 氦-3产品气瓶储存区温度控制在293 K（室温），压力30 MPa。气瓶每5年进行一次水压试验（试验压力45 MPa），每10年更换气瓶（金属疲劳寿命限制）。
4. 氦-3泄漏检测：精炼系统每日进行一次氦质谱检漏（灵敏度10⁻⁹ Pa·m³/s），发现泄漏立即隔离泄漏段并修复。氦-3为贵重资源（2100年市价约120万信用单位/kg），泄漏损失需专项记录。

#### 6.5 人员驻留与轮换

1. 常驻人员64人，八班四运转，每班8人，工作6小时/班。驻留周期180天，到期轮换（由补给飞船接送，单程约3年，故实际轮换周期与补给周期绑定，约每2—3年轮换一批）。
2. 驻留期间健康监测：每日记录体重、血压、心率、骨密度（每周一次，DEXA扫描）、视力（每两周一次）、心理状态（每周一次，自主填写抑郁焦虑量表+每月一次与地球心理医生视频咨询，延迟2h41m）。
3. 人工重力旋转段每日使用时间不少于16小时（睡眠+用餐+休闲），工作时段（微重力区）每2小时进行一次15分钟人工重力暴露（进入旋转段短暂停留），以减缓骨质流失与肌肉萎缩。
4. 辐射剂量管理：全站人员年累计辐射剂量不超过500 mSv（前哨站内部剂量率约0.15 mSv/h，年累计约1,314 mSv，需通过屏蔽与时间分配控制——人员在核心屏蔽区（居住舱，剂量率0.05 mSv/h）停留时间不少于80%）。

#### 6.6 应急处置规程

1. **裂变堆失效**：3台堆同时失效概率极低（<10⁻⁶/年），但若发生，立即启动RTG备用电源（10×500 W RTG，总功率5 kW），维持关键系统（生命维持、通信、低温系统保温）运行，非关键系统全部关闭。RTG可维持关键系统运行约30天，期间需紧急修复至少1台裂变堆。
2. **居住舱失压**：立即关闭泄漏舱段隔离阀，人员撤离至相邻加压舱。失压舱段由维修人员着舱外航天服修复（极寒环境下舱外活动时间不超过30分钟/次，航天服主动加热功耗800 W）。
3. **氦-3大量泄漏**：立即关闭精炼系统进出口阀门，启动站内氦回收系统（将泄漏氦气抽回储气罐）。氦-3无毒不可燃，但为贵重资源，泄漏量需精确计量并上报。
4. **微陨石撞击**：前哨站外壳为蜂窝夹层结构（铝锂合金面板+铝蜂窝芯，总厚度80 mm），可抵御1 mm以下微陨石高速撞击。>1 mm撞击导致穿孔时，立即启动舱内压力监测，定位穿孔位置，由维修人员从内部封堵（膨胀式密封塞）。
