# 比邻星b"祖父星夜祭"民俗文化节确立公报

![图注：比邻星b"祖父星夜祭"民俗文化节确立公报 · 任务日 · 档案体](../../world/生图集/669.webp)

**发布机构**：比邻星b行星文化局 / 民俗保护处
**发布日期**：3169年10月5日
**文件等级**：行星级公开

## 一、节日背景

"祖父星夜祭"起源于比邻星b第一代移民家庭。每年秋分之夜，家庭长辈带领晚辈走出室内，仰望天空中那颗暗淡的蓝色星点——那是从比邻星b上看到的地球。长辈讲述ARK-01航行故事与祖辈经历，晚辈默想祖先的远渡。

该民俗自2910年代起在民间自发流传，至今已有约250年。经行星文化局申报，今日正式确立为行星级民俗文化节。

## 二、节日时间

每年秋分日（比邻星b标准历9月23日前后），为期一天。

## 三、节日内容

1. **观星**：日落后，家庭成员共同观星，寻找地球方向；
2. **讲述**：长辈讲述祖辈故事；
3. **点灯**：在窗台或门口放置一盏暖灯，象征为祖先照路；
4. **祭文朗读**：朗读家族保存的第一代移民家书。

## 四、保护措施

1. 将"祖父星夜祭"列入比邻星b非物质文化遗产名录；
2. 支持各地社区组织观星与讲述活动；
3. 鼓励家庭保存和传抄第一代移民家书。
