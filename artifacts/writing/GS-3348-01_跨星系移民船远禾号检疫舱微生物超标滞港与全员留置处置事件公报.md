# 跨星系移民船"远禾号"检疫舱微生物超标滞港与全员留置处置事件公报

| 时刻（中继站标准时） | 事件 |
|---|---|
| 3348-10-15 | 移民船"远禾号"载320名迁徙人员自第四恒星系方向抵达L4中继站 |
| 10-15 08:21 | 检疫通道第七代设备（见GS-3311-01）气闸气溶胶采样检出一株未知真菌 |

| 10-25 | 全员解除留置，放行 |
| 10-27 | 本公报发布，事件结束 |

## 二、真菌来源

- 该真菌为火星地下温室长期未消杀的旧设备带入移民船。
- 与3308年11月舱内真菌超标事件（见GS-3309-01）同源。
- 非第五恒星系方向——该方向无移民船（见GS-3303-01）。

## 三、处置

| 措施 | 执行 |
|---|---|
| 全员留置 | 72小时（10-15至10-18），非72小时延长 |
| 行李辐照 | 全船终末辐照 |
| 船体消杀 | 气闸单独臭氧吹扫48小时 |
| 人员健康 | 无感染，无人员就医 |
| 信息公开 | 本事件跨星系公开 |

无人员伤亡，无扩散，无经济损失（滞留成本由检疫总署承担）。

## 四、整改

1. **出发站预检**：第四恒星系方向出发站增设预检通道（呼应GS-3309-01升级），避免旧设备真菌带上船。
2. **设备消杀标准**：移民船设备消杀标准更新，旧设备上船前强制消杀。
3. **贺雨清签发**：贺雨清按规程扣留，无处分；其"慢一点"原则（见GS-3344-01）获检疫总署通报表扬。
4. **不追责移民船**：真菌来自旧设备，非船员过失。

## 五、与既有事件区别

- 不同于GS-3312-01拥堵——那是吞吐量瓶颈，这是生物安全扣留。
- 不同于GS-3333-01误报——那是望远镜误判，这是真阳性但非新威胁。
- 本事件为检疫通道正常工作，非事故。

## 五、人员健康

320名迁徙人员留置72小时，无一人出现症状。解除留置时，随队医官逐人问询，均称无不适。医疗费用由检疫总署承担，不向个人收取。
