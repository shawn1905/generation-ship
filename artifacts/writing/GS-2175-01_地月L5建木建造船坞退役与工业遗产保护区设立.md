# 地月L5"建木"建造船坞退役与工业遗产保护区设立公报

**发文单位**：地月空间工业管理局 · 建造设施退役与遗产保护委员会
**公报编号**：L5-DEC-2175-001
**签发日期**：2175年8月30日
**密级**：公开

## 一、退役背景

"建木"建造船坞（Jianmu Construction Yard）位于地月系统第五拉格朗日点（L5），是人类历史上规模最大的空间建造设施，也是ARK-01世代飞船的主建造基地。船坞自2071年开工建设，2078年投入使用，至2146年ARK-01出港，累计运行68年。ARK-01出港后，船坞继续承担了若干大型空间设施的建造任务（包括3座深空通信中继站、2艘外太阳系货运飞船、以及1座火星轨道空间站的扩建模块），至2170年完成最后一项建造合同。

此后，船坞进入"待机维护"状态。经过5年的评估与论证，地月空间工业管理局于2175年正式决定将建木船坞退役，并将其设立为工业遗产保护区。

## 二、船坞历史与规模

### 2.1 建设历程

建木船坞的建设分为三个阶段：

- **一期工程**（2071–2078）：建设核心建造平台与基础保障设施，包括主桁架结构、加压居住舱、电力与推进系统、初期建造设备。一期投资约1,200亿元（2070年不变价）
- **二期工程**（2082–2090）：扩展建造能力，增加大型构件制造与装配设施，包括3D打印厂房、材料加工车间、大型机械臂阵列。二期完成后，船坞具备建造百万吨级空间设施的能力
- **三期工程**（2095–2105）：为ARK-01建造专项扩建，增加超大型构件装配泊位、聚变推进器安装设施、生命保障系统测试平台。三期完成后，船坞总质量达到8,400万吨，成为人类有史以来建造的最大单体工程结构

### 2.2 主要设施与规模

建木船坞的主要技术参数：

| 参数 | 数值 |
|------|------|
| 总质量 | 8,400万吨（含压载与设备） |
| 主桁架跨度 | 12.4公里 |
| 最大建造泊位尺寸 | 8公里×3公里×2公里（长×宽×高） |
| 加压居住舱总容积 | 420万立方米 |
| 常驻人员峰值 | 12,800人（2120年，ARK-01建造高峰期） |
| 电力系统总装机 | 2.4 GW（4座聚变反应堆） |
| 推进系统 | 离子推进+化学推进组合，用于轨道维持与姿态控制 |
| 累计建造设施总质量 | 约4.2亿吨（含ARK-01本体3.8亿吨） |

船坞的核心结构是一组十字形主桁架，由高强度钢—钛—碳纤维复合材料建造，桁架截面为120米×120米的箱型结构，内部为多层走廊与设备舱。主桁架上安装了超过2,000台各类机械臂与建造设备，最大的机械臂展开长度达800米，可操纵百吨级构件。

## 三、退役工程

### 3.1 退役评估

在决定退役之前，退役与遗产保护委员会对船坞进行了全面的技术评估，主要结论：

1. **结构完整性**：主桁架结构在68年运行后整体完好，关键构件的材料性能下降在可接受范围内（钢材屈服强度平均下降4.2%，碳纤维复合材料层间剪切强度下降3.8%）。但部分非关键构件（如外部平台、走道、设备支架）出现了较明显的微陨石损伤与材料老化，需要维修或拆除
2. **系统状态**：4座聚变反应堆中，2座已达到设计运行寿命（60年），需退役；另外2座尚可运行10–15年。电力、推进、生命保障等系统的部分部件已老化，继续运行需要大规模更换
3. **经济可行性**：若继续维持船坞运行，年维护成本约为85亿元；若进行全面翻新以恢复建造能力，投资约为3,200亿元，且翻新后的市场需求不确定（当前空间建造市场已转向更灵活的分布式建造模式）
4. **遗产价值**：船坞作为ARK-01的出生地，具有不可替代的历史与文化价值。其建造技术、工程组织、工人生活等方面的遗存，是人类太空文明史的重要物证

基于以上评估，委员会建议将船坞退役并设立为工业遗产保护区，而非继续运行或拆解回收。

### 3.2 退役工程内容

退役工程自2175年3月启动，计划于2177年底完成，主要内容包括：

1. **核燃料卸载与反应堆封存**：将4座反应堆的核燃料全部卸载（转运至月球南部的核废料储存库），反应堆舱进行清洗、固化与密封
2. **危险物质清理**：清理船坞内的推进剂（液氢、液氧、氙气等）、化学品、润滑油等危险物质，消除火灾、爆炸与泄漏风险
3. **系统断电与封存**：除遗产保护必需的监测与通信系统外，全部电力系统断电，设备舱进行密封与惰性气体填充（防止材料氧化）
4. **结构加固与防护**：对主桁架等关键结构进行检查与必要的加固，增加微陨石防护层（在关键构件表面增加一层铝—聚乙烯复合防护箔）
5. **遗产记录与建档**：对船坞的全部设施进行三维激光扫描与摄影测量，建立完整的数字档案；对具有历史意义的设备、工具、个人物品进行登记与保护
6. **参观设施建设**：在船坞的加压居住舱区域改造建设遗产展示与参观设施，包括展览馆、解说系统、安全的参观路线

### 3.3 人员安置

船坞退役涉及常驻人员的安置。退役前船坞常驻人员为1,240人（维护与运营团队），其中：约380人转入工业遗产保护区的管理与维护团队、约520人由地月空间工业管理局协调安置到其他空间设施、约240人选择退休（享受提前退休待遇）、约100人选择返回地球就业（提供就业推荐与搬迁补贴）。

## 四、工业遗产保护区

### 4.1 保护区定位

建木工业遗产保护区的定位为：**人类太空文明史的活态博物馆与工程教育基地**。保护区将保留船坞的主要结构与设施，使其作为人类建造史上最大工程的物证，供公众参观、学术研究与工程教育使用。

### 4.2 保护区功能分区

- **遗产展示区**：位于原加压居住舱区域，改造为展览馆与参观设施。展示内容包括：船坞建设史、ARK-01建造过程、太空建造技术、工人生活与文化、重要历史事件的实物与多媒体展示。设计年参观容量为20万人次（主要为地月空间旅行者与远程虚拟参观）
- **工程教育区**：保留部分建造设施（如一台大型机械臂、一个3D打印厂房、一条材料加工线）的可运行状态，用于太空工程专业的学生实习与技术培训。每年可接纳约500名学生进行为期2–4周的实习
- **封存保护区**：主桁架结构与核心建造泊位（ARK-01曾停靠的泊位）作为核心遗产进行封存保护，不对外开放参观，仅允许经批准的研究人员进入（每年不超过100人日）。封存区域维持真空环境（不加压），以减缓材料老化
- **监测与维护区**：保护区管理团队的工作区域，配备船坞结构状态监测系统（应力、温度、微陨石撞击、轨道姿态等参数的实时监测）、通信系统、维护设备

### 4.3 保护原则

保护区的保护遵循以下原则：

1. **最小干预原则**：尽可能保留船坞的原始状态，不进行不必要的修复与翻新。对必须进行的加固与维护，采用可识别、可逆转的方式，并做好记录
2. **真实性原则**：保留船坞在运行过程中形成的真实痕迹，包括焊接痕迹、设备磨损、工人涂鸦、事故修复痕迹等。这些痕迹是历史的真实记录，不应被"修复"掉
3. **可及性原则**：在确保安全的前提下，尽可能让公众能够接触与理解这份遗产。同时提供高质量的远程虚拟参观，使地球上的公众也能体验
4. **可持续性原则**：保护区的运行采用低能耗模式，主要电力来自太阳能电池板（在船坞外部安装）与1座小型聚变反应堆（从原4座中保留1座，降级运行）。年运行成本控制在15亿元以内

## 五、历史意义

建木船坞的退役与遗产保护区的设立，标志着人类太空文明从"建造时代"进入"传承时代"。船坞本身是人类工程能力的巅峰之作，它孕育了ARK-01——人类第一艘世代飞船，承载着人类文明向星际扩散的使命。将船坞保留为工业遗产，不仅是对一段工程史的纪念，更是对人类文明"从哪里来、到哪里去"这一根本问题的物质回答。

保护区内将永久保存一块刻有以下文字的铭牌（位于原ARK-01建造泊位的入口处）：

> 此地，人类建造了通往星辰的船。
> 2078–2146，建木船坞运行六十八年，
> 建造ARK-01及其他空间设施四十一座。
> 一万两千八百名建造者在此工作，
> 他们的汗水凝固在每一条焊缝里。
> 船已远航，坞留此地，
> 为后来者铭记。
