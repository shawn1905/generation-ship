# 木星轨道工业区"朱庇特"氦-3精炼联合体首期投产公报

**公报文号**：JUP-HE3-2085-009
**发文单位**：木星轨道工业区管理委员会生产处
**工程标的**："朱庇特"氦-3精炼联合体首期生产线（含大气采集艇2艘、精炼厂1座、储罐区）
**核算周期**：2085年2月1日 — 2085年6月30日（首期五个月投产运行）
**作业位置**：木星同步轨道，木卫四轨道共振点（距木星中心约18万km）

---

## 一、联合体概况

朱庇特氦-3精炼联合体为外太阳系首个商用氦-3生产设施，由"长风"系列大气采集艇（2艘）、轨道精炼厂、低温储罐区与装载码头组成。采集艇定期下降至木星大气顶部（气压0.1bar高度）采集氢氦混合气体，压缩后运回轨道精炼厂进行低温精馏分离。

### 首期核心参数

| 参数项 | 设计值 | 首期实测 |
|:---|:---:|:---:|
| 采集艇单次采气量 | 12,000 t（混合气体） | 11,400 t |
| 采集艇月均出动次数 | 8次/艘 | 7.2次/艘 |
| 精炼厂氦-3提取率 | ≥65% | 67.4% |
| 氦-3设计年产量 | 800 kg/年 | 年化812 kg |
| 氦-3产品纯度 | ≥99.995% | 99.997% |
| 联合体常驻人员 | 64人 | 64人 |

## 二、首期生产数据

首期五个月累计采集氢氦混合气体8.2万吨，经精炼分离产出氦-3产品338kg、氦-4副产品2,840吨、氢气副产品61,200吨。氦-3产品全部封装入低温储罐，待内太阳系聚变燃料采购方提货。

## 三、大气采集作业安全

木星大气采集为高风险作业，采集艇下降至大气顶部时需承受强辐射、高速气流与静电放电。首期作业期间共执行72架次采集任务，无重大安全事故，关键安全指标如下：

| 安全指标 | 控制阈值 | 首期实测峰值 | 超限次数 |
|:---|:---:|:---:|:---:|
| 采集艇舱内辐射剂量率 | ≤0.5 mSv/h | 0.42 mSv/h | 0 |
| 采集艇结构载荷（气动） | ≤设计值80% | 72% | 0 |
| 静电放电事件 | ≤5次/架次 | 3.2次/架次 | 0 |
| 采集艇返航推进剂余量 | ≥15% | 22% | 0 |
| 人员舱外作业辐射（人均累计） | ≤150 mSv/任期 | 89 mSv | 0 |

## 五、投产结论

朱庇特氦-3精炼联合体首期生产线经五个月投产运行，大气采集工艺稳定，低温精馏分离效率达标，氦-3产品纯度符合聚变燃料标准，作业安全可控。**首期投产验收合格，联合体自2085年8月起进入满负荷生产阶段，目标年化氦-3产量提升至900kg。**
