**本学期学术配给基本准则：**
1. **去功利化原则**：选课申请不与既往产值、社会积分或考试评分挂钩。研学会仅核验申请人过去四季中获得具名学时的总量，优先保障长期从事不具名公共维护（如生态巡护、水网清理、设备值守）之公民进入外场高端工位；
2. **纯粹实体感知原则**：外场高阶研学课程严禁使用端到端深度神经网络生成实验报告。数字模型仅限用于天体坐标初算与潮汐振幅对账，所有实验原始记录必须以物理纸张、手工水墨、光学目镜直视描摹完成；
3. **署名存根制**：完成具名研学之学员，其手写观测日记正本直接移交华东科学与技术档案馆永久归档，享有百年档案手迹存证权。

## 四、 外场研学基地运行规程与生活保障规范

为确保研学人员在脱离全自动化算法依赖之状态下，获得高纯度自然沉浸与严谨科研训练，东海暗夜基地与杭州湾野化站执行以下运行保障规程：

```
                    【东海暗夜天象观测基地 · 离岸32.5km海面实景规程】
   
    [深空天幕] ── 零光害区（Bortle Class 1，天顶夜空亮度 ≥ 21.85 mag/arcsec²）
         │
    [观测平台] ── 2.4米折反射“张衡号”望远镜球冠穹顶（直径18米，哑光消反射黑漆涂层）
         │        └── 露天观测甲板（铺设老式防滑柚木地板，配备4组黄铜赤道仪）
         │
    [防波堤岸] ── 洋山外海重型玄武岩防波堤（长3,200米，夜间受生物荧光藻类冲刷呈冷蓝微光）
         │
    [生活舱区] ── 120间防潮隔音木结构静音研学居室（接入奉贤聚变电网谷电直供超导地暖）
                  └── 食堂全天候供应：南岸新鲜全麦烤包、热番茄浓汤、纯黑咖啡与自产红茶
```

### 1. 绝对暗夜管制条例（东海基地适用）
- **时段限制**：每日 19:00 至次日 05:30，除天文台圆顶裂缝与引导红光外，平台全域严禁开启任何波长小于 620 nm（黄绿蓝紫光波段）之光源；
- **照明标准**：室外走廊及甲板地面仅允许开启埋地式 0.05 勒克斯暗红光发光二极管导引条；
- **终端管制**：学员个人便携终端必须调至“深空红光单色模式”（照度 ≤ 0.2 cd/m²），严禁在室外露天甲板开启全彩背光。

### 2. 餐饮与生活起居配给
- **食材直供**：研学期间每日生活物资由南岸综合体中央厨房清晨通过低噪纯电动摆渡驳船专线送达，包含南岸温室自产番茄、黄瓜、高蛋白水培燕麦面包、鲜牛奶及奉贤深井泉水；
- **作息安排**：实行天文研学“昼伏夜作制”。每日 12:00 提供正餐，18:00 提供夜班前热汤与焙烤点心，午夜 00:00 及 03:30 于甲板休息室供应热浓茶与姜糖饮；
- **心理与健康支持**：基地配备常驻医师与心理疏导员各 1 名，每日为长时间处于暗夜环境之学员进行生理节律校核，保证每日地热温水淋浴与充足睡眠。
