# 深空光学中继站接收器校准件换班封存表

![深空光学中继站接收器校准件换班封存表](../../world/生图集/1580.webp)

**单位：中继站维护组**  
**日期：2617年1月24日**  
**记录：接收器校准件交接**

接收器例行校准使用两只封存盒：一只存放参考件，一只存放待检件。两盒外观相同，锁扣颜色不同；本班按盒内编号核对，不以颜色单独认定。

| 项目 | 状态 |
|---|---|
| 参考件编号 | 与上次记录一致 |
| 待检件外观 | 无可见缺损 |
| 校准数据 | 写入本地记录，待复核 |
| 发往另一端的回执 | 尚未收到 |

这张表只证明本地交接完成，并不证明远端已经接收。发出记录与回执各按其所在地时标保存；无回执时，维护组继续保留原件，不用空白回执代替确认。

盒角有旧维修贴纸，贴纸的一侧被新封签压住。接班人检查封签完整并签名，贴纸留在原处。
