# 跨星系公民身份认同重构与三系合籍身份法典修订公报

![图注：三系合籍法典修订表决厅 · 任务日 · 档案体](../../world/生图集/1002.webp)

**发布机构**：三恒星系文明联合体议会身份与公民权委员会
**发布日期**：3502年4月10日
**文件等级**：跨星系公开

## 一、修订背景

自3390年千年连续定居身份继承制度（见GS-3390-01）施行以来，跨星系公民身份长期沿"原籍—现籍"双轨登记。公民在三系间迁徙换籍时，原籍档案与现籍档案分存两地，身份叙事需自行拼接。第五百年大典后，议会身份与公民权委员会启动身份认同重构，将双轨并为一轨，称"三系合籍"。

## 二、修订要点

**（一）一籍通三系**

原"原籍—现籍"双轨废止，改为单一"三系合籍"。公民无论出生于哪一系、迁徙至哪一系，档案合并为一条，原籍作为"出身地"字段保留，不再单独成籍。

**（二）出身地字段**

出身地字段不随迁徙注销。公民出生于比邻星b、定居鲸鱼座τ星地下城，其合籍档案同时记录两处。委员会注明：走了就是走了，但从哪来的，永远在纸上。

**（三）身份认同问卷**

合籍后首次纳入身份认同问卷，每年随换籍登记采集。问卷不问"你是哪系人"，问"你认哪段来历"。委员会注明：以前我们只问你住哪，现在多问一句你认哪。

## 三、修订过程

法典修订历时三年（3499—3502），经三系议会代表跨系连线表决（见GS-3239-01字幕规程）。表决中，纯本土出生公民代表提出：合籍后若"出身地"字段权重过高，恐将从未踏足老地球方向的公民排除在"正统"之外。委员会采纳，将出身地字段设为中性记录，不作身份权重。

## 四、与既有制度衔接

| 既有制度 | 衔接方式 |
|---|---|
| 千年连续定居身份继承（GS-3390） | 连续定居年限并入合籍履历字段 |
| 迁徙落户制度（GS-3310） | 换籍手续并入合籍登记，不再单独换籍 |
| 公民权过渡授予（GS-3338） | 第五恒星系方向暂不适用合籍，仍按过渡暂行 |
| 不可交易名录（GS-3374） | 合籍档案中文化身份部分仍受名录保护 |

## 五、施行首年数据

| 指标 | 数值 |
|---|---|
| 合籍登记公民 | 约41亿 |
| 双轨合并耗时（人均） | 约14分钟 |
| 合并错误率 | 0.02% |
| 身份认同问卷回收率 | 93.7% |
| 问卷表达疏离 | 8.2%（见GS-3503-01） |

## 六、表决争议与妥协

法典修订三年间，三系代表争议集中于两处：

其一，比邻星方向代表主张出身地字段权重应高于现居地，理由为先人迁徙代价；第四恒星系代表反对，认为会歧视本土出生者。折中为出身地字段中性化。

其二，鲸鱼座τ星地下城代表主张濒危语言（见GS-3317-01）应随合籍自动转入个人档案；委员会认为濒危语言属社群而非个人，不入个人籍，仅入社群名录。

委员会注明：两处争议都不是"谁对谁错"，是三系各自的来路不一样。法典不是把来路磨平，是让来路并排写在一张纸上。

## 七、合籍后的第一次年度

3503年首次问卷回收（见GS-3503-01），疏离率8.2%。委员会在法典附则中预留"随认同演变定期修订"条款，不指望一劳永逸。

## 八、合籍前后的身份比对

| 维度 | 合籍前（双轨） | 合籍后（一籍） |
|---|---|---|
| 档案数量 | 一人两档 | 一人一档 |
| 换籍手续 | 原籍注销加现籍新办 | 合籍登记一次 |
| 出身地 | 随换籍注销 | 永久保留为字段 |
| 跨系通行 | 逐系核验 | 一次核验通行 |
| 问卷 | 各系各问 | 统一问卷 |

委员会注明：双轨并一轨，省的是手续，不是省了身份。一个人从比邻星b搬到鲸鱼座τ星地下城，以前要销一籍办一籍，现在只登记一次。手续简单了，背后的来历反而记得更全。

## 九、合籍不抹平差异

合籍后，各系方言、地方仪式、社群文化不受影响。委员会注明：合的是籍，不是文化。一个人可以既是三系合籍公民，又是某地下城某片区的人。籍统一了，人没被削平。

## 十、委员会注明

五百年了，我们终于把三系的名字写在同一张纸上。纸是合了，认不认，是另一回事。8.2%的人说"这纸不像我"。我们不催，我们把纸留着，等他们哪天愿意翻开。合籍是制度，认同是人心，制度先到，人心慢慢跟。


## 十一、附则说明
法典附则写明：本法典不规定文化认同，只规定身份手续。委员会在审议中反复强调，一个人认不认三系，是他自己的事；法律能做的，只是把他的一档、一次核验、一次共誓办妥。身份是账本，认同是人心。账本能统一，人心不能。法典修订到此为止，余下交给时间和广场。


## 十二、合籍后的第一个十年
法典施行后的第一个十年，跨系换籍人数从每年四百万人次涨到每年九百万人次。委员会在附记中说明，换籍人数上涨不是因为旧籍不好，是因为一个人在三个恒星系之间来回，不再需要为每一次搬家销籍办籍。手续省下来的时间，让人敢动。敢动，才敢把自己当成三系的人，而不是某一颗星上的人。合籍不是把人钉在一颗星上，是把人从一颗星上松出来。松出来之后，他反而更愿意认这一整盘。
