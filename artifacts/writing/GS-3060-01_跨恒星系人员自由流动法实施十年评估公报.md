# 跨恒星系人员自由流动法实施十年评估公报

**发布机构**：联合体法院 / 跨星系民事庭
**发布日期**：3060年8月14日
**文件等级**：跨星系公开
**公报号**：CT-3060-0814

## 一、评估缘起

《跨恒星系人员自由流动法》于3050年1月1日施行，授权持联合体公民身份者在三恒星系间免签证迁徙。至3060年满十年，法院依约评估。

## 二、流动规模

| 指标 | 十年累计 |
|---|---|
| 跨星系永久迁徙人数 | 约2,140万 |
| 鲸鱼座τ星→比邻星b | 占41% |
| 比邻星b→鲸鱼座τ星 | 占22% |
| 主带⇄两星表面 | 占29% |
| 其余 | 8% |
| 临时工作派遣（非永久） | 约9,800万人次·年 |

## 三、三类主要纠纷

法院十年间受理跨星系流动相关民事案共1,872件，三类占比最大：

1. **社保接续**（41%）：迁徙者在原星系缴纳的养老、医疗关系能否带走。经多轮判例，已确立"缴费年限连续计算、福利按迁入地标准接续"规则；
2. **子女教育**（27%）：跨星系求学的学籍与学分互认（与GS-2923-01互锁）。问题在十年内基本消解；
3. **低重力适应**（19%）：主带低重力出身者迁住高重力星球后的骨、前庭适应（见GS-2368-01同类问题），法院已确立迁入方须提供三个月免费适应期的规则。

## 四、未竟事项

1. **身份认同模糊**：部分第三代跨星系家庭三代分居两星，"我是哪里人"在法律上清晰、在情感上模糊——法院无权亦不应立法解决；
2. **欠发达方向人才外流**：鲸鱼座τ星净流出仍大于流入，虽有家庭团聚优先（GS-2961-01），但工程师、医师流失未止。法院建议经济理事会以发展基金对冲，而非以限制迁徙的方式解决；
3. **通信延迟下的家事**：4—12年光距使"跨星系离婚""跨星系继承"的程序异常冗长，法院已将相关程序列为下一修法重点。

## 五、结论

自由流动十年，2,140万人换了一颗出生以外的星球落脚。法律把门槛拆掉了，但门后那片土地会不会把人留下，法律不管，也管不了。
