# 主小行星带"铸星"城市群联合宣告自治与对地关税独立公报

![档案影像：主小行星带"铸星"城市群联合宣告自治与对地关税独立公报 · 2198年7月4日](../../world/生图集/391.webp)

**发文单位**：主小行星带铸星城市群联合议会 · 自治宣告起草委员会
**公报编号**：ZX-AUT-2198-001
**签发日期**：2198年7月4日
**密级**：公开

## 一、宣告背景

主小行星带的人类开发始于21世纪80年代的自动化采矿前哨。经过一个多世纪的发展，至22世纪末，主小行星带已形成以"铸星"城市群为核心的、人口超过180万的永久性人类聚居区。铸星城市群由12座小行星改造的居住城市组成，分布在小行星带内轨道区（2.2–2.8天文单位），各城市之间通过定期穿梭航班与数据链路连接，形成紧密的经济与社会共同体。

长期以来，铸星城市群在行政上隶属于地球联合政府的"外太阳系开发管理局"，其治理结构为"管理局委派总督+地方咨询议会"模式，重大决策需经管理局批准。随着城市群人口增长、经济成熟与社会文化的独特化，这种治理模式与城市群的实际需求之间的张力日益显现。

2195年，铸星城市群联合议会（咨询性质）以87%的赞成票通过《关于争取完全自治地位的决议》，并启动与地球联合政府的谈判。经过两年半的谈判，双方未能就自治地位与经济关系达成一致。2198年6月，联合议会决定单方面宣告自治，并于7月4日正式发布本公报。

### 2.2 经济结构

铸星城市群2197年的经济总量（GDP）约为1.2万亿元（小行星带货币单位，与地球元的汇率约为1:1.3），经济结构如下：采矿与资源加工34.2%、制造业22.7%、服务业18.9%、农业与食品12.4%、能源7.8%、其他4.0%。

铸星城市群的对外贸易中，对地球出口占62.3%（主要为稀有金属、工业材料、空间设备），从地球进口占47.8%（主要为精密仪器、特殊化学品、文化产品、奢侈品）。对月球与近地轨道的贸易占28.7%，对火星与外太阳系的贸易占9.0%。

### 2.3 社会与文化

经过一个多世纪的发展，铸星城市群已形成独特的社会文化特征：平均年龄38.2岁，在小行星带出生的"星带人"占总人口的62.7%。工作语言为汉语与英语并用，日常交流中形成了独特的"带语"（Belt Creole）——一种以汉语和英语为基础、混入大量技术术语与空间生活词汇的混合语。文化特征强调工程能力与实用主义，重视社区互助与资源共享。

## 三、自治宣告内容

### 3.1 政治自治

铸星城市群联合议会宣告：

1. 铸星城市群为**完全自治的政治实体**，拥有内部事务的完全立法权、行政权与司法权
2. 联合议会为城市群的最高立法机构，由各城市按人口比例选举产生的代表组成（每2万人选举1名代表，共89名代表），每届任期4年
3. 联合行政委员会为最高行政机构，由联合议会选举产生的7名委员组成，首席委员为城市群的行政首长
4. 联合最高法院为最高司法机构，法官由联合行政委员会提名、联合议会批准，终身任职（70岁强制退休）
5. 各城市保留内部自治权，联合政府负责跨城市事务（外交、国防、货币、跨城基础设施、总体经济规划）

### 3.2 关税独立

铸星城市群联合议会宣告：

1. 自2198年10月1日起，铸星城市群实行**独立的关税政策**，自主决定对来自地球（含月球与近地轨道）的进口商品征收关税的税率与品类
2. 此前由地球联合政府外太阳系开发管理局征收的"资源出口税"（对铸星城市群出口至地球的资源类商品征收的15%从价税）自即日起停止执行
3. 铸星城市群将与地球联合政府就新的贸易关系进行谈判，在谈判达成协议前，实行临时关税安排：对地球进口商品征收平均8%的基础关税，对可能冲击城市群本土产业的商品（如精密电子器件、高端机械）征收15%–25%的保护性关税
4. 铸星城市群的货币（带元 Belt Dollar, BTD）为独立货币，与地球元的汇率由市场决定，联合央行负责货币政策的制定与执行

### 3.3 对外关系

1. 铸星城市群愿意与地球联合政府保持友好合作关系，在科学研究、深空探索、交通安全、传染病防控等领域继续合作
2. 铸星城市群申请成为国际社会的正式成员，希望与各主权国家及政治实体建立外交关系
3. 铸星城市群承诺遵守国际法，履行已签署的国际条约义务（包括《外层空间条约》《月球协定》等）
4. 铸星城市群不寻求军事对抗，但其联合警备队（负责城市群内部安全与外部防御）为合法武装力量，规模与装备由联合议会决定

## 四、谈判历程与分歧

铸星城市群与地球联合政府就自治问题的谈判自2195年10月开始，至2198年5月结束，共进行了17轮正式谈判。双方的主要分歧如下：

| 议题 | 铸星城市群立场 | 地球联合政府立场 | 谈判结果 |
|------|--------------|----------------|---------|
| 自治地位 | 完全自治，拥有独立的立法、行政、司法权 | 高度自治，但外交、国防、货币权归联合政府 | 未达成一致 |
| 关税政策 | 完全独立的关税政策，自主决定税率 | 关税政策需经联合政府批准，资源出口税继续征收 | 未达成一致 |
| 资源权益 | 小行星带的资源归城市群所有与支配 | 小行星带资源为"全人类共同继承财产"，联合政府有管理权 | 未达成一致 |
| 军事力量 | 联合警备队为合法武装，规模自主 | 城市群不得拥有武装力量，安全由联合政府太空军负责 | 未达成一致 |
| 公民身份 | 城市群居民拥有独立的公民身份 | 城市群居民继续为地球联合政府公民 | 未达成一致 |

由于在所有核心议题上均未达成一致，铸星城市群联合议会于2198年6月15日以78票赞成、8票反对、3票弃权的表决结果，决定单方面宣告自治。

## 五、国际反应与影响

本公报发布后，国际社会的反应分化：

- **支持方**：火星殖民地政府发表声明，对铸星城市群的自治宣告表示"理解与同情"，并表示愿意与铸星城市群建立贸易关系。外太阳系若干小型定居点发表联合声明支持。部分地球国家（主要为长期主张限制联合政府权力的联邦制国家）表示"尊重城市群人民的选择"
- **反对方**：地球联合政府发表声明，称铸星城市群的单方面自治宣告"违反国际法与联合政府宪章"，宣布不承认其自治地位，并考虑采取"必要措施"维护联合政府的权威。部分依赖小行星带资源的地球国家表示关切
- **中立方**：月球城市带政府发表声明，呼吁双方通过对话解决分歧，表示愿意充当调解人。多数国际组织与国家呼吁保持克制，避免局势升级

## 六、后续安排

1. 2198年10月1日起，临时关税安排正式实施
2. 2198年12月，举行联合议会首次完全自治选举（此前为咨询议会，此次为正式立法机构选举）
3. 2199年1月，联合行政委员会与联合最高法院正式成立
4. 持续与地球联合政府进行对话，寻求在相互尊重的基础上建立新的关系框架
5. 申请加入相关国际组织，参与国际规则的制定

本公报为铸星城市群自治进程的正式起始文件，其法律效力与国际地位将在后续的政治实践中逐步确立。
