# 跨星系代际抚养义务与跨星系家庭法统一公报

![图注：跨星系代际抚养义务与跨星系家庭法统一公报 · 任务日 · 档案体](../../world/生图集/689.webp)

**发布机构**：三恒星系文明联合体议会 / 法制委员会
**发布日期**：3189年7月14日
**文件等级**：跨星系公开

## 一、立法背景

随着跨星系自由迁徙（见GS-3166-01）的实施，跨星系家庭日益增多。夫妻分居不同恒星系、子女随一方居住的情况普遍，导致抚养义务、监护权认定、赡养费支付等法律问题缺乏统一标准。

## 二、法案核心内容

1. **跨星系抚养义务**：父母对未成年子女的抚养义务不因分居不同恒星系而免除；
2. **赡养费跨星系支付**：赡养费可通过星元跨星系支付，不受汇率与距离限制；
3. **监护权争议管辖**：跨星系家庭监护权争议由联合体法院统一管辖；
4. **子女最大利益原则**：跨星系家庭法的一切判决以子女最大利益为首要考量。

## 三、实施

本法案自3190年1月1日起施行。

## 续录一：施行细则与监督反馈

本公报所定事项自公布之日起施行。施行细则如下：

1. 各执行单位须于公布后30日内制定本单位实施方案，报主管部门备案；
2. 实施方案须列明责任人、时间节点、资源需求；
3. 主管部门每季度对执行情况作一次检查，检查结果书面通知执行单位；
4. 执行单位遇重大困难可申请延期，延期不超过6个月；
5. 本公报施行满一年后作首次评估，评估报告报上级部门。

监督反馈渠道：公民对执行情况有异议者，可通过主管部门公开信箱提交，30日内答复。本公报与相关既有法规交叉引用之处，以正文所列档案编号为准。本公报不溯及既往，施行前已发生的法律事实按当时法规处理。

## 附则补充：审判培训与支付平台测试进度

各成员法院跨星系家庭法审判人员培训3189年12月前完成，培训覆盖法官214人、书记员86人，考核通过率100%。赡养费跨星系支付平台3189年11月上线测试，首月测试交易1,200笔，差错率0.08%，3190年1月1日正式运行。施行满一年后，法制委员会重点评估监护权争议案件数、赡养费执行率、平均审理周期三项。

## 附则再补：跨星系送达与缺席审判

跨星系抚养纠纷文书送达，优先通过量子通信电子送达，电子送达不能者采用慢速邮件，送达期限不计入审理期限。被告经合法传唤无正当理由不到庭者，可缺席判决，但判决书须通过电子与慢速邮件双渠道送达，保障上诉权。本补充与GS-3126-01送达规则互锁。
