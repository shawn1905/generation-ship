## 一、任务背景

ARK-01 远征舰队于公元 2350 年 10 月抵达比邻星 b 轨道（实际航行时间 200 年 7 个月，含加速、巡航、减速三段）。经过 18 个月的轨道遥感测绘与大气分析，选定晨昏圈（terminator）区域作为首批登陆点。本报告记录首批 3 艘工程拓荒艇的降落过程与地表初步勘察结果。

### 1.1 登陆点选择依据

| 候选区域 | 纬度 | 经度 | 优势 | 劣势 | 最终选择 |
|---|---|---|---|---|---|
| 晨昏圈 A 区（"黎明岸"） | 0° | 120°E | 地形平坦，温度适宜（0–40℃），光照稳定 | 风化层较厚，地基处理难度中等 | ✅ 选择 |
| 晨昏圈 B 区（"黄昏岸"） | 0° | 300°E | 岩石裸露，地基条件好 | 地形崎岖，着陆风险高 | 备选 |
| 向阳面中心 | 0° | 0° | 光照充足，太阳能效率高 | 温度过高（80–120℃），辐射强 | 否 |
| 背阳面中心 | 0° | 180° | 温度低，利于设备散热 | 永久黑暗，无太阳能，温度 -80℃ 以下 | 否 |

**最终登陆点**：晨昏圈 A 区（"黎明岸"），坐标南纬 2.4°、东经 118.6°，海拔 -120 m（相对于比邻星 b 大地水准面）。

## 三、地表环境初勘

### 3.1 大气与气候

| 参数 | 实测值 | 与轨道遥感预测对比 |
|---|---|---|
| 大气压力 | 0.92 atm | 预测 0.88–0.95 atm，符合 |
| 大气成分 | N₂ 78.2%、O₂ 21.1%、CO₂ 0.48%、Ar 0.18%、其他 0.04% | 预测基本一致，CO₂ 略低于预测 |
| 地表温度（登陆点） | 18.6℃（当地太阳时 06:30） | 预测 15–25℃，符合 |
| 温度日变化 | 12–28℃（晨昏圈稳定带） | 预测 10–30℃，符合 |
| 风速 | 3.2 m/s（东南风） | 预测 2–8 m/s，符合 |
| 相对湿度 | 42% | 预测 30–60%，符合 |
| 降水 | 无（观测期内） | 晨昏圈降水稀少，符合 |
| 大气辐射剂量（地表） | 0.8 mSv/日（含红矮星耀斑贡献） | 预测 0.5–1.5 mSv/日，符合 |

**大气可呼吸性评估**：比邻星 b 大气氧气含量 21.1%，压力 0.92 atm，理论上人类可直接呼吸。但 CO₂ 浓度 0.48%（地球 0.04% 的 12 倍），长期直接呼吸可能导致慢性呼吸性酸中毒；建议定居点采用大气过滤系统，将 CO₂ 浓度降至 0.1% 以下。首日出舱人员仍佩戴封闭式航天服，未进行无防护呼吸试验。

### 3.2 地形与地质

| 项 | 实测值 |
|---|---|
| 登陆点地形 | 平坦冲积平原，坡度 <2° |
| 地表覆盖 | 风化层（regolith）厚度 0.5–3.0 m，下方为玄武岩基岩 |
| 岩石类型 | 玄武岩（主要）、少量安山岩、沉积岩（层状结构） |
| 地质构造 | 登陆点 5 km 范围内有 2 条断裂带（NE-SW 走向），近期无活动迹象 |
| 水蚀痕迹 | 有！登陆点东南 3 km 处发现古河道痕迹（宽 20–50 m，深 2–5 m），表明历史上曾有液态水流 |
| 冰川痕迹 | 登陆点西北 8 km 处发现冰碛物堆积，表明高纬度地区曾有冰川活动 |

### 3.3 土壤与化学成分

首批采集 12 个地表土壤样本（0–30 cm 深度），艇载实验室分析结果：

| 成分 | 含量范围（均值） | 备注 |
|---|---|---|
| SiO₂ | 42–48%（45.2%） | 与地球玄武岩土壤类似 |
| Al₂O₃ | 12–16%（14.1%） | |
| FeO + Fe₂O₃ | 14–19%（16.8%） | 铁含量高于地球平均土壤 |
| MgO | 6–9%（7.6%） | |
| CaO | 5–8%（6.4%） | |
| Na₂O | 2–4%（3.1%） | |
| TiO₂ | 1.5–2.5%（2.0%） | |
| **高氯酸盐（ClO₄⁻）** | **0.8–2.4%（1.6%）** | **显著高于地球（<0.001%），与火星类似** |
| 重金属（Pb+As+Cd+Hg） | 0.12–0.35%（0.22%） | 高于地球土壤背景值 |
| 含水量 | 2–8%（4.6%） | 以结合水形式存在，非液态水 |
| 有机质 | 未检出（<0.001%） | 首批样本未发现有机分子 |
| pH | 7.8–8.6（8.2） | 弱碱性 |

**高氯酸盐与重金属的工程意义**：
1. 土壤不可直接用于农业，需经过淋洗与修复处理（去除高氯酸盐与重金属）后方可种植
2. 高氯酸盐可作为氧气来源（电解还原产氧），具有资源价值
3. 重金属（铁、钛、铝）含量较高，可作为就地资源利用（ISRU）的原料
4. 建筑材料可直接使用玄武岩与土壤（烧结砖、3D 打印混凝土），但需处理高氯酸盐以避免长期健康风险

### 3.4 水资源调查

| 水源类型 | 状态 | 评估 |
|---|---|---|
| 大气水汽 | 存在（相对湿度 42%） | 可通过冷凝收集，产量约 2 L/m²/日（理论值） |
| 土壤结合水 | 存在（含水量 4.6%） | 可通过加热提取，1 t 土壤约产 40 L 水 |
| 地下冰 | 推测存在（高纬度地区） | 需进一步钻探确认，登陆点 30 m 深度内未发现地下冰 |
| 液态水 | 未在地表发现 | 古河道痕迹表明历史上曾有液态水，当前可能存在于地下深处 |
| 水硬度与纯度 | 土壤提取水含高氯酸盐与重金属 | 需经过滤与蒸馏处理后方可饮用 |

### 3.5 生物初步调查

| 调查项 | 结果 | 备注 |
|---|---|---|
| 土壤微生物培养 | 未检出 | 12 个样本在 4 种培养基中培养 72 小时，无菌落生长 |
| 大气微生物采样 | 未检出 | 空气过滤器样本 DNA 分析未发现已知生物序列 |
| 岩石表面生物膜 | 未发现 | 目视与显微镜检查未发现生物膜或化石痕迹 |
| 有机分子检测 | 未检出 | 质谱分析未发现氨基酸、核苷酸、脂质等生物分子 |

**结论**：首批样本未发现比邻星 b 存在生命的证据。但调查范围有限（仅登陆点周边 1 km、深度 30 cm），不能排除其他区域（如地下深处、热液喷口、高纬度冰区）存在生命的可能性。建议后续开展更广泛的生物调查，重点关注古河道与地下热水活动区。

## 四、辐射与环境安全

### 4.1 红矮星辐射环境

比邻星是一颗 M 型红矮星，耀斑活动频繁。登陆首日观测到 2 次小型耀斑（C 级，相当于太阳 C 级耀斑），未对人员与设备造成影响。

| 辐射源 | 剂量率 | 年累积剂量（估算） | 防护措施 |
|---|---|---|---|
| 银河宇宙射线 | 0.3 mSv/日 | 110 mSv/年 | 居住舱水屏蔽+土壤覆盖 |
| 红矮星稳态辐射 | 0.4 mSv/日 | 146 mSv/年 | 同上 |
| 红矮星耀斑（年均 12 次 M 级、2 次 X 级） | 事件剂量 1–20 mSv | 年均 50 mSv | 耀斑预警+应急避难所 |
| 地表次生辐射（土壤放射性核素） | 0.1 mSv/日 | 36 mSv/年 | 居住舱底板屏蔽 |
| **合计** | **0.8 mSv/日** | **约 340 mSv/年** | 定居点设计屏蔽后降至 <50 mSv/年 |

**辐射安全评估**：比邻星 b 地表辐射剂量约为地球海平面（2.4 mSv/年）的 140 倍，长期无防护暴露不可接受。定居点必须采用辐射屏蔽设计（居住舱覆盖 2–3 m 土壤或水层），将年剂量降至 50 mSv 以下（国际辐射防护委员会推荐限值）。拓荒艇本身具备屏蔽能力，乘员在艇内与航天服内的剂量在安全范围内。

### 4.2 大气毒性

- **CO₂ 浓度 0.48%**：短期暴露（数小时）无害，长期暴露（数月以上）可能导致慢性呼吸性酸中毒、电解质紊乱。定居点需配备 CO₂ 过滤系统。
- **高氯酸盐粉尘**：地表土壤含 1.6% 高氯酸盐，扬尘吸入可能导致甲状腺功能障碍。定居点需配备空气过滤系统，出舱人员需佩戴防尘面罩。
- **重金属粉尘**：长期吸入可能导致重金属中毒。处理同上。

## 六、结论与建议

### 6.1 主要结论

1. **首批 3 艘拓荒艇安全降落**于比邻星 b 晨昏圈 A 区（"黎明岸"），全员安全，无伤亡。
2. **大气与气候条件良好**：温度 12–28℃，大气含氧量 21.1%，压力 0.92 atm，CO₂ 0.48%（需过滤）。
3. **地形与地质条件适合建设**：平坦冲积平原，玄武岩基岩，建筑材料与矿产资源丰富。
4. **土壤含高氯酸盐（1.6%）与重金属（0.22%）**：不可直接用于农业，需修复；但高氯酸盐可作为氧气来源，重金属可作为资源。
5. **水资源可满足初期需求**：大气冷凝+土壤提取，长期需寻找地下水源。
6. **辐射剂量较高（约 340 mSv/年）**：定居点需屏蔽设计，屏蔽后可降至安全范围。
7. **未发现生命证据**：首批样本未检出微生物或有机分子，但调查范围有限，不能排除其他区域存在生命。

### 6.2 建议

1. **批准首批定居点建设**：在登陆点周边 5 km 范围内建设首批永久定居点，按上述四阶段计划推进。
2. **优先解决三项关键问题**：辐射屏蔽（地下居住舱或土壤覆盖）、土壤修复（去高氯酸盐与重金属）、CO₂ 过滤（居住舱大气处理）。
3. **开展更广泛的资源与生命调查**：重点调查地下冰/水源、古河道区域、可能的热液活动区，同时扩大生物调查范围。
4. **建立耀斑预警系统**：在轨道部署辐射监测卫星，为地表提供红矮星耀斑预警（提前 10–30 分钟）。
