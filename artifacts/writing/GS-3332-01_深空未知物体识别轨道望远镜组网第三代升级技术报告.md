# 深空未知物体识别轨道望远镜组网第三代升级技术报告

![图注：轨道望远镜组网中继站 · 多面碟形天线与桁架 · 单一恒星光 · 档案体](../../world/生图集/832.webp)

**编制单位**：联合体航天学派 · 深空观测组
**报告编号**：SPC-OPT-3332-023
**日期**：3332年7月27日
**密级**：跨星系公开技术版

## 一、任务概述

按《深空安全预警分级响应制度》（见GS-3331-01），橙级响应须由望远镜组网确认未知物体。第二代望远镜组网自3310年代部署以来，对小尺寸、暗弱未知物体识别率不足。航天学派承担第三代组网升级，拟于3333年部署。本报告记录升级方法与数据。

## 二、组网架构

| 项目 | 第二代 | 第三代 |
|---|---|---|
| 望远镜数量 | 6面 | 12面 |
| 分布 | 三恒星系方向 | 三恒星系+第四恒星系方向 |
| 口径 | 1.5m | 2.0m |
| 基线 | 约2AU | 约4AU |
| 角分辨率 | 0.1角秒 | 0.02角秒 |
| 灵敏度 | 20等 | 24等 |

## 三、升级内容

1. **基线扩展**：在第四恒星系方向新增6面望远镜，基线翻倍，识别暗弱小天体能力提升。
2. **多波段**：新增红外通道，识别冷却后的退役船壳与碎片。
3. **自动判别**：接入AI初筛，但最终判读由观测员（见GS-3329-01）人工确认——AI仅辅助，不自动定级。
4. **数据链路**：沿用光帆脉冲通信（见GS-3127-01）与量子中继（见GS-3160-01），时延4—5小时。

## 四、测试数据

| 指标 | 目标 | 实测 |
|---|---|---|
| 24等天体识别率 | 90% | 91% |
| 小尺寸（<10m）识别 | 80% | 83% |
| 误识别率 | <5% | 4.1% |
| 组网响应时间 | <12小时 | 9小时 |
| 数据延迟 | <6小时 | 5.2小时 |

## 五、局限

- 光时延4—5小时，无法实时闭环，所有判读为事后。
- 对完全冷黑物体（无反射、无红外）识别率仍低。
- 第五恒星系方向望远镜未覆盖——该方向由接触事务局被动监听（见GS-3305-01），不纳入安全组网。

## 六、部署

- 第三代组网3333年第一季度部署完成。
- 旧第二代6面转用于近地天体监测（见GS-3195-01）。
- 所有望远镜出厂前经本报告同款测试，逐台归档。

## 七、部署成本

| 项目 | 金额（星元） |
|---|---|
| 12面望远镜制造 | 1200万 |
| 第四恒星系方向部署 | 380万 |
| 数据链路升级 | 95万 |
| 合计 | 1675万 |

由联合体深空安全专项预算列支。

## 八、与第五恒星系方向分界

本组网不覆盖第五恒星系方向——该方向由接触事务局被动监听（见GS-3305-01），不纳入安全组网。航天学派说明："望远镜看的是'威胁'，不是'邻居'。邻居的门，由别人敲。"

## 九、望远镜不跟踪第五恒星系方向

本组网不跟踪第五恒星系方向——该方向由接触事务局被动监听。航天学派说明："望远镜看威胁，不看邻居。"

## 十、组网不透明

组网位置、孔径、灵敏度不公开。跨星系公开仅"第三代组网已部署"一份公报。

## 十一、组网与人工复核

第三代组网后，AI初筛，沈灼（见GS-3329-01）等夜班人员人工复核。航天学派明确："机器看第一遍，人看第二遍。机器报的，人信；人没报的，机器不许替人报。"

## 十二、组网构成

| 子站 | 位置 |
|---|---|
| 1—4 | 三恒星系方向 |
| 5—8 | 第四恒星系方向 |
| 9—12 | 跨系中继 |

共12面，组网不公开位置。

## 十三、组网启用

第三代组网本年部署完成，共十二面子站，覆盖三恒星系与第四恒星系方向。位置不公开。组网后，沈灼等夜班人员仍坚持人工复核。

## 十四、组网回顾

第三代组网部署完成，运行三个月无故障。位置不公开。
