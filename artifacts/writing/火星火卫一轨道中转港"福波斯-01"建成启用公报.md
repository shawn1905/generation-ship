# 火星火卫一轨道中转港"福波斯-01"建成启用公报

**签发单位**：内太阳系物流基础设施建设联合体 · 火星火卫一中转港项目办
**公报编号**：PHB-01-2055-001
**签发日期**：2055年9月25日

---

## 一、项目概况

火星火卫一（Phobos）轨道中转港"福波斯-01"于2055年9月22日10时08分（UTC）完成最后一个核心模块——推进剂储运库的对接与调试，9月23日通过48小时全系统联调考核，9月25日正式宣布建成启用。

"福波斯-01"是内太阳系物流网络中首个位于火星系统的深空中转港，锚定于火卫一轨道（距火星表面约6,000 km），利用火卫一的低重力与稳定轨道作为地球—火星—小行星带—外太阳系航线的物流中转与人员换乘节点。港口设计年货物吞吐量120万吨，年人员换乘能力8,000人次。

| 港口参数 | 数值 |
|---|---|
| 锚定轨道 | 火卫一轨道（半长轴9,376 km，距火星表面约6,000 km） |
| 港口总质量 | 约48,000吨（含桁架、舱段、储罐、设备） |
| 桁架总长度 | 1,200 m（主桁架）+ 4×600 m（支桁架） |
| 加压舱段总容积 | 42,000 m³（含居住、办公、仓储、换乘） |
| 泊位数量 | 大型泊位4个（可停靠500吨级深空货船）、小型泊位8个（穿梭机/渡船） |
| 推进剂储罐容量 | 液氧8,000 m³ + 液氢2,000 m³ + 甲烷3,000 m³ |
| 供电 | 太阳能阵列（15 MW，峰值）+ 核电源（2 MW RTG，持续） |
| 常驻人员 | 120人（运营期），建设高峰期480人 |
| 设计寿命 | 50年（主体结构），设备每10年更新 |

## 二、建设历程

| 阶段 | 时间 | 主要内容 |
|---|---|---|
| 可行性研究 | 2048—2049 | 火卫一轨道特性分析、物流需求预测、方案比选 |
| 初步设计 | 2049—2050 | 总体方案、桁架结构、舱段布局、推进剂储运方案 |
| 详细设计与生产 | 2050—2052 | 模块详细设计，月面澄海基地与静海工业带批量生产结构件与舱段 |
| 模块发射 | 2051—2053 | 虹湾质量投射器分86批发射至地月L2门户站，累计发射约52,000吨 |
| 轨道转移 | 2052—2054 | 离子推进拖船与核热推进货船分批从L2转移至火星轨道，共34次转移任务 |
| 在轨组装 | 2053.03—2055.08 | 主桁架合拢、舱段对接、储罐安装、设备调试 |
| 联调与验收 | 2055.08—2055.09 | 全系统联调、48小时考核、竣工验收 |

## 三、设施组成

### 3.1 核心设施

| 设施 | 规格 | 功能 |
|---|---|---|
| 主桁架 | 1,200 m × 80 m × 60 m，碳纤维复合材料 | 港口主体承力结构，锚定火卫一 |
| 中央控制舱 | 直径12 m，长30 m，3层 | 港口运行控制、通信、导航 |
| 居住舱群 | 6个直径8 m、长20 m舱段 | 常驻人员居住（120人），含食堂、医疗、文娱 |
| 换乘中心 | 直径15 m，长40 m，2层 | 人员换乘、检疫、行李处理 |
| 货运仓储区 | 4个加压仓库（各5,000 m³）+ 露天桁架堆场 | 货物中转、分拣、暂存 |
| 推进剂储运库 | 液氧8,000m³ + 液氢2,000m³ + 甲烷3,000m³ | 深空船舶推进剂补给 |
| 维修船坞 | 2个（各可容纳200吨级船舶） | 船舶检修、维护、改装 |
| 太阳能阵列 | 15 MW（峰值），面积约45,000 m² | 港口主供电 |
| 核电源 | 2 MW RTG（4台500 kW） | 持续供电、应急电源 |

## 七、存在问题与后续计划

1. **推进剂原位生产能力不足**：当前港口推进剂全部依赖地球转运（经虹湾质量投射器→L2→火卫一），成本较高。计划2058年在火卫一表面建设水冰提取与电解设施（火卫一含水冰约5%—8%），实现推进剂原位生产，目标2062年自给率达60%。
2. **人工重力设施缺失**：港口常驻人员长期处于微重力环境（火卫一重力约0.0006g），骨密度与前庭功能退化风险较高。当前通过每日2小时离心机锻炼缓解。计划2057年在居住舱段增加小型旋转人工重力模块（半径15 m，0.3g）。
3. **火卫一轨道衰减**：火卫一轨道以约1.8 cm/年的速率衰减，预计5,000万年后坠入火星大气。对港口50年设计寿命无影响，但锚定系统需每年微调。已纳入港口长期维护计划。
4. **二期扩建规划**：根据吞吐量增长预测，计划2060年启动"福波斯-02"扩建工程，新增4个大型泊位与20,000 m³仓储容积，总吞吐量提升至200万吨/年。

## 八、启用首航安排

"福波斯-01"建成启用后，首艘靠泊船舶为地球—火星干线货船"远运-06"号（载重420吨），预计2055年10月8日抵达A-1泊位，卸载火星表面开发物资（含奥林匹斯山地下城市二期扩建设备与"太白-01"金星浮空城市补给转运物资）。

首艘客运飞船"远航-03"号预计2055年11月15日抵达A-4泊位，运送首批48名港口运营人员与12名火星表面轮换人员。
