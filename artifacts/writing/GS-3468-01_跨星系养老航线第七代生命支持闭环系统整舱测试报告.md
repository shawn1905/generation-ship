# 跨星系养老航线第七代生命支持闭环系统整舱测试报告

**编制单位**：联合体跨星系养老事务总署　**报告编号**：LSC-ELDER-7TH-3468-006　**密级**：跨星系公开

## 一、标定规格牌（贴于养老专用闭环整舱测试台管路柜）

| 项目 | 通用第七代 | 养老专用标定 |
|---|---|---|
| 氧分压波动余量 | ±2% | ±1% |
| 二氧化碳清除延迟 | 三十秒 | 十五秒 |
| 温湿度调节 | 通用 | 偏暖偏湿 |
| 冗余切换 | 单机 | 双机热备 |
| 故障告警到人 | 舱级 | 床位级 |

第七代生保闭环（见 GS-3375-01）原为长航程移民船设计，船上多是青壮年，耐受余量按青壮年标定。移植到养老航线，须按老人的生理特点重新标定——同一台闭环，量的是两种肺。

## 二、测试缘起

3451 年养老航线一次生命支持故障（见 GS-3474-01），无人员伤亡，却暴露通用闭环对老年人生理耐受的余量不足。那次靠总管卫慕（见 GS-3453-01）四十七分钟人工分流兜住。总署据此立项养老专用第七代闭环整舱测试。

## 三、设计边界·三层差异

| 层 | 老人与青壮年之差 | 标定动作 |
|---|---|---|
| 肺 | 肺泡弹性下降，同样的二氧化碳堆积，青壮年呼得掉、老人呼不掉，残气在肺里越积越多；呼出量小、清除慢，堆积更慢却更久，慢堆积更难察觉 | 清除延迟从三十秒压到十五秒 |
| 循环 | 对温湿度波动调节能力弱，舱里偏冷半度、偏干半成，青壮年无所谓，老人可能受凉 | 温湿度调偏暖偏湿 |
| 应急 | 反应慢，告警到了青壮年能自己动、老人动不了 | 双机热备自动切换 + 床位级直接告警到人 |

一句话记进规格牌：老人是设计边界。

## 四、故障注入测试记录卡（记录编号 LSC-ELDER-7TH-3468-注入）

| 注入故障 | 检出 | 处置 |
|---|---|---|
| 氧分压漂移 | ✓ | 设计指标内 |
| 二氧化碳堆积 | ✓ | 设计指标内 |
| 温湿度失准 | ✓ | 设计指标内 |
| 冗余切换 | ✓ | 设计指标内 |
| 单舱断电 | ✓ | 设计指标内 |

五类逐项勾选，全部在设计指标内被检出并处置，无一次漏检。技术组签认。

## 五、复现测试日志原行（模拟 3451 年那次故障）

> ＋6 秒　床位级告警触发（3451 年靠卫慕人工分流，历时四十七分钟）
> ＋8 秒　双机热备切换完成，不用人动
> 全程　三百一十二名测试用老人（模拟）生命体征读数无波动
> 仪表复核无异议。技术组签认，经办人存根归档。

这一代把人的四十七分钟，换成系统的六秒。不是不信人，是不能每次都赌一个人那天还在岗位上。

## 六、成本台账（登记簿编号 LSC-ELDER-7TH-3468-账）

| 项 | 数 |
|---|---|
| 整舱采购成本较通用版上浮 | 18%（主要来自双机热备与床位级传感器） |
| 十二条线换装合计 | 约星汇两亿四 |
| 列支 | 计入 3460 年养老床位互认制度（见 GS-3460-01）三年过渡投入，与床位扩容四万张一并安排 |

总署注明：上浮的 18%，买的是三百一十二位老人在六秒内被看见。3451 年那次人工分流是人命赌出来的余量，不该再赌第二次。床位是让人有地方去，闭环是让人去的路上活着到——两样一起办，才叫养老体系。

## 七、换装节奏与存量航线

| 批次 | 年份 | 条数 |
|---|---|---|
| 首批 | 3468 | 4 条 |
| 次批 | 3469 | 5 条 |
| 末批 | 3470 | 3 条 |

十二条养老航线分三批换装。换装期间新旧两套闭环并行一个航次，比对生命体征数据，偏差在允许范围后方可停运旧型。换装不搞一刀切，每一条线换完都要跑一个航次看着老人没事，才换下一条。

## 八、手动冗余（第三级）

故障注入中最极端的一次模拟是双机同时失效——概率极低，但一旦发生，养老专用闭环仍留第三级手动冗余，由随船医工手动切换。

总署注明：系统再自动，最后仍留一只人手。3451 年靠的就是这只手，这一代不打算去掉它，只是让它平时不用动、关键时刻还动得了。自动化不是把人赶走，是把人从守着机器的位置，挪到看着机器出事的位置。

## 九、附则

兹将本报告随养老专用闭环定型交付，3460 年起逐步换装十二条养老航线。养老航线的生保，不是把年轻人的闭环照搬过来，是把老人的身体当成设计边界。归档编号 LSC-ELDER-7TH-3468-006。
