# 主带谷神星一轨道转运站装卸机械臂脱落与泊位临时封闭事件报告

![图注：谷神星轨道转运站事故泊位 · 脱落机械臂与隔离索 · 档案体](../../world/生图集/717.webp)

**编制单位**：主小行星带自律城市群安全工程局
**事件对象**：谷神星第二轨道转运站三号泊位
**报告日期**：3217年5月11日
**密级**：跨星系公开

## 一、事件经过

谷神星第二轨道转运站为主小行星带与三系货运之重要中转（参见GS-2900年后主带城市群布局），三号泊位常年装卸标准协元模数货箱（见GS-3021-01）。3217年4月下旬，三号泊位一装卸机械臂在卸一箱铂族锭（见GS-3214-01）时，臂根主销轴疲劳断裂，机械臂上段脱落，斜倚于泊位外壁，未坠离转运站，亦未击中任何停泊飞船。当时泊位无人员在臂下作业，无人员伤亡。事发后三号泊位立即封闭，相邻两泊位改道。

## 二、时间线

| 时刻(协星历) | 事件 |
|---|---|
| 4-22 装卸中 | 机械臂异响，操作员急停 |
| 4-22 09:40 | 臂根销轴断裂，臂段斜倚外壁 |
| 4-22 09:55 | 三号泊位封闭，设隔离索 |
| 4-22—4-25 | 调轨道工程舱固定脱落臂段 |
| 4-26—5-02 | 更换销轴，全面探伤 |
| 5-03 | 三号泊位复检合格，恢复装卸 |
| 5-11 | 公布事件报告 |

## 三、原因初查

销轴已服役二十一年，超出设计检修周期三年。转运站原计划本年度列入换型，因货运繁忙（见GS-3028-01罗盘调度）一再推迟。断裂面显微观察呈典型疲劳扩展，非瞬时过载。操作员急停及时，为未造成坠离与人员伤亡之直接原因。

## 四、处置与整改

1. 三号泊位暂停装卸十二日，由轨道工程舱固定脱落臂段后更换销轴；
2. 转运站全部装卸机械臂销轴纳入寿命台账，超期一律停用；
3. 因货运繁忙而推迟检修之陋习，在本系统内通报批评；
4. 事件未致货运长期中断，相邻两泊位分流，跨系货运整体延误不超过两日；
5. 对当时操作员急停及时，予通报表扬。

## 五、无伤亡说明

本事件系"险肇事故"——未致伤亡，然性质严重。安全工程局强调：机械臂为轨道转运站之关键设备，销轴虽小，关系全泊位与停泊飞船之安全，不得以"忙"为由推迟检修。

## 六、转运站恢复与保险

三号泊位封闭十二日后恢复，相邻两泊位分流，跨系货运整体延误不超过两日。主带自律城市群安全工程局依航运保险规则（见GS-2935-01）向受影响货主理赔。断裂销轴送文枢工程实物库（见GS-3015-01）封存，作疲劳教学样本。

## 七、恢复与理赔

三号泊位封闭十二日后恢复，相邻两泊位分流，跨系货运整体延误不超过两日。主带安全工程局依航运保险规则（见GS-2935-01）向受影响货主理赔。断裂销轴送文枢工程实物库（见GS-3015-01）封存，作疲劳教学样本。转运站全系统销轴纳入寿命台账。

## 八、主带全系统整改

转运站全部装卸机械臂销轴纳入寿命台账，超期一律停用。"因货运繁忙推迟检修"之陋习在本系统内通报批评。本事件系"险肇事故"——未致伤亡，然销轴疲劳扩展之教训须记。

## 九、不忙忘检修

安全工程局强调：机械臂销轴虽小，关系全泊位与停泊飞船安全，不得以"忙"为由推迟检修。本事件系险肇事故，未致伤亡，然销轴疲劳之教训入训鉴。全系统销轴台账自此建立。

## 十、立卷说明

三号泊位封闭十二日后恢复，相邻两泊位分流，跨系货运整体延误不超过两日；主带安全工程局依航运保险规则（见GS-2935-01）向受影响货主理赔。断裂销轴送文枢工程实物库（见GS-3015-01）封存，作疲劳教学样本。安全工程局在卷末附言：机械臂销轴虽小，关系全泊位与停泊飞船安全，不得以"忙"为由推迟检修；本事件系险肇事故，未致伤亡，然销轴疲劳扩展之教训须记。全系统装卸机械臂销轴自此纳入寿命台账，超期一律停用。
