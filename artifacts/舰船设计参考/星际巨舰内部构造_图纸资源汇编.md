## 三、对星际巨舰设计的核心参考提炼

### 3.1 舱段布局的共性规律

从航母+潜艇+科幻飞船的图纸中提炼出的共性规律：

1. **纵向功能序列**：从前到后按功能排列舱段（指挥→居住→动力→推进），减少交叉运输
2. **垂直分层**：每层甲板有明确功能主题（飞行甲板→机库→居住→机械→底舱）
3. **核心舱居中**：关键系统（反应堆/指挥中心）放在船体中心，受保护
4. **人员区靠前/居中**：居住舱靠近指挥舱，远离引擎噪音和振动
5. **货舱/载荷舱独立**：与人员区隔离，有独立的装卸通道
6. **垂直交通节点**：电梯/楼梯集中在几个核心位置，连接各层甲板
7. **通道沿纵向贯通**：主走廊沿船体纵向，各舱室从走廊分支进入

### 3.2 太空船的特殊调整（基于"真空逻辑"）

| 现实舰艇 | 太空船调整 |
|---|---|
| 整体耐压壳体（潜艇） | 独立加压舱段胶囊，桁架连接 |
| 货舱加压（防止海水进入） | 货舱真空/开放式桁架，货物直接固定 |
| 外壳承重+抗压 | 外壳仅防护（微陨石/辐射），桁架承重 |
| 机舱封闭（隔音+防火） | 引擎区裸露（散热需要，真空只能辐射散热） |
| 舷窗少（抗压考虑） | 舷窗/观景台可多（内压向外，玻璃抗拉即可） |
| 压载水舱 | 燃料罐+辐射屏蔽水箱（兼做压载） |
