## 厚重感从哪里来？——拆解两种传统的"厚"

**教堂天顶画（西斯廷）的厚重**：
1. **叙事密度**——300+ 人物、9 个主画格，每个角落都有故事
2. **建筑幻觉框**——画格之间不是空白，是假建筑（先知、女先知、青年像坐在框上），框本身承载叙事
3. **光的神圣性**——中心格《创世纪》"要有光"，光是构图的原点
4. **时间的包浆**——湿壁画龟裂、金色氧化、蜡烛烟熏数百年

**浮世绘的厚重**：
1. **系列变奏**——富岳三十六景同一母题（富士山）在四季/远近/阴晴中反复出现，时间感来自"同一物的变奏"
2. **题跋与收藏印**——朱印层层叠盖，物理上的历史包浆
3. **名所绘的日常**——宏大风景里必有凡人生活（旅人、农夫、船夫）

## 融合方案：十格天顶 + 金缮裂痕 + 三代人血脉

### 1. 穹顶结构：十格天顶

```
        [先知·制度滞后律]  [先知·殖民地独立律]
[时代Ⅱ·军备重构]  [中心格·启航]  [时代Ⅳ·文明扩展]
[时代Ⅰ·白领冬天]  [先知·成本崩塌律]  [时代Ⅴ·星际尺度]
        [先知·冗余需求律]  [时代Ⅲ·后稀缺雏形]
```

- **中心格 = ARK-01 启航**——对应西斯廷的《创世纪》中心格。"神说要有光"转译为"引擎点火"：聚变脉冲的第一束光，是全画的光源原点
- **五个时代格**沿穹顶弧度排开——透视深度=时间深度：越靠近画面边缘（前景）越是 2025 的写实地球，越往穹顶中心越是抽象的未来
- **四个"先知格"**——四条规律拟人化，像天顶画的先知一样坐在画格之间：
  - 成本崩塌律 → 打算盘的老会计（旧经济）与捧着光的孩童（新能源）
  - 制度滞后律 → 追赶马车的人（法律追不上技术）
  - 殖民地独立律 → 斩断锚链的殖民地青年
  - 冗余需求律 → 把种子分装进许多陶罐的母亲

### 2. 画格边框 = 飞船结构件

不用石膏线、不用画框——**用 ARK-01 的结构件做格框**：环形骨架的弧段、铆钉、管线、检修舱门。教堂的建筑幻觉框变成飞船自身结构：画框即船体，历史被装在船里。边框上有维修痕——焊接疤、补丁板、不同年代的铭文（呼应《12-B 层》的刻字墙）。

### 3. ★ 金缮裂痕（核心创意）

整幅画布刻意做**龟裂纹理**，裂痕用**金线修补**——日本金缮（kintsugi）美学：
- 每道裂痕对应文明的一次断裂：AI 泡沫破裂（2027-30）、热战危机（2040s）、殖民地冲突（2080s）、船上大故障（2180s）
- 金缮哲学：**修补即历史，伤痕即装饰**——"这艘船的 200 年，就是不断修补的 200 年"
- 与已有创作一脉相承：《12-B 层》的刻字墙、《C 区的曲子》的"别修"——**维修是我们项目的母题**，金缮是它的视觉化

### 4. 题跋与朱印（包浆层）

- 每格角落一方篆字朱印：**冬 / 重构 / 雏形 / 扩展 / 启航**，中心格盖总印「舟」
- 画面留白处叠历代"收藏者"题跋——设定为未来各代人在这幅画上留下的题记（船上第 3 代题、第 7 代题……），物理包浆 = 历史沉积

### 5. 人物群像（三代人血脉贯穿）

每格有具体的人，且是**一家人**——家族血脉是时间轴的人性化锚点：
| 格 | 人物 |
|---|---|
| Ⅰ 白领冬天 | 失业的产品经理（父亲） |
| Ⅱ 军备重构 | 月球基地的机器人监工（儿子） |
| Ⅲ 后稀缺 | 栖息地管理员（孙子） |
| Ⅳ 文明扩展 | 殖民地独立宣言签署者（曾孙） |
| Ⅴ 星际尺度 | **阿芽、阿留**（船上维修员/音响管理员——已有角色资产入画） |
| 中心格 | 启航日，全家人历代肖像沿环壁排列（船上祭祖堂） |
