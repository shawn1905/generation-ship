# 🎵 世代飞船音乐实验

Strudel（[strudel.cc](https://strudel.cc)）在线作曲——把灵感笔记里的「飞船的声音设计」落成可听的曲子。

## 《C 区的曲子》· Sector C Suite (ARK-01, Year 137)

> 启航时设计师给每个舱段写了专属环境音乐。137 年后设备老化、音高漂移、循环错位，音乐在**变异**。船员习以为常的「C 区的脾气」，其实是一首正在腐烂的曲子。有一天有人从地球备份里听到「原版」——和现在的版本已完全不同。哪一个才是这艘船真正的声音？

### 四层结构

| 层 | 名称 | 含义 | 技术实现 |
|---|---|---|---|
| L1 | Earth Backup | 地球备份·原曲（干净、对齐） | 钢琴和弦 Am-F-C-G，无修饰 |
| L2 | The Decay | 第 137 年的活版本 | `slow(8.03)` 循环微拉长→与备份永不重合缓慢错位；`add(slow(32,range(-0.05,0.05)))` 音高慢漂移；`delaytime` 被拉扯；`sometimes(degradeBy 0.125)` 偶发丢音 |
| L3 | The Hull | 船体低鸣 | pads 低音垫，`add` 慢漂移模拟金属热胀冷缩 |
| L4 | The Pump | 农业环 3 号水泵 | 三角波琶音，偶发失稳像老水泵喘振 |

### 核心手法：循环错位（时间上的「腐烂」）

- L2 用 `slow(8.03)`：8 拍主题被拉成 8.03 拍，与 L1 每 100 循环差 3 拍——**100 年后就是完全不同的歌**，但每一刻听起来都几乎一样。这正是「渐变腐烂」的听觉隐喻。
- 音高漂移用 `slow(32, range(-0.05, 0.05))`：±0.05 半音几乎听不出，但 137 年积累下来就是另一个调。

## 技术备忘（复现/续写）

- 链接格式：`https://strudel.cc/#` + 标准 base64(URL 编码) 的完整脚本，可直接解码回源码。
- 本地校验：`npm i @strudel/core` 后需 stub 掉 `@kabelsalat/web` 的 `SalatRepl`（.mjs 缺该导出，Node 下加载失败），用 `--experimental-loader` 别名；再用 `evalScope(import('@strudel/core'))` 注入全部 mini 函数，`new Function` 显式 `return stack(...)` 求值，`pattern.queryArc(0,2)` 验证事件。
- 注意：Strudel 只播放**最后一条表达式**，多层必须包 `stack(...)`。
