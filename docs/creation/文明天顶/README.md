## 制作路线（已验证）

**混合路线**：seedream 生图出浮世绘底稿（4K）→ 手绘 SVG 装帧层（格框/金缮裂痕/朱印/题跋）叠加。

- 底稿提示词要点：浮世绘木版画、葛饰北斋、普鲁士蓝渐变、和纸底、粗黑轮廓线、平面色块、无透视阴影 + 方法论检查清单（主体锁死/极小尺度参照/单一光源/精准细节）
- 装帧层：金色双线格框+铆钉（飞船结构件）、金缮裂痕（从格框延伸）、朱印、题跋（历代题记=包浆层）
