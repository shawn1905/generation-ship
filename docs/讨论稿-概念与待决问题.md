# 世代飞船设计项目 · 概念讨论稿

> 版本：v0.1（kickoff 讨论用）
> 状态：概念论证阶段，待朋友讨论后拍板关键参数
> 目标：最终输出一艘宇宙飞船的**内外部完整结构**，可直接在 3D 软件（Blender / FreeCAD）中建模渲染

---

## 0. 项目背景与三条原则

设计一艘按 **200 年航行、到达一颗新行星** 规模设计的世代飞船。开工前明确三条原则：

1. **严谨的科技幻想**——每个数字都来自物理推导或可查证的研究，不做科幻/玄幻/金手指（没有超光速、没有惯性阻尼器、没有凭空能量）。
2. **尽量参考 GitHub 已有开源项目**，不随意编造。
3. **按"航行 200 年抵达新星球"的规模设计**——这不是一个可选项，而是整个设计的约束源头。

---

## 1. 核心判断：200 年这个约束，直接锁死了整个设计包络

世代飞船最迷人的一点是：**它不是"众多方案之一"，而是被时间常数逼出来的唯一解**。

```
200 年 + 到达"新行星"
  → 目标只能是 4~5 光年内的恒星（比邻星 b，4.24 ly）
  → 平均速度 ~0.021c，巡航 ~0.03c（9000 km/s）
  → 化学推进不可能（Isp 300~450 s）
  → 核热 / 核电推进也不可能（Isp ~10⁴ s，达到 9000 km/s 需要质量比 e⁹⁰ ≈ 物理不可能）
  → 唯一解：聚变脉冲推进（Daedalus / Longshot 谱系，Isp ~10⁶ s）
  → 制动质量比 e^(9000/9800) ≈ 2.5，可接受（这正是两级构型的由来）
  → 加速 ~15 年 + 巡航 ~170 年 + 减速 ~15 年 = 200 年
```

**重要推论：推进不是最难的问题。** 真正残酷的是另外两个：

| 难题 | 具体数字 | 结论 |
|---|---|---|
| 200 年累计辐射 | 舱内 GCR 若维持 0.5 Sv/yr，200 年累计 100 Sv，必死 | 必须 主动磁屏蔽 + 水屏蔽 + 风暴掩体 三者组合，是全船**最大不确定项**，需诚实标注 |
| 200 年零补给闭环 | 水/氧/氮 ~100% 闭环，食物 ~90%+ | 历史基准：苏联 BIOS-3 达 85% 闭环率；ESA MELiSSA 目标更高 |

## 2. 硬约束推导出的关键参数（量级已定，具体值可讨论）

| 项目 | 数值 | 依据 |
|---|---|---|
| 目标 | 比邻星 b，4.24 ly | 距太阳系最近的可疑岩质宜居行星 |
| 巡航速度 | ~0.03c（9000 km/s） | 200 年行程的算术必然 |
| 初始人口 / 抵达人口 | ~1000–2000 / 1–2 万 | 最小可存活种群 ~100–160 奠基者；殖民需 ≥500 |
| 栖息地 | 半径 250–500 m 环形/圆柱，双环反向旋转 | 1g 需 ω=√(g/r)，半径 300–500 m 时 ~1.2–1.9 rpm，科里奥利力可接受（NASA 标准 ≤2 rpm） |
| 推进 | 两级聚变脉冲（加速级 + 减速级）+ 末端磁帆辅助制动 | Daedalus（BIS 1978，54,000 t，0.12c）、Longshot（USNA 1988） |
| 功率 | 生命支持 + 工业 10–100 MW(e)；推进 GW–TW 级仅燃烧段 | — |
| 屏蔽 | 超导偶极主动屏蔽（GCR）+ 推进剂/水贮箱兼屏蔽层 + 中央风暴掩体（SPE） | 全船质量最大单项，需单独立项权衡 |
| 维护 | 辐射加固电子 + 冗余 + 机内 3D 打印/机加工 | 船内无法造芯片 → 容错设计是硬约束 |
| 前端防护 | Whipple 双层防尘盾 | Daedalus 研究过的 0.03c 星际尘埃侵蚀问题 |

**总体构型**（Daedalus 式"列车"布局）：

```
[前段载荷舱] → [中部双环旋转栖息地] → [外围水/推进剂贮箱兼辐射屏蔽] → [后段两级聚变推进 + 巨型散热器 + 磁帆]
     │                │                          │
  着陆器/前哨模块   居住/农业/生命支持/工业     Whipple 防尘盾在前端
```

## 4. 交付物与工作流（建议分四阶段）

每阶段都带"依据清单"（每个数字对应一个引用）——这就是"严谨科技幻想"的落地方式：

1. **Phase 0 需求与预算**：质量预算表、功率预算表、人口与农业面积核算（CSV + docs，用 OpenMDAO 思路交叉校验）
2. **Phase 1 概念架构 + 参数化外壳**：Blender Python 脚本，由 半径/长度/转速/质量预算 参数生成外壳、环形段、推进列车、散热器
3. **Phase 2 内部结构**：甲板分区（居住/农业/生命支持/工业/医疗/仓储）、走廊、双环内部布局，输出剖视图
4. **Phase 3 渲染**：材质、光照、Cycles 出图，OpenSpace 做星空背景

建议仓库结构：

```
generation-ship/
├── docs/          # 需求、权衡研究、引用清单（本文件所在）
├── design/        # 参数化脚本与导出文件
├── scripts/       # 预算核算、几何生成脚本
└── refs/          # 书目与链接
```

## 5. 待讨论的问题（决策点）

以下问题需要朋友讨论后拍板。每个都给出选项与利弊：

### Q1 目的地：锁定还是泛化？
- **A. 锁定比邻星 b（4.24 ly）**：数字最实，所有推导可闭环；但比邻星 b 本身有争议（可能被耀斑剥离大气）
- **B. 泛化"M 型矮星宜居世界"**：留创作空间，但每个数字都要重新假设
- **倾向：A**，但可把"耀斑环境下的设计应对"当作一个有意思的工程挑战点

### Q2 人口规模：1000 初始 → 1 万抵达，这个量级可以吗？
- 更小（500 初始）：栖息地尺寸小一半，但遗传多样性压力大（最小可存活种群 ~100–160）
- 更大（5000 初始）：更像"文明方舟"，但质量/功率/农业面积翻倍
- **倾向：1000 → 1 万**，这是工程可行性与社会可行性的平衡点

### Q3 保真度：概念级还是渲染级？
- **概念级 CAD**：外形 + 分区示意，快，适合先讨论
- **渲染级细节**：内部可漫游，出图震撼，工作量指数上升
- **倾向：先概念级，确认方向后再升级**

### Q4 是否要求可 3D 打印？
- 影响结构设计约束（壁厚、分件方式、公差）
- **倾向：是**，会让模型天然"工程化"，也方便朋友拿到实物

### Q5 社会学维度要不要纳入？
- 代际传承、教育、文化、船内政府形式——Finney & Jones 有大量文献
- **倾向：纳入 docs 但不进入 3D 模型**，作为背景设定文档
