| 电影/剧集原始数据 | IMDb 官方非商业数据集（title.basics + title.ratings，2025-08 快照） | https://datasets.imdbws.com/ |
| 游戏原始数据 | Steam 2024-10 全量快照（games/genres/tags/reviews/steamspy） | https://github.com/NewbieIndieGameDev/steam-insights |

| 原画/设定集 | 人工精选（ArtStation 社区知名概念艺术家 + 官方设定集）→ 维基 REST 核验 + Goodreads 封面 | en.wikipedia.org / goodreads.com |
