# 科幻素材库（2000+）· 世代飞船设计参考

> **分支收集工作产出**：2000 年以后的科幻电影 / 剧集 / 游戏，按内容与评价整理，服务于世代飞船设计主线。

## 0. 收集方法与数据源（可复现）

| 步骤 | 说明 | 数据源 |
|---|---|---|
| 电影/剧集原始数据 | IMDb 官方非商业数据集（title.basics + title.ratings，2025-08 快照） | https://datasets.imdbws.com/ |
| 游戏原始数据 | Steam 2024-10 全量快照（games/genres/tags/reviews/steamspy） | https://github.com/NewbieIndieGameDev/steam-insights |
| 精选策略 | 人工代表作清单 + 数据核验（评分/票数/好评率），非自动全量 | — |
| 海报/封面 | IMDb suggestion JSON API + Steam CDN，本地缓存 | https://v2.sg.media-imdb.com/ |
| 复现脚本 | `branch/scripts/`（make_* 原始过滤 → curate_* 人工精选 → download_images → make_gallery/docs） | 本仓库 |

> **重要发现**：IMDb 类型标签不可靠（Avatar/Blade Runner 2049/Ad Astra 均未标 Sci-Fi），故精选用"人工清单 + 全量候选池匹配"而非纯标签过滤。

## 7. 评价指标说明

- **电影/剧集**：IMDb 评分 + 投票数（数据集中 `title.ratings`）
- **游戏**：Steam 好评率 + 评价总数（steam-insights `reviews.csv`），另有 SteamSpy 估算玩家数
- **精选门槛**：人工清单为主；自动档参考阈值 电影≥5000 票、游戏好评率≥80% 且评价≥1000 或玩家≥20 万
