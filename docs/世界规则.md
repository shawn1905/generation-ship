# 世界规则（内核 v1）

> **本项目的本体不是任何一件作品，而是这套规则。**
> 一切内容——飞船、短篇、伪档案、画、音乐、素材策展——都是这套规则下的产物（插件）。
> 架构原则（用户 2026-08-14 定调）：**坚硬内核 + 无限插件**。内在逻辑要硬，适应性要强。
> 规则宁可少而硬，不可多而软。每一条都必须能用来裁决「这件产物合不合法」。

---

## 一、物理规则（不可违背）

1. **无金手指**：一切技术设定来自物理推导或可查证的研究/开源项目。不允许科幻式便利（FTL、冬眠、人工重力黑科技、室温超导）。
2. **时间与距离是真实成本**：比邻星 b 4.24 光年 = 200 年航程。没有捷径，一切戏剧性必须在这个成本结构内生长。
3. **反奇点备忘**：若某项黑名单技术（冬眠/意识上传/室温超导）被引入，属于内核级版本变更，必须全轴回算，不允许局部例外。

## 二、历史规则（时间轴动力学）

1. **循环律**：技术不是平滑上升——泡沫→破裂→衰退→博弈→重建。
2. **博弈律**：巨型工程不由繁荣驱动，由大国博弈驱动（阿波罗逻辑：不图赚钱，图不能输）。
3. **离心律**：距离 × 自给自足 = 独立倾向。凡殖民地/飞船/前哨，迟早与母体产生政治张力。
4. **改元律**：纪元不按时间均分，按文明处境的突变改元；纪元名后世追认，当事人只觉得自己在过日子。
5. **七纪元**（v2 版）：替代（2025—35）→ 竞赛（2035—50）→ 丰裕（2050—80）→ 离心（2080—2150）→ 启航（2150—2350）→ 落地（2350—2500）→ 双星系（2500—3000+）。

## 三、叙事规则（创作纲领）

1. **无冲突史诗**：不依赖激烈矛盾、伟大道德观、闪耀人格。历史车轮前，主观皆渺小。
2. **局部观察**：作品只呈现局部，但任何细节挖进去都必须连着整个世界（世界密度）。
3. **分形自洽**：枝叶自由生长，年轮必须对上主干——新产物不得与既有物理/历史/正典矛盾；矛盾即返工或改写主干（走内核版本变更）。
4. **档案馆美学**：中性、克制、程序化冷静。情绪来自文体与内容之间的裂缝，真相埋在文件与文件的缝隙里。作者隐退，读者当研究员。**文体取「文件口吻」而非「百科口吻」**（2026-08-14 用户定调，对照 Orion's Arm 百科体后确认）：产物是世界运转中**产生的纸**（报告/日志/工单/备忘录/数据表/刻痕），片面、留白、自称合法；不做全知解释。**视角共时性**（2026-08-14 用户定调，对照 All Tomorrows 后确认）：产物必须是「当时人留下的纸」——写的人不知道结局；禁止「回望者」叙述（未来学者解说词亦在其列）。回望只允许存在于元框架（如纪元名由后世追认），不进入作品本体。
5. **双轨时间**：官方时间与民间时间的消长是合法且鼓励的素材（倒计时照走，读者渐无）。

## 四、插件接口（如何在此世界下产出内容）

**合法性三问**（任何新产物过一遍）：
1. 违反物理规则吗？（→ 违规则返工）
2. 能定位在时间轴/纪元/双轨时间上吗？（→ 不能则说明是孤儿，需补锚点）
3. 遵守叙事规则吗？（→ 尤其：有没有偷偷依赖戏剧冲突撑场子）

**产物形态不限**：设定文档 / 短篇 / 伪档案 / SVG / 生图 / 音乐 / 工程模型 / 素材条目 / 数据表……载体自由，规则统一。

**生长路径**：灵感 → 记入 `creation/灵感笔记.md` → 展开成稿 → 回填主干（与既有作品互锁）。

**升格机制**：若某件产物揭示了一条**通用规律**（不只适用于它自己），该规律升格进内核，版本号 +1。内核只能这样长大——从产物里长出来，不凭空加。
