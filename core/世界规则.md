# 世界规则（内核 v1）

> **本项目的本体不是任何一件作品，而是这套规则。**
> 一切内容——飞船、短篇、伪档案、画、音乐、素材策展——都是这套规则下的产物（插件）。
> 架构原则（用户 2026-08-14 定调）：**坚硬内核 + 无限插件**。内在逻辑要硬，适应性要强。
> 规则宁可少而硬，不可多而软。每一条都必须能用来裁决「这件产物合不合法」。

---

## 一、物理规则（不可违背）

1. **无金手指**：一切技术设定来自物理推导或可查证的研究/开源项目。不允许科幻式便利（FTL、冬眠、人工重力黑科技、室温超导）。
2. **时间与距离是真实成本**：比邻星 b 4.24 光年 = 200 年航程。没有捷径，一切戏剧性必须在这个成本结构内生长。
3. **反奇点备忘**：若某项黑名单技术（冬眠/意识上传/室温超导）被引入，属于内核级版本变更，必须全轴回算，不允许局部例外。

## 二、历史规则（时间轴动力学）

1. **循环律**：技术不是平滑上升——泡沫→破裂→衰退→博弈→重建。
2. **博弈律**：巨型工程不由繁荣驱动，由大国博弈驱动（阿波罗逻辑：不图赚钱，图不能输）。
3. **离心律**：距离 × 自给自足 = 独立倾向。凡殖民地/飞船/前哨，迟早与母体产生政治张力。
4. **改元律**：纪元不按时间均分，按文明处境的突变改元；纪元名后世追认，当事人只觉得自己在过日子。
5. **七纪元**（v2 版）：替代（2025—35）→ 竞赛（2035—50）→ 丰裕（2050—80）→ 离心（2080—2150）→ 启航（2150—2350）→ 落地（2350—2500）→ 双星系（2500—3000+）。

## 三、叙事规则（创作纲领）

1. **无冲突史诗**：不依赖激烈矛盾、伟大道德观、闪耀人格。历史车轮前，主观皆渺小。
2. **局部观察**：作品只呈现局部，但任何细节挖进去都必须连着整个世界（世界密度）。
3. **分形自洽**：枝叶自由生长，年轮必须对上主干——新产物不得与既有物理/历史/正典矛盾；矛盾即返工或改写主干（走内核版本变更）。
4. **档案馆美学**：中性、克制、程序化冷静。情绪来自文体与内容之间的裂缝，真相埋在文件与文件的缝隙里。作者隐退，读者当研究员。**文体取「文件口吻」而非「百科口吻」**（2026-08-14 用户定调，对照 Orion's Arm 百科体后确认）：产物是世界运转中**产生的纸**（报告/日志/工单/备忘录/数据表/刻痕），片面、留白、自称合法；不做全知解释。**视角共时性**（2026-08-14 用户定调，对照 All Tomorrows 后确认）：产物必须是「当时人留下的纸」——写的人不知道结局；禁止「回望者」叙述（未来学者解说词亦在其列）。回望只允许存在于元框架（如纪元名由后世追认），不进入作品本体。
5. **双轨时间**：官方时间与民间时间的消长是合法且鼓励的素材（倒计时照走，读者渐无）。

## 四、插件接口（如何在此世界下产出内容）

**合法性三问**（任何新产物过一遍）：
1. 违反物理规则吗？（→ 违规则返工）
2. 能定位在时间轴/纪元/双轨时间上吗？（→ 不能则说明是孤儿，需补锚点）
3. 遵守叙事规则吗？（→ 尤其：有没有偷偷依赖戏剧冲突撑场子）

**产物形态不限**：设定文档 / 短篇 / 伪档案 / SVG / 生图 / 音乐 / 工程模型 / 素材条目 / 数据表……载体自由，规则统一。

**生长路径**：灵感 → 记入 `artifacts/灵感笔记.md` → 展开成稿 → 回填主干（与既有作品互锁）。

**空隙产物（2026-08-15 增补）**：任务执行中产生的即兴创作——资料收集时的日记、脚本跑批时写的一小节曲子、等待生图时的一张随笔——是**合法且鼓励**的产物形态。特性：即兴、小、不做大规划；价值在于**世界密度**（即兴产物常是主任务规划不出来的角落，如 12-B 层、C 区的曲子、文明天顶都源于此）。流程同生长路径：随手记 → 展开成稿 → 回填主干 → 定位到格子。**规则不豁免**：仍须过合法性三问、视角共时性、无元层词——空隙只是「形态来源」，不是「规则例外」。

**升格机制**：若某件产物揭示了一条**通用规律**（不只适用于它自己），该规律升格进内核，版本号 +1。内核只能这样长大——从产物里长出来，不凭空加。

## 附录 · FTL 备忘录（为何「无超光速」是物理而非偷懒）

> 2026-08-15 增补。本附录给内核「无 FTL」条款背书，同时为创作保留「超光速失败史」的素材空间。
> 判定原则：**数学缝隙存在，物理量级绝望。** 它需要的是「控制宇宙尺度能量」——不是工程问题，是常识问题。

### 1. 为什么「加速到光速」不可能

狭义相对论：有质量物体 E = γmc²，γ 随速度趋向光速而趋向无穷。**达到光速需要无穷能量**——这不是技术瓶颈，是数学死路。

### 2. 四个理论候选（都是广义相对论的「缝隙」，不是伪科学）

| 方案 | 原理 | 现实性 | 死结 |
|---|---|---|---|
| 曲率引擎（Alcubierre） | 压缩/拉伸飞船前后的时空，飞船靠时空泡移动 | 数学可行（1994），物理绝望 | 需负能量/奇异物质；泡内外信息传递存在因果问题 |
| 虫洞（Morris-Thorne） | 两时空点间的捷径 | 数学可行（场方程允许） | 需负能量撑喉；防塌陷；无宏观证据 |
| 额外维度 | 弦论允许额外维 | 卷曲在普朗克尺度（10⁻³⁵ m） | 宏观物体无法利用 |
| 量子纠缠 | 科幻最常误用 | **不传信息**（No-communication 定理） | 纠缠传相关不传因果（Bell 实验已证） |

### 3. 唯一一线「不是纯幻想」的理由，以及它的绝望量级

- **负能量并非零证据**：卡西米尔效应（真空零点能的真实测量）确实在实验室产生过负能量密度——这让曲率引擎不是纯伪科学。
- **但量级是宇宙学级**：撑一个可用曲率泡所需负能量 ≈ 整个可见宇宙的能量密度量级。**不是造不出来的机器，是「人类无法控制宇宙尺度的能量」的常识问题。**
- 暗能量（宇宙学加速膨胀）本身是负压力，但被钉在宇宙学尺度，无法局部操控。

### 4. 对世界创作的意义

1. **禁 FTL 是物理的，不是偷懒**——数学我们引用（严谨科技幻想：讨论它，然后否定它），死结在物理量级。
2. **题材空间（强烈推荐）**：双星系纪元（2500—3000+）或更远，人类反复尝试曲率引擎/虫洞，每次都在「负能量量级」面前失败，留下的文献堆成山——**「负能量项目的纪念碑」**。它完全符合无冲突史诗：不是没人试过，是试了一千年，物理没让步。
3. **反奇点备忘联动**：若某产物引入 FTL，属内核级版本变更，必须全轴回算（如「若 2700 年曲率引擎成功，则 ARK-01 的 200 年航程失去意义」——所有既有产物全部重审）。
4. **「低速已足够」的叙事立场**：0.03c 聚变脉冲 + 千年尺度扩散，本身就是文明的常态；FTL 是物理学范式的革命（相对论推翻牛顿那种），不存在「造出机器」的渐进路径。
