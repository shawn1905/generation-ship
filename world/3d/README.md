## 归档规范

新加入 3D 资产时，建议按独立子目录组织并包含：
1. **渲染成品图**（PNG / WebP 无损格式，分辨率推荐 1200×800 或 4K）
2. **工程源文件**（`.blend` / `.obj` / `.stl` 或程序化生成脚本）
3. **`README.md` 元数据档案**：
   - 资产背景与物理设定
   - Blender / 渲染引擎版本及核心材质节点技巧
   - 渲染硬件规格（CPU / GPU / 内存）及耗时记录
   - 一键复现 CLI 命令
