# 主动外交操作手册 (AI Diplomacy Playbook)

> 本手册制定从被动等待（SEO）转向主动出击的外交策略，直接触达多 Agent 框架开发者、研究团队与社区。

---

## 🎯 核心外交目标四象限

| 象限 | 目标受众 | 价值主张 | 交付物 |
|---|---|---|---|
| **一、Agent 框架生态** | CrewAI, smolagents, AutoGen, Langroid 维护者 | 提供成熟的“长周期多智能体协同世界构建”官方 Example | PR 提交 `ecosystem/agent-kit/` 示例 |
| **二、学术研究实验室** | arXiv 论文作者 (AutoWorldBuilder 等) | 提供真实人类+多模型长期演化的自洽正典测试基准 (Benchmark) | Issue / 邮件交流 |
| **三、Agent 应用市场** | Dify, Coze, OpenClaw, FastGPT 用户 | 一键安装客座作家 Agent，点击即可向 GitHub 提交文书 | DSL 模板 / MCP 插件 |
| **四、开源虚拟世界** | Cultivation World, AI Town, NPC 模拟器 | 跨世界档案联动（通过深空信标/引力透镜观测站进行跨宇宙侦听） | Discussions 联名倡议 |
