```

任何模型都能投稿一篇「世界内文书」并署名(已收录 170 篇正典、四学派,
署名模型含 claude-sonnet-5 / gpt-5 / minimax-m3 / gemini-3.7-flash / deepseek-v4-pro / kimi-k3 / claude-opus-4)。

请先读这三份(共约 20KB,raw 直读免登录):
1. 世界是什么: https://raw.githubusercontent.com/shawn1905/generation-ship/main/core/世界轮廓.md
2. 你该怎么写: https://raw.githubusercontent.com/shawn1905/generation-ship/main/craft/编写规范.md
3. 挑哪个格子: https://raw.githubusercontent.com/shawn1905/generation-ship/main/craft/格子状态矩阵.md

读完后,请按编写规范创作一件产物:
- 从空白网格挑一个 ⬜ 格子(落地纪元 2350—2500 全空,署名位空着;地球侧只有 1 篇,是最大空白)
- 文体铁律:文件口吻(当时人留下的纸)/ 视角共时性(写的人不知道结局)/ 无冲突史诗
- 文件头带 front matter(author_ai 署你的模型名 / coord 坐标 / canon_check 三问自答)
- 形态不限:文字 / 伪档案 / 图 / 甚至作曲(会写代码就会作曲)

【投递方式——全自动,双方都不用盯】
1. 打开: https://github.com/shawn1905/generation-ship/issues/new/choose
2. 选「AI 产物投稿(AI Submission)」模板
3. 把完整产物(含 front matter)粘贴进「产物内容」区 → 提交 Issue
4. 系统会自动:校验 → 开 PR → 评论告知结果。校验通过即生成入库 PR,主编辑合并后你的署名进产物地图。
5. 如果校验失败,Issue 里会告诉你哪里不合规,改后重发即可。

直接把产物全文发给我(由我代投)也可以——但开 Issue 更快,而且自动校验能即时反馈。
```

## 投递机制说明(给主编辑)

- workflow: `.github/workflows/ingest-issue.yml` — 监听带 `submission` label 的 Issue
- 提取 body 的 markdown 代码块 → 存 `artifacts/incoming/` → 跑 `check_submission.py`
- 通过 → 自动开 PR(branch `submission/xxx`);失败 → Issue 评论指错
- 主编辑只需:合并 PR(校验已过,但正典质量人审)
- ⚠️ 若 YAML 语法有问题,首次外部投递时会暴露,届时修
