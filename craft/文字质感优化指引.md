# 文字质感优化指引（P2 · 文学层工艺）

> 补足 `编写规范.md`（管合法）之外的**质感**维度：一篇文书合规，不等于它有生命。
> 本指引由全库 1520 篇质感诊断（`scripts/canon_texture.py`）驱动，附三篇已入库范本。
> 版本 v1 · 2026-09-16。修订走 `多AI共创协议.md` §5。

## 0. 一句话诊断

全库合规率高、元数据干净，但**质感中位仅 68/100，四维里"物证钩子"均值只有 4.7/25**——这是最大的短板。多数篇章是「制度密度」而非「世界密度」：讲满了规则，却没留下一张能让人摸到的纸。留白（23.9）、破模板（24.0）其实不差，问题集中在**物证缺席**与**声音单一**。

> 核心命题：**档案体不是把制度写清楚，而是让制度从物证里渗出来。**

## 1. 四个杠杆（各 25 分，`canon_texture.py` 可量化）

### 杠杆一 · 物证钩子（最重要，全库最缺）
一篇文书至少锚定**一个具体、可触、带使用痕迹的物证**，让抽象制度落在它上面。

- ✅ 该写：一枚磨平的签名章、一张连超标三夜的夜眠记录、一份签名涂改旁注"代签，本人目疾"的联名册、一条 `09-16 03:41 网络波动，服务降级` 的运行日志原行、一把储物间钥匙的交接登记、一张译员初签的抽检卡。
- ❌ 别写：`建立了完善的XX体系`、`取得了长足发展`、`反映了收尾阶段`。
- 手法：把"结论"换成"凭证"。不说"调解成功"，给出**调解会签字件**（谁签、签了什么、专员批"调解成立"）。

### 杠杆二 · 留白
公文的力量来自"没写完"。删掉解释性尾段，只给处置、不给动机；只给数据、不给结论。

- ❌ 过度解释标记（诊断器会数）：因为 / 所以 / 因此 / 这意味着 / 旨在 / 由此可见 / 综上所述 / 值得一提的是。
- ✅ 让读者补全：`日志无备注栏——重试既成，无需人过问。`（一句留白，胜过三段解释）
- 铁律：**同一规则全篇只出现一次**；要呼应就用档案编号互引（`见 GS-XXXX-NN`），不要重抄。

### 杠杆三 · 破模板
禁止连续篇章共用同一套章节骨架。诊断器对以 `## 一、系统概述/建档缘由/事件概况/立法缘由/总则` 开篇者判低分。

- ✅ 用**文书形态本身**当骨架，而非"一二三四"通用标题：
  - 决算 → 收支总表 + 一张扫描工单存根 + 传输日志原行
  - 事件通报 → 联名件物证登记 + 处置时刻表 + 调解签字件
  - 技术规格 → 贴在机柜上的规格牌 + 值班表 + 抽检卡
  - 人事 → 档案袋目录 + 考绩考勤 + 申请单三段式 + 死亡通报
- 不同学派配不同形态：工技用带公差与磨损读数的检修单，商贸用对冲结算流水，科医用体征曲线与用药台账，官档用任命令与签批链。

### 杠杆四 · 声音
对抗"一个模型写 74%"的均质。给文书一个**执笔岗位的腔调**，并让句长有起伏。

- 世界内公文腔：兹 / 查 / 奉 / 照准 / 准此 / 此令 / 特此 / 签名略 / 经办人 / 值班工程师签认。
- 允许一句克制的"岗位按语"收尾（去英雄化、不回望）：
  > 调查科注：本案无胜负。三十一人与二十七人，末了共用一间屋、一把钥匙。满意度三点九与三点六，都不是满分，也没人再要求调整。档案记到此为止。
- 句长要参差：长句给数据，短句给judgment。全篇等长句 = 机器节奏。

## 3. 怎么用（创作与返工流程）

1. **定位**：`python3 scripts/canon_texture.py --top 40 --csv /tmp/tex.csv`，从"最扁平方阵"里挑（优先 `证`(物证)列为 0—2 者）。
2. **诊断单篇**：看四维哪一维低——`证`低就加物证钩子，`模`低就换文书形态骨架，`白`低就删过度解释，`声`低就加岗位腔与句长起伏。
3. **改写纪律**（与去英雄化返工同）：**保留全部事实锚点**（人名/年代/职务/数据/事件/互引编号）与 **coord 坐标切片不动**；只改标题口吻、正文质感、必要时按形态重排结构。
4. **复检**：`canon_texture.py` 看质感分是否上去，`check_submission.py` 看是否仍合规、无红线，`canon_health.py` 看无新增刷屏/残句。
5. **不要**：为凑物证而虚构与既有正典矛盾的细节；物证须与本卷数据自洽（残陶口径、日志时刻、抽检卡编号都要对得上）。

## 4. 边界

- 本指引只管**质感**，不放宽任何红线：视角共时性、无元层词、去英雄化、无金手指、合法性三问，一条都不能少（见 `编写规范.md` §2/§6）。
- 即兴不等于粗糙，留白不等于删信息：删的是**解释**，留的是**事实与凭证**。
- 质感优化是日常编辑（不改坐标轴），主编辑可随返工执行，不走升格；但若沉淀出通用新规律，走 `编写规范.md` §5 升格。
