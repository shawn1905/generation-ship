> **「让宇宙显大的不是写了多少个 epic，而是观众能否在 1 秒内看懂：人有多小，物理有多硬。」**  
> 本文件是《世代飞船》多 AI 共创世界的视觉资产生成与评审规范。一切配图、概念画、3D/渲染、插画均须遵守本规范。

## 一、 核心视觉美学哲学（“那个作图的感觉”）

《世代飞船》的视觉语言拒绝轻浮的流行赛博朋克与流线型软科幻，追求**「重工业机械理性 + 宏大尺度压迫 + 真实物理质感」**的工程档案感。

### 1. 尺度对比铁律（Macro vs Micro）
* **微小参照物锚定**：画面必须包含极小的具体尺度参照物（如 3m 级检修艇、轨道穿梭机、宇航员、窗前驻足的人），其比例要小到近乎微尘，用反差彰显万吨级巨构。
* **天体与巨构出画（Framing Cut）**：环形飞船、行星地平线、戴森云或天井结构一般不强求全部塞入画面，可切出画幅边缘；正典物证或工程全貌图按用途保留整体，让想象力去填补未见的全貌。
* **分形密度（Fractal Detail）**：近看是窗格、管道、铆钉与水培梯田，远看是浩瀚的城市网格与行星弧线，杜绝大面积无纹理的平滑假面。

### 2. 光影与光学物理（Brutal Light & Optics）
* **单一主导硬光**：真空中没有大气散射形成的普遍填光；整体由一处有物理来源的主光控制，允许天体／结构反射和局部施工、检查、生活照明。焊接瞬态亮点不能被“单一主光”误禁；严禁无来源的多彩环境光。
* **尘光与丁达尔效应（God Rays）**：光束穿过厚重石英采光窗、气闸或中枢天井时，在加压舱内漂浮的微尘与气溶胶中形成雄浑清晰的定向光柱。
* **大动态范围反差**：光照面极其硬朗清晰，背光面深沉克制，在深空纯黑背景前形成雕塑般的剪影。

### 3. 材质与历史磨损（Industrial Textures）
* **机械与工业实体感**：外壳呈现耐高温防辐射涂层、铸造接缝、模块化装甲板、散热肋片、外露桁架。
* **岁月与环境痕迹**：带有微陨石擦痕、工质消蚀、金属氧化与结霜痕迹，拒绝光滑如塑料玩具的概念车漆面。

## 二、 提示词结构与工程公式

所有生图必须遵循以下骨架配方（中英双语）：

```text
[主体锁定] + [极小尺度参照物] + [构图出画/机位镜头] + [单一主光源/尘光] + [真实工业材质细节] + [摄影风格锚定] + [Negative 负向词过滤]
```

### 1. 常用镜头与风格锚定词
* **大画幅工业质感**：`IMAX 70mm, shot in the style of Hoyte van Hoytema, Christopher Nolan space epic aesthetic`
* **深邃光影与纪实感**：`Arri Alexa Mini, cinematography by Roger Deakins, extreme high dynamic range, chiaroscuro`
* **太空复古油画质感（典藏风格）**：`Classic sci-fi concept art, style of John Berkey, Chris Foss, Syd Mead, rich gouache and oil painting texture, fine particulate grain`
* **虚幻渲染/次世代工业**：`Unreal Engine 5 architectural render, hyper-detailed mechanical greebles, 8k resolution, crisp focus, clean maximalism`

### 2. 负向提示词清单（Negative Prompt 必带）
```text
cyberpunk neon glow, glowing outlines, purple on dark neon, smooth plastic hull, toy spaceship, flat lighting, empty low-poly surface, lens flare spam, oversaturated magical nebula, cartoon anime style, blurry, overexposed, messy clutter
```

## 六、 生图算力与配额调用全局操作规范（Rate Limit & Token Efficiency Discipline）

为确保全库视觉资产的高效产出、杜绝算力浪费与突发限流，所有 AI Agent 与协作主编辑在调用生图工具（`generate_image` / `seedream` / `gemini-image`）时必须遵守以下全局操作纪律：

### 1. 配额模型与滑动窗口认知（Sliding Window & Token Bucket）
* **4～5 小时动态恢复桶**：云端图像生成算力按固定滑动窗口（约 4～5 小时）分配并发与总额度（单窗口约 10～15 张大图）。
* **多轨解耦安全原则**：生图算力与代码编写、文本推理（`gemini-3.7`）属于独立配额轨道。**生图冷却绝不阻断文本创作、架构治理与工具链操作**。

### 2. 拒绝盲目批量轰炸，推行「单图极致化」（One-Shot Precision）
* **严禁无准备的批量盲发（No Blind Spray & Pray）**：严禁在未精确设定提示词的情况下，连续并发派发 10+ 张生成任务，这会同时触碰瞬时并发速率（RPM）与窗口总量硬顶（RPW），导致过早进入数小时冷却。
* **先调提示词，后触发渲染**：必须先在 [全量文书配图规划与超级提示词方案库.md](全量文书配图规划与超级提示词方案库.md) 中完成物理约束、法证标尺、光源与负向词的推演，争取**单次出图即定稿**。

### 3. 有节律的串行调用原则（Staggered Cadence）
* **小批次串行推进**：推荐以 **单次 3～5 张** 为一个创作小批次，生成后立即目检、命名并完成 Git 入库。
* **利用滴灌平滑恢复**：串行调用给令牌桶留出微量恢复空间，配合全天早中晚的节奏推进，可将单日有效高保真大图产能提升至 **30～40 张/天**。

## 七、 图像资产存储与 Git 仓库防膨胀铁律（Asset Storage & Repository Hygiene）

随着世代飞船正典与配图数量持续扩充（全域 270+ 篇正典全带图闭环），为杜绝 Git 仓库体积恶性膨胀、保障 GitHub 远端托管健康度与各节点快速拉取，所有入库图像资产必须严格遵守以下两条操作铁律：

### 1. 格式铁律：优先使用 WebP 格式，以画面质量为首要验收标准
* **格式优先选择 WebP**：新配图统一优先采用 `.webp` 格式。在同等视觉保真度下，WebP 体积仅为标准 JPEG 的 60% 左右、PNG 的 20%~30%，可从源头削减 40%~70% 的存储负担。若出图工具仅输出 JPG/PNG，入库前应经轻量高保真压缩转为 WebP。
* **画面质量为首要验收标准（体积不设硬性上下限）**：
  * 单张配图的验收以**画面质量**为首要标准——清晰度、细节丰富度、构图尺度对比、物理合理性、与文书内容的图文互锁度。体积仅作参考，**不设 300KB~1MB 硬性区间**：画面简单、色块纯净的图自然体积小（可低至 100KB+），细节密集、纹理复杂的图自然体积大（可超 1MB），均属正常。
  * 长边分辨率维持在 **1600px ~ 2048px**，杜绝无意义的 4K/8K 巨幅原图入库。
  * 压缩质量参数根据画面内容灵活选择（WebP q75~q95 均可），以人眼不可察觉压缩损失、关键细节（金属纹理、焊缝、舷窗、仪表读数）清晰可辨为度，不设固定质量百分比。
* **单文件硬红线**：严禁提交单文件 > 50MB（触发 GitHub 告警警告）以及 > 100MB（触发 GitHub 物理拦截拒绝）。严禁向仓库提交未压缩 RAW 原片、分层 PSD 文件或未压缩视频。
* **避坑认知：坚决不使用 Git LFS**：GitHub 免费配额仅有 1GB 存储空间与 1GB/月 下行带宽。若采用 LFS，多节点 pull、Actions 构建或多人 clone 会在极短时间内耗尽下行配额，导致全库资源拉取瘫痪。保持在标准 Git 仓库内通过 WebP 瘦身是零成本、最高健壮性的最佳工程解。

### 2. 提交纪律：严禁“覆盖式修改”频繁提交大图，必须本地定稿后再行入库
* **底层原理认知**：Git 的底层机制是不可变对象快照（blob）。对同一张 1MB 的图片，如果仅为了微调对比度、裁切边缘而在 Git 中连续修改并提交 5 次，`.git/objects` 历史库中就会永久固化 5 个完整的二进制快照，净增 5MB 且无法随日常 pull 释放，导致仓库历史体积成倍暴增。
* **工作流隔离原则**：
  * **生图与调优在本地草稿目录隔离完成**：AI 出图、重采样、二次扩图、画质打分、色调微调与格式转换，必须在本地未跟踪的草稿目录（如 `draft_concept_art/` 或临时目录）中完成。
  * **一锤定音，单次提交**：只有当配图完全符合《视觉规范》全部质检标准、图文互锁校验通过、且确认为正典最终物证后，方可移入 `world/生图集/`，并执行**唯一的单次入库 commit**。
* **禁止无实质意义的二次翻新**：已经合入正典并入库的历史配图，非灾难性质的严重事实性穿帮，严禁频繁推翻并覆盖式替换。若确需更换，必须经过主编辑审核并权衡历史体积增量代价。

### 八项强制质检清单

适用范围：以下巨构与载具条目按§十、§十一解释。人物／物证近景采用相应尺度参照；无人设备不要求载人加压舱；大场景允许有功能的大面积安静表面。旧样例不能替代本轮验收。

| 序号 | 检查项 | 通过标准 | 不通过后果 |
|:---:|---|---|---|
| 1 | **载具封闭加压 + 太空载具形态** | 所有小型载具（穿梭艇、巡检车、工程车、探测车、接驳艇、拖船/拖轮等）必须同时满足：①完全封闭的加压金属船体，带舷窗和推进器；②**太空载具形态**——必须有推进器喷口、散热肋片/散热板、桁架结构、RCS 姿态喷口、对接端口、工业装甲板等太空飞船特征。**严禁水面船只形态**——不得出现船首、船舷、甲板、上层建筑、船首楼、桅杆等水面船只特征，不得把水面拖船/客轮/游艇直接搬到太空。严禁开放式船体、划船/救生艇/水上小艇/带桨小船形态出现在太空或异星地表场景中。**严禁轮子**——在太空/轨道/深空场景中的飞船/载具严禁出现轮子（轮胎、履带、火车轮、汽车轮等地表载具特征），太空飞船应该用推进器、RCS喷口、桁架、对接端口等太空特征，轮子只允许出现在异星地表/行星表面的地表载具（如火星探测车、月球工程车）上。 | 返工重绘 |
| 2 | **无大眼睛小飞船** | 小型载具严禁单个大型圆形正面观察窗（"大眼睛"）。舷窗必须改用多小舷窗（方形/矩形）、长条观察窗、或无窗封闭式工业设计。 | 返工重绘 |
| 3 | **无简单复制 + 禁梭形扎堆** | 画面中如果出现多个飞行器/载具，它们必须有明显的形态差异（不同大小、不同形状、不同功能、不同涂装），严禁同一个模型简单复制粘贴。**严禁梭形飞船扎堆**：梭形（两端尖、中间粗、像织布梭子的细长飞船）是AI默认偷懒形态，多飞船场景中梭形飞船不得超过1艘，优先使用方盒子型、圆柱形、扁平碟形、不规则工业组合体等有明确工业功能分区的形态。拖船/工程船必须有短粗方盒子型、细长牵引型（非梭形，是带桁架的圆柱牵引舱）、扁平工程型等不同形态，不能全是梭形。 | 返工重绘 |
| 4 | **符合正典剧情** | 画面内容必须与正典描述的剧情一致，关键元素（地点、时间、人物、设备名称、技术参数对应的视觉特征）必须准确。不得出现正典中不存在的元素或与正典矛盾的场景。 | 返工重绘 |
| 5 | **风格路线正确** | 画面必须符合指定的风格路线（见§九风格×路线矩阵），视觉特征（光影、材质、构图、色彩、氛围）必须与该路线的定义一致。 | 返工重绘 |
| 6 | **尺度对比参照物** | 画面必须包含极小的具体尺度参照物（宇航员、小型载具、窗前驻足的人、检修步道上的工程师），其比例要小到近乎微尘，用反差彰显巨构。严禁没有尺度参照物的"不知道多大"的画面。 | 返工重绘 |
| 7 | **单一硬主光源 + 尾喷控制** | 深空场景由一个有来源的硬主光控制整体明暗；允许局部焊接、检查灯和反射光（见§十），严禁无来源的多彩环境光、霓虹光、发光轮廓。光照面极其硬朗清晰，背光面深沉克制，在深空纯黑背景前形成雕塑般的剪影。舱内/异星地表有大气的场景可适用漫射光。**多飞船尾喷控制**：同时亮起推进器尾焰的飞船不得超过1艘（通常是画面主体/正在机动的那艘），其余飞船推进器必须关闭或仅微亮（RCS喷口微弱光点即可），严禁多艘飞船同时喷出明亮尾焰导致画面杂乱、过度渲染、缺乏真实操作感。 | 返工重绘 |
| 8 | **工业材质与磨损** | 金属外壳必须呈现耐高温防辐射涂层、铸造接缝、模块化装甲板、散热肋片、外露桁架、液压管线、电缆桥架。必须带有微陨石擦痕、工质消蚀、金属氧化与结霜痕迹。严禁光滑如塑料玩具的概念车漆面、无纹理的平滑假面。 | 返工重绘 |

### 质检员交付前自检话术

每张图交付前，质检员必须在内部完成以下自问：

```
1. 画面里所有小型载具都是封闭加压金属船体吗？有没有开放式船体/桨/救生艇/木船？载具形态是太空飞船吗（有推进器喷口/散热片/桁架/RCS喷口）？还是水面船只（有船首/船舷/甲板/上层建筑）？水面船只形态必须返工。太空/轨道/深空场景中的飞船有轮子吗（轮胎/履带/火车轮/汽车轮）？太空飞船严禁轮子，轮子只允许出现在异星地表/行星表面的地表载具上。
2. 有没有"大眼睛"——单个大型圆形正面观察窗的小飞船？
3. 如果有多个飞行器，它们形态各异吗？还是简单复制了同一个梭形飞船？梭形飞船超过1艘了吗？优先用方盒子/圆柱/扁平碟形等工业形态。
4. 画面内容和正典剧情对得上吗？关键设备/地点/人物准确吗？
5. 这是指定的风格路线吗？光影/材质/构图/氛围对吗？
6. 有尺度参照物吗？人/小车/小艇在巨构面前够小吗？
7. 深空场景是单一硬主光源吗？有没有无来源的霓虹/发光轮廓？同时亮尾喷的飞船超过1艘了吗？其余飞船推进器应该关闭或微亮。
8. 金属表面有铸造接缝/散热肋/磨损痕迹吗？还是塑料玩具感？
```

任何一项回答为"否"或"有问题"，即返工重绘，不得交付。

### 风格路由使用规则

1. **每张配图必须明确标注风格编号+路线编号**（如"1B 巨大内部工业空间"），不得使用模糊描述。
2. **同一批配图中，同一路线不得重复超过3次**，必须轮换不同路线，避免视觉单调。
3. **正典剧情优先于风格路线**：如果正典内容明显适合某条路线，优先按剧情选择；如果正典内容可以适配多条路线，选择库里使用较少的路线以丰富视觉多样性。
4. **载具约束适用于所有风格**：§八的八项质检清单是全局强制标准，五大风格的所有路线都必须遵守。




## 十、 全题材做图流程与审美验收（2026-10-18 修订）

本节适用于世代飞船全部配图：舰船外观、轨道设施、舱内生活、农业生态、行星地表、档案物证、人物和历史场景。它将本轮图像迭代经验纳入通用制作流程；船坞只是案例，不把暗调、俯视、焊光或末日气氛强加给所有题材。与前文表述冲突时，按本节的适用范围解释审美与制作条款；正典与物理约束优先。

### 1. 先确定图像要说明什么

开图前写清：对应文书／场景、年代、地点、已知主体结构、物理环境、关键活动、观众第一眼需要读出的信息。区分正典物证图、概念探索图和技术说明图；探索图不得反向确立舰型或历史事实。人物、器物近景无需为满足巨构规则强塞微尘般的人群；尺度参照应匹配题材，可用手、标准件、工具或标尺。

按已有风格路线选择摄影或绘画语言，服从时代与场景。克制、专业和真实是工业场景的默认方向；生态空间可温暖，公共生活可松弛，档案照可朴素。末日感、灾难感及极繁主义仅按内容使用。

### 2. 构图与尺度先于细节词

每张图指定一个主要视觉对象或事件，安排前、中、远景的信息任务；用轮廓、遮挡、透视、疏密和留白形成主次。极繁场景也要保留安静的大形体，避免每平方米都同样繁忙。背景服务主体，不能用抢眼天体或发光装饰代替叙事。

巨构用至少两级可辨尺度参照建立体量，必要时让结构出画；具体比例服从正典。放大或缩小时说明相对参照物或画面占比，不把裁切等同于实体尺寸变化。高清细节应支持尺度，不能把大型结构缩成模型。

机位必须为信息服务：俯视交代布局与装配关系，仰视交代包围感和高度，平视适合劳动与生活，近景交代物证和工艺。避免整批作品重复同一斜向巨物构图。多角度须确认独立图或拼图，并保持对象结构、时代与状态连续。

### 3. 光线克制且有变化

深空的单一主导光控制整体方向，允许有来源的施工灯、窗光、导航灯与反射；舱内和有大气地表按真实环境设置漫射及多光源。不能把全题材简化为一个硬光模板。

照明具有亮度、色温、密度与功能的层次。避免等距等亮灯带、满屏暖金灯点、无来源彩光和同时争抢注意力的高亮区。工业施工可有局部焊光，生态舱可有植物补光，生活区可有灯窗与局部人物活动，但都须照亮具体对象。高亮变化由活动产生，不为打破单调随意添灯。

低照度画面仍应辨识主体、通道与关键工艺；柔光也须有接触阴影与体积关系。调暗、变冷等指令记录为相对视觉调整，未指定单位时不擅自解释成曝光档数或物理参数。氛围不能靠压黑掩盖结构错误。

### 4. 环境决定结构、运动与烟尘

先标明真空／加压舱／有大气地表，以及失重／自转重力／地表重力。交通方式、人的姿态、构件固定、颗粒运动和作业安全都依环境变化。避免将陆地港口、道路、工厂或海船直接搬进太空；也不把舱内有重力的生活区画成无缘由漂浮。

真空允许工艺产生的短暂局部喷流、金属蒸气与微粒快速扩散；禁止浮力上升的烟柱和遍布太空的雾。加压舱可有受通风影响的烟尘，地表须服从大气与风向。烟雾、火花、尾喷均为有因果的局部活动痕迹，不是每图必加的特效。

载人小艇要求气密舱与合理出入方式；无人检修机器人、开放桁架拖曳设备不必伪造加压客舱。受控自由飞行构件可以无接触支承，但近景须能读出机械捕获、系索或姿态控制关系。地表车辆、固定导轨机构与自由飞行载具应分别判断，不用同一外观模板处理。

### 5. 细节、材质和背景的取舍

细节来自功能层级：主结构、舱段、检修接口、管线与紧固件。先保证工程关系清楚，再增加近看细节；不以随机管线、铆钉与碎片密度冒充复杂系统。磨损按年代、位置与暴露环境分配，新造件不必遍布锈蚀，真空外壳不默认具有潮湿地面的锈水痕。

金属、陶瓷、玻璃、织物和植物各有不同反射与粗糙度；镜面反光、珠光、焦散、次表面散射仅在材质与照明适用时采用，不把渲染术语全部叠在提示词中。

外太空默认近黑与稀疏星点；银河、星云和巨大行星仅在位置与内容需要时出现，并服从曝光关系。舱内背景须交代真实舱壁、曲率或结构，地表背景须交代地貌与气象。保持背景可信且不夺主。

### 6. 通用提示词顺序与修改方式

```text
[图像用途与正典边界] + [年代／地点／环境与重力] + [主体结构与正在发生的活动]
+ [机位、画幅、视觉中心与尺度参照] + [主光、局部活动光与明暗层次]
+ [功能细节与材质状态] + [背景及氛围] + [摄影／绘画路线]
+ [本场景的具体负向约束] + [实际交付要求]
```

用户已经具体描述时以整理和消除冲突为主，避免擅加天体、角色、灾难或品牌。负向词应按题材选择：人物档案照不能机械套用“必须极繁”，真空场景不能套用“大气光柱”。

编辑现有图时，明确目标图与保留项，再列修改项；优先以选定图作为编辑输入。先解决结构／机位，再解决尺度，再调光色和活动细节；相互依赖的问题可同轮修改。保留原图与选版关系，防止反复重生成导致主体漂移。独立新图不能误继承上一张灾难或舰型。

8K、32K、UE5、光追及胶片等词是视觉目标，不证明真实像素、渲染工具或拍摄介质。交付记录实际分辨率及生成方式；原始分辨率、放大处理与风格描述分别说明，不制造虚假高清承诺。

### 7. 全题材交付验收

在§八清单基础上，按适用范围检查；不适用项注明原因：

| 检查维度 | 验收问题 |
|---|---|
| 内容 | 是否准确对应文书，探索性设定有无冒充正典？ |
| 主次 | 第一眼是否看懂主体与活动，背景和亮点是否喧宾夺主？ |
| 尺度与机位 | 比例参照是否有效，透视和视点是否支持图像任务？ |
| 光线 | 是否有来源、有层次，既避免杂乱亢奋，也避免重复单调？ |
| 环境物理 | 重力、气压、支承、运动、烟尘与载具是否一致？ |
| 细节与材质 | 是否能解释功能和工艺，有无玩具感与无意义堆砌？ |
| 连续性 | 编辑是否保住所需结构，多视图是否为同一对象？ |
| 交付 | 真实像素、文件、版本与图文绑定是否准确？ |

验收不能只靠一长串否定词。发现问题应记录到具体可见部位，并用一次针对性修改验证改善；检查通过后停止无目的翻新。

## 十一、 大场景专项：空间、尺度与文明活动

### 1. 大场景的六层组织

开图前按以下层次写场景，不要求每层都塞满：

| 层次 | 负责表达 | 可见线索 |
|---|---|---|
| 总体形体 | 这是什么地方 | 环、筒、轴、山体、舱壁、城市地形；缩略图仍清楚 |
| 空间骨架 | 空间如何延伸 | 曲率、主通道、跨距、径向连接、山谷轴线和地平线 |
| 功能分区 | 各处在做什么 | 生产、物流、居住、农业、能源、检修区域的形态差异 |
| 人类尺度 | 它究竟有多大 | 标准舱、门、通道、车辆、工位和人物的连续比例关系 |
| 局部活动 | 此刻为何值得看 | 装配、靠泊、巡检、收获、通勤、交接等一个主要事件 |
| 表面细节 | 它如何建成并使用 | 面板、接口、补丁、磨损、局部生活痕迹 |

先成立前三层，再加入后三层。无法读出总体形体时，继续加窗户和灯光只会增加噪声。

### 2. 六种构图方法及选用条件

- **局部进入巨构**：近景截断梁、舱壁、岩壁或建筑边缘，观众从结构内部向外看。前景必须有功能和厚度，不能用任意黑块遮画面。
- **沿轴深入**：主廊道、管廊、船台或峡谷引向远处；通过逐步缩小的构件、交叉通道和局部遮挡建立距离。避免所有结构汇聚成一个无法辨认的亮洞。
- **曲率展开**：环城、圆筒生态舱或环形设施沿曲面展开，远处街区改变朝向；梁、交通线和地形应共同服从曲率，不能仅把天花板画弯。
- **跨层俯瞰**：从真实的高层检修点、运输层或观景位置看向多层空间；交代层间连接与空隙，避免全图同一高度的平铺模型。
- **巨物掠边**：主体部分出画，主体边缘旁的小艇或维护设施提供比例，远处天体建立位置。局部构件要能推知整体，不能只剩无意义的金属墙。
- **远景与近景事件并置**：近处一个劳动或通行事件，对照远处广域城市、生态带或基地网络。事件面积小但轮廓清楚，不靠放大人物破坏巨构尺度。

这些是可选择的工具，不是强制拼装清单。正典物证需要全貌时允许完整纳入画幅；出画并非所有图的硬指标。

### 3. 尺度要形成连续证据

避免“一个巨大物体旁加一粒小人”就宣布尺度成立。至少让两级中间结构可读：例如人 → 门与工位 → 维护舱 → 环形主梁；小艇 → 对接端口 → 总装分段 → 船体；车辆 → 道路与街区 → 穹顶 → 山体。尺寸有依据时按依据，没有依据时只记录相对关系。

重复单元应在透视中递减，并有符合功能的变化：主梁跨距稳定，维修节点少量不同，街区密度按用途变化。远处小单元可以融合成纹理，不能强求每颗铆钉同样锐利。大尺度结构保持稳定几何与表面分区，避免密集无规则拼片产生微缩模型感。

### 4. 深度来自几何，空气感按环境使用

以前景遮挡、中景连接、远景延续建立空间；至少有一条可追踪的视线路径，同时保留次级路径与休止区。重复主结构可以有节奏，局部设备和活动不应机械复制。

真空深度依靠遮挡、透视、光照和投影，不靠距离越远雾越厚。舱内远景是否降低对比，取决于空气、跨度和照明；地表大气透视取决于当地气象。浅景深、倾斜微缩效果与全屏锐化都容易损害巨大尺度，应有明确拍摄理由。

### 5. 密集与安静区域相互衬托

极繁场景把细节集中在功能接口、交通交汇、居住层和作业节点；主体的大面、外部虚空、未开发地形或开放中庭可安静。允许大面积低细节面，其比例与尺度必须正确，不能把“禁止平滑假面”误读成“每一处都铺满管线”。

明暗组织先看大块面，再看局部亮点。采用少数可辨的亮区、过渡区与暗区组织观看顺序；不要给每座建筑、每根桁架都加轮廓灯。主次既可由亮度，也可由形体、颜色、位置和留白建立，无需每次都做中央强光。

### 6. 大场景需要有秩序的活动

繁忙程度通过交通层级和工序关系表达：大型船靠泊或缓慢机动，中型运输设备走独立通道，小型巡检设备靠近工作面；活动密度在节点处增加，航道留出安全空间。惯性滑行无需持续明亮尾焰。

人物、机器人与设备应在做具体事情，位置能解释工作流程。生态区的生活感可来自桥上通勤、维护补光、水培收获；城市可来自层间运输和公共空间；地表基地可来自资源运输、维修和进出气闸。不是每张图都添加焊接，也不是每个地方同时发生戏剧事件。

### 7. 不同大场景的转译表

| 场景 | 核心空间证据 | 局部活动与光线 | 常见失败 |
|---|---|---|---|
| 轨道船坞／工业巨构 | 贯穿桁架、镂空层次、多向接近与捕获关系 | 局部工序闪光、定向检查灯，主体结构保持安静 | 陆地道路搬进真空，满屏灯带与烟雾 |
| 环形城／圆筒居住舱 | 曲率连续、径向连接、远处街区朝向变化 | 生活窗、交通节点和公共空间按分区分布 | 普通平面城市加一片弯天花板，所有窗户同亮 |
| 巨型机库／母港内景 | 跨距、层高、连续分舱与通道递减 | 靠泊、检修、吊运；照明按工区而非均匀铺开 | 正中亮洞吞没结构，人物与门的比例失控 |
| 农业生态空间 | 种植层、水路、检修网、采光与舱壁的关系 | 收获、授粉、管路维护；日光与补光各有来源 | 只剩地球公园，工程与循环系统消失 |
| 行星基地／殖民城市 | 地形约束、压力边界、运输与资源网络 | 车队、施工、进出气闸；服从当地日照风尘 | 随机穹顶散落，所有区域像同一功能的模型 |
| 采矿／能源设施 | 采掘面、输送路径、处理区与维护区的链条 | 分区运行、装卸与检测；热区和普通工区区别照明 | 只有大机器和碎石，没有物流与操作关系 |
| 巨舰航行／星际远景 | 主体功能布局、参照小艇或天体、清晰剪影 | 少量巡检或伴飞；按状态控制尾喷 | 豪华游艇化、主体缩成小挂件、星云抢戏 |
| 仪式／公共历史场景 | 广场或舱室尺度、通行与集合关系 | 人群行为、设施使用与现场照明 | 英雄人物占满画面，普通参与者沦为重复贴图 |

### 8. 一组图像应互补

同一场景的组图可以依次回答：它在哪里、空间如何组织、人如何使用、关键工艺如何发生。无需机械生成四联图；按用户用途选择单张或多张。建立对象不变量：主轴、环数、对接方向、功能分区、建造进度与涂装。相机换位后，太阳在画面中的左右可以变化，但世界坐标中的光源方向应一致。

### 10. 大场景的三轮验收

1. **缩略图看大形体**：缩到约320像素宽，主体、明暗与空间方向是否仍可辨？多亮点是否分散注意？此项是观看方法，不是硬性像素标准。
2. **正常尺寸看空间和活动**：通道、层间连接、尺度链和主要活动是否成立？是否只有“很复杂”却没有可读关系？
3. **局部放大查工艺与物理**：接口、材质、人物姿态、颗粒方向与结构是否穿帮？不能以远景漂亮掩盖近景错误，也不能为了每处微细节锐利牺牲整体。

大场景不通过时，按“形体与空间 → 尺度与活动 → 光线与细节”定位问题，而不是继续追加 epic、maximalism、32K。最终记录使用的构图方法、参照物、环境和主要修改；一次形成的审美结论不能未经判断推广到所有题材。
