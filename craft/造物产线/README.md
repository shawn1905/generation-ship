状态：2026-09-05，设定基线与依赖审计 v0.1；元层工程工作文件，非世界内正典，未授予 GS 编号。

## 重跑检查

在仓库根运行：

```sh
python3 scripts/audit_world_basis.py > /tmp/world-basis-audit.json
```

脚本只读源文件、输出 JSON，不修正档案，不修改登记簿。检查编号唯一性、登记目标、年代候选差异与引用目标，并记录源文件 SHA-256。已有投稿合规校验不能代替这些检查；这些检查也不能代替语义审阅和物理核算。

本轮已在桌面试制目录生成 Blender 样件、GLB、检查渲染图与 Unity 场景；仓库只保存生成源和验证报告，桌面二进制资产不随本次提交入库。此前本地搜索未发现已有 `.blend/.glb/.gltf/.fbx/.obj/.stl/.step/.stp` 实体模型文件；不据此断言外部磁盘或其他分支没有资产。
