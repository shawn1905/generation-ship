## 2. 证据分层

| 标签 | 含义 | 模型如何使用 |
|---|---|---|
| 世界约束 | 内核明确的物理与叙事边界 | 必须遵守；与工程证据冲突时登记并提案 |
| 文书陈述 | 某份正典在某时某地的记录 | 保留说话者、时间与范围，不自动推广为全宇宙规律 |
| 现实证据 | 已打开的外部原始来源能支持的具体事实 | 只迁移已证明部分，保留应用环境差异 |
| 推导结果 | 给出输入、公式、单位、适用假设的计算 | 可进入参数；随输入变动重算 |
| 实验假设 | 为试制选定、尚无正典依据的规格 | 必须可替换；不自动成为标准或正典 |
| 争议项 | 来源矛盾或证据不足 | 保留候选值；依赖它的正式资产不得悄悄定值 |

内核规定“怎么判合法”，正典记录“当时发生或声称什么”，现实证据判定“工程上证明了什么”。它们不是简单的文件新旧排序。控制台摘要不能覆盖原文；新日期本身也不是修订授权。

## 4. 七条线路的资产依赖

| 线路 | 主要对象 | 必须输入的条件 |
|---|---|---|
| 工业自持 | 母机、采选、冶炼、回收设备 | 原料、纯度、耗材、功率、产率、排热和备件来源 |
| 建造工程 | 舱体、桁架、推进与屏蔽系统 | 压差、载荷、质量预算、热预算、装配和维修路径 |
| 生物圈 | 培养槽、光生物反应器、温室 | 气液流、光照、清洗、污染隔离、损失补充 |
| 制度 | 终端、计量器、签收与档案器具 | 谁使用、谁维修、谁能改装；制度变化是否改变接口 |
| 通信 | 主镜、信标、指向与存储设备 | 波长、口径、精度、功率、散热、维护与链路预算 |
| 地理 | 港口、城镇、修复设施 | 当地重力、地质、大气、运输与能源来源 |
| 义体 | 辅助装备、维护台、充电接口 | 使用者、人体接口、功耗、维护和电磁环境；医学参数待专项核验 |

## 5. 本轮外部核验样例

[NASA 2023-09-06 MOXIE 任务总结](https://www.nasa.gov/solar-system/nasas-oxygen-generating-experiment-moxie-completes-mars-mission/)记录了 16 次火星产氧、累计 122 克氧气。读取日期：2026-09-05。它支持“火星原位产氧演示”，不能单独支持“甲烷合成、液化储存、轨道转移加注的整条链路已经成熟”。

这是证据适用范围核验，不是对全部 2026 项目状态的调查。科技树内其它 TRL、效率、寿命与产率目前仍需按资产依赖逐项查证。

先做 2035 地月货运背景下的非承压备件货箱与机械固定底座。它继承货运需求，不依赖 2088 芯片闭环、聚变或 ARK 尺寸。尺寸、接口和载荷是显式实验假设，见[规格卡](首件规格卡.md)。
