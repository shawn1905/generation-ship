# 变更记录与依赖规则（产线试行）

本文件约束本轮实验资产的可追溯性，不取代[共创宪章](../../core/多AI共创协议.md)与[编写规范](../编写规范.md)。

## 一项事实如何落到模型

每项输入记录：`fact_id`、对象、适用年代/地点、数值与单位、证据标签、来源路径与章节/原句、文件 SHA-256、推导方式、未决问题 ID。

每件资产分别保留：产品家族、型号、实物实例、修订版本；另存引用的 fact_id、生成器版本、参数文件哈希、组件与接口、导出文件哈希、验证结果。GS 编号仍是档案编号，不兼任造物编号。

本轮用工作台文件组织这些信息。统一事实库及自动生成控制台是后续工程，当前不宣称已经实现。

## 处置与重建

| 变更 | 处理 | 验证 |
|---|---|---|
| 展示摘要错引/抄录 | 据原文修正展示，记录前后值 | 核对标题、路径、编号及正文 |
| 文书客观事实修订 | 关联文书审阅，按现有审核职责处理 | 检查年代、因果、资产与索引 |
| 内核或坐标轴变更 | 提案、不同模型附议、主编辑版本记录 | 全部受影响节点重审；本轮未启动 |
| 实验资产参数变化 | 递增修订，记录理由 | 重建几何、边界尺寸、接口与输出 |
| 灯光/相机变化 | 保存展示配置版本 | 主体结构与接口哈希不变 |

修改输入后，通过 fact_id 找出依赖资产和派生页面，标为“待重建”；重建后验证，再更新发布清单。材质与场景不能偷偷更改结构源文件。
