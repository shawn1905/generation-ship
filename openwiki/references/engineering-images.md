# NASA Engineering Reference Images

The repository contains a curated collection of NASA public domain reference images that are used for design inspiration and reference. The images are located in `/docs/nasa_参考影像/` organized by subsystem.

## Content

The collection includes:

### 1. Stanford Torus (NASA SP-413)
- Complete set of images from the original 1975 NASA Ames Stanford Torus study
- Includes:
  - Original diagrams of the torus design
  - Cutaway views
  - Interior layout
  - Artist's impressions

This is a key reference for rotating habitat design

### 2. Other NASA Reference Material
- Other NASA public domain images related to:
  - Space station design
  - Life support systems
  - Propulsion systems
  - Space colonization concepts

## Organization

Images are organized by subsystem, matching the subsystems in this wiki:
- propulsion/
- habitat/
- life-support/
- radiation-shielding/
- general/
